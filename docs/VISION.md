# ゲームの方向性（配り役が新しい項目を考えるときの拠り所）

持ち主の言葉：「剣と魔法のファンタジー。凶暴な魔物や、ランスシリーズの魔人のような知能のある凶悪な敵がいる。残酷だけど冒険の楽しさがあり、上位存在もいる世界。TRPG のようにステータスで成功率が決まり、ステータスは行動で成長する。死んだら年表を見たい。実績はトロフィーとして残したい。自由に行動したいが、そのたびにトークンを使うのは嫌」

## 柱
1. **何でもできそうな自由さ**：町・野外・迷宮・施設・出来事の選択肢・自由入力の読み取りで、トークンなしに多くの行動ができる。足りないときだけ GM（Claude）に任せられる。
2. **ステータスがすべて**：あらゆる判定の成功率は能力値から計算して画面に出す。使った能力値が伸び、才能限界で止まる。
3. **残酷で、でも楽しい世界**：弱い者が踏みつけられ、選択には代償がある。同時に、ばかばかしさと冒険のわくわく感がある。
4. **上位存在**：神々（創世神ヴェルムと三天神）→ 魔王 → 十三魔人 → 使徒。魔人は絶界に守られ、二振りの剣でしか斬れない。
5. **一代限りの人生と、残る記録**：死ねば終わり。年表と墓碑とトロフィーが残る。

## 広げていく方向（配り役はここから項目を作る）
- **出来事**：場所・状況ごとの出来事をどんどん増やす。一つの出来事に、能力値の違う2〜3の解き方と、判定なしの選択肢を用意する。続き物（`next`）や一度きり（`once`）も使う。
- **敵と魔人**：残りの魔人（十三のうち未登場の十体）、その使徒、地域ごとの魔物。魔人は倒せなくても関われる出来事（取引・逃走・玩具にされる）を持たせる。
- **場所**：国ごとの町・迷宮・秘境。魔物界の奥。八雲の島々。
- **仕組み**：魔法の種類と習得、装備の強化、仲間の個性と会話・裏切り、国ごとの評判と悪名、季節と天候、世界の出来事（魔人の襲来で町が滅ぶ、戦争が始まる）。
- **目的の道筋**：どの目的にも、たどり着くまでの中間の目標と、そこで起きる出来事を用意する。
- **絵と画面**：場所・天候・季節ごとの背景、迷宮の種類ごとの背景、戦闘の演出、スマホでの遊びやすさ。
- **釣り合い**：職業ごとの生き残りやすさ、敵の強さ、お金の入り方。テストで測って直す。

## やらないこと
- 普段の手番で Claude を呼ぶ仕組み（持ち主はトークンを使いたくない）。
- 外部の画像・音声ファイル、外部ライブラリ。
- 性的な描写の直接の表現。
- 実在の作品の固有名詞（ランス・リーザス・魔剣カオスなど）をそのまま使うこと。雰囲気は参考にし、名前と設定は独自に作る。
