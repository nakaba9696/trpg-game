# 仲間との会話の書き方（talk）

持ち主の声：「冒険で楽しいことは魅力的なキャラとの掛け合いだと思います。キャラとは色々話ができるようにしてください。特に仲間にできるような主要なキャラです」

仲間になる主要な人（C2 の 8 人・C4 の 4 人）と、話題を選んで話せるようにする仕組み。**全部データで動く（Claude を呼ばない）。**
最初に書いたのはディル・シェイラ・ノラ・ゼリナの 4 人。残りの人は、この手引きを読んで `src/data/talk_<id>.js` を一つ足せばよい（仕組みは触らない）。

- 仕組み：`src/engine/zzzzz_talk.js`（G.tk）
- 中身：`src/data/talk_dil.js`・`talk_sheila.js`・`talk_nora.js`・`talk_zerina.js`（D.TALK[id]）、掛け合い `src/data/talk_banter_c2.js`（D.TALK_BANTER）
  - K2 で 8 人を足した：`talk_kaidel.js`・`talk_rui.js`・`talk_elnea.js`・`talk_natalia.js`・`talk_bertrand.js`・`talk_ilse.js`・`talk_tula.js`・`talk_mirlene.js`、掛け合い `talk_banter_k2.js`
- 画面：出来事の画面をそのまま使う（話題の一覧・話・返し方が「どうする？」の欄に並ぶ）。シートの仲間の札の「話す」は `src/ui/talk.js`
- 確認：`tests/checks/talk.mjs`（人を足すと、その人の表も自動で確かめる。量の下限を確かめる人は `PEOPLE` に足す）。K2 の 8 人の量・恋と信頼の分け方・全部聞き切る遊びは `tests/checks/talk_k2.mjs`

## 遊び方の流れ
1. **話す**：行動の「仲間」の欄か、シートの仲間の札の「話す」。一日一度、一手番を使う。好感度が尽きた仲間（F3 で −70 以下）は今まで通り M2 の別れ話になる。
2. **話題の一覧**：今話せる話題から 3〜5 個（冷たいときは 3 個まで）。並べ方：最近の出来事への反応 → 頼まれごとの続き → 残りの種類から一つずつ（毎回少し違う順）。身の上は一番浅い段が出る。C2 の「その人だけの話」（`c2talk` の出来事）も、ときどき「（〇〇の様子を見る）」として混ざる。
3. **話**：話題を選ぶと、その人が話す（地の文と台詞）。返し方を 2〜3 個から選ぶ。返し方で好感度が動く。一度の「話す」で三つまで話せる。
4. **既に聞いた**：一度返した話題は出ない（`again: true` のものを除く）。続き（`after`）があれば、次から開く。最近の出来事への反応は、次に同じことが起きればまた出る。
5. **掛け合い**：仲間二人が勝手にしゃべる（2〜6 行）。旅で場所を移った手番（3 割）、野営・宿の夜（3 割）、ふだんの手番（5 分）。一日に一度まで。問いのあるものは、どちらの肩を持つか選べる（片方が上がり、片方が少し下がる）。
6. **夜の会話**：野営・宿に泊まった夜、好感度 30 以上（信頼している）の仲間が、一人だけ話しかけてくることがある（4 割半）。一夜に一度まで。夜の話題（`kind: "night"`）か、身の上の次の段を一つ話して終わる。宿から始まった会話は、終わると宿に戻る。

## データの形
```js
// src/data/talk_<id>.js（id は D.C2_PEOPLE の鍵）
(function (G) {
  const D = (G.data = G.data || {});
  D.TALK = D.TALK || {};
  const R = (tone, label, text, x) => Object.assign({ tone, label, text }, x || {});
  D.TALK.dil = {
    tones: { earnest: 2, tease: 4, joke: 4, praise: -1, sweet: 1, scold: -4, cold: -3, quiet: 2 }, // 返し方の好み
    greet: { warm: [...], mid: [...], low: [...], cold: [...] }, // 話しかけたときの一言（好感度 45 以上・10 以上・それ未満・−20 以下）
    bye: [...],            // 話を切り上げるときの一言
    empty: [...],          // 話すことが無いとき
    nightIntro: { camp: [...], inn: [...] }, // 夜に話しかけてくるときの一言
    topics: [ { 話題 }, ... ],
  };
})(globalThis.G = globalThis.G || {});
```

### 話題
| 鍵 | 意味 |
|---|---|
| `id` | すべての人で重ならない（`<人>_<種類><番号>` が分かりやすい：`dil_p3`・`nora_l_forest`） |
| `kind` | `past` 身の上・`place` この土地・`event` さっきのこと・`mate` 仲間のこと・`chat` 世間話・好み・`ask` 相談・頼みごと・`love` ふたりのこと（恋）・`bond` 信頼（恋の相手にならないときの、恋の代わり）・`cold` 冷たい会話・`night` 夜だけ |
| `title` | 一覧に出る見出し（選択肢の文）。`{m}` が使える |
| `text` | その人の話。文字列か、行の配列（一行ずつ記録に出る） |
| `replies` | 返し方 2〜3 個（下の表） |
| `mood` | 立ち絵の表情（`joy`・`anger`・`sorrow`・`fun`）。無ければ文から推す（V8 の `G.guessMood`） |
| `step` | 身の上の段（1 から。一覧には一番浅い段だけ出る） |
| `min` / `max` | 好感度（F3 の −100〜+100）の範囲。`min` の既定は −19（冷たいときは出ない）。冷たい会話は `max` の既定が −20 |
| `after` | 前に聞いた話題の id。`"dil_a1#yes"` なら、その話題で `key: "yes"` の返しを選んだときだけ |
| `at` | 場所の id か札（`town`・`wild`・`dungeon`・`capital`・`port`・`snow`・`realm`）。夜の話題は `camp`・`inn` |
| `fresh` | `event` の種類（下の表）。その仲間が居合わせた出来事が 6 日以内にあると出る |
| `mate` | ほかの仲間（C2 の id）。その人が一緒にいるときだけ。`{m}` がその人の呼び名になる |
| `need` | 頼まれごとの続き：`{ item: "herb" }`・`{ gold: 20 }`・`{ loc: ["karna"] }`（全部そろうと出る） |
| `love` | `true` なら恋の話題。恋の相手になれるとき（`G.m10Can`。名のある人は `D.C2_PEOPLE` に `romance: true` がある人だけ。#182・`docs/romance.md`）だけ。`kind: "bond"` の信頼の話題は、その逆で、恋の相手になれないときだけ出る。**18 歳未満の主人公・18 歳未満や子どもの姿の相手には出ない**（`zzz_love_age.js`） |
| `when` | `(S, c) => 真偽`。そのほかの条件（例：シェイラの `S.flags["ev:c2_siblings"]`） |
| `again` | `true` なら何度でも出る（冷たい会話） |

### 返し方
| 鍵 | 意味 |
|---|---|
| `tone` | `earnest` 真面目に聞く・`tease` からかう・`joke` 冗談で返す・`praise` 褒める・`sweet` 優しくする・`scold` たしなめる・`cold` 突き放す・`quiet` 黙っている |
| `label` | 選択肢の文（下に返し方の名前が小さく出る） |
| `text` | その人の返事（文字列か配列） |
| `aff` | 好感度の増減（書かなければ、その人の `tones[tone]`。それも無ければ既定 `G.tk.TONES`） |
| `plus` | `tones` の値に足す数 |
| `key` | 続きの条件に使う印（`after: "<id>#<key>"`）。無ければ `tone` |
| `pay` | 頼まれごとの続きで、`need` の物・金を渡す |
| `memo`・`lore`・`grow`・`item`・`gold`・`hp`・`flag`・`fame`・`chron` | 出来事の結果と同じ書き方 |

### 最近の出来事（`fresh`）
`win` 戦いに勝った・`boss` 大物を倒した・`apostle` 使徒を倒した（E3）・`near` 死にかけた（HP 3 割未満）・`fled` 負けた・逃げた・`death` 仲間が死んだ（`{dead}`）・`left` 仲間が去った・`crime` 罪を犯した（M3）・`quest` 依頼を果たした・`arrive` はじめての場所に着いた・`title` 称号を得た。
文の `{foe}` は、その出来事の相手（戦った敵・着いた場所・称号）、`{dead}` は死んだ仲間の呼び名。

### 掛け合い
```js
D.TALK_BANTER.push({
  id: "bt_dz_debt", a: "dil", b: "zerina", title: "三頁", where: ["road", "town"], // road 旅のあと・camp 野営の夜・inn 宿の夜・場所の札
  lines: [["b", "{a}、あんたの欄、今日で四頁目に入ったで"], ["a", "…"], ["", "地の文"]],  // 2〜6 行
  side: { q: "二人が、同時にあなたを見た。",                                             // 無ければ聞くだけ
    a: { label: "「…」と{a}に付く", text: [["b", "…"]], aff: [4, -2] },                 // [a の増減, b の増減]
    b: { label: "…", text: [...], aff: [-2, 4] }, none: { label: "どちらにも付かない", text: [...], aff: [0, 0] } },
  // min: 二人とも好感度がこれ以上・after: 前の掛け合いの id・when: (S) => 真偽
});
```
台詞の行は「ディル「…」」の形で記録に出る（呼び名は `G.m2Short`）。

### 文の差し込み
`{n}` 話している人の呼び名・`{m}` 話題の仲間（`mate`）・`{a}` `{b}` 掛け合いの二人・`{foe}` `{dead}` 最近の出来事・`{place}` 今いる所・`{you}` 主人公の名前・`{kin}` `{food}` `{home}` `{keep}` `{habit}` その人の暮らし（M2）。

## 量の目安（一人あたり）
- 話題 **20 以上**（4 人は 36〜38）：身の上 5〜6 段（最後は秘密か悲しい過去）・場所 5 以上・出来事への反応 5 以上・ほかの仲間 3 以上・世間話と好み 3〜5・相談 2 と、その続き 2・冷たい会話 2〜3・夜 2・恋 1（`romance` のある人）・信頼 2（恋の代わり。全員に書く。主人公が 18 歳未満のときも、これが出る）
- 返し方は 2〜3 個。少なくとも一つは、その人が喜ぶ返し。冷たい返し（`cold`）は、悲しい話にだけ置く（突き放すと下がる）
- 掛け合い：組み合わせごとに 2 つ以上。問い（`side`）のあるものを半分くらい
- 好感度の動き：ふつうの返し ±1〜5、深い話・頼まれごとの続き +8〜15、突き放す −4〜−8

## 口調と中身の注意
- **説明役にしない。** 暮らし・悩み・癖・好物・その日の用事で話す（[lore/voice.md](lore/voice.md) の「人物の作り方」）。世界の仕組みや信仰を語らせない。上位の存在の真相の言葉（`tests/checks/u3_voice.mjs` の BANNED）・今の人の「魔王」は書かない。
- **口調はその人の今の台詞に合わせる**（`src/data/c2_people.js` の `D.C2_VOICE`・`events_c2*.js`）：ディル「俺」・だるそうで計算高い／シェイラ「うん、」から・「じろり」「うむり」／ノラ「あたし」・明るく短い／ゼリナ「うち」・関西言葉。カイデルは「俺」で後先を考えない、エルネアは「〜っす」、ナタリアは酒、ルイはほとんど話さない（仕草で）。
- **地の文は二人称（あなた）か三人称。叫ばない**（「！」は台詞の中だけ。テストが確かめる）。台詞のあとに、その人の癖を一つ置く（頁の角を折る・耳が下がる・銅貨を転がす）。
- **身の上は浅い順に深く。** 一段目は誰にでも話す話、最後は秘密か悲しい過去。答え合わせはしない（断片で）。秘密は `memo` に一行残す（見たこと・聞いたことだけ）。
- **ほかの仲間の話は、相性で書き分ける**（ディルとゼリナは犬猿、シェイラとノラは先生同士）。
- **冷たい会話**は、刺々しくても、その人らしく（ディルは帳面に線を引く、ノラは一人で火を起こす練習をする）。持ち直す返しを一つ置く。
- 性的な描写はしない（体つきを書かない。C2 の確認に合わせて「胸」も避ける）。恋の話題は `love: true` を必ず付ける。子どもの姿の人（ルイ）には恋の話題を作らない。
- 物語の秘密に触れる人（シェイラが第七王子、など）は、明かす出来事のフラグを `when` で見る。

## 乱数
話題の並び・声のかけ方・切り上げの一言・「様子を見る」が混ざるかは、状態（冒険・手番・日・仲間・何番目の話）から決まる乱数（`G.tk.roll`）で選ぶ。`G.rand` の並びを使わないので、会話をしても戦いや出来事の乱数の並びは変わらない（目的の道筋のボット `tests/checks/q4_goals.mjs` が揺れない）。夜の会話・掛け合いが起きるかどうかだけ `G.rand` を使う。

## 古いセーブ
`S.tk` が無くても `G.tkState` が埋める。会話の途中で保存しても、殻の出来事（`tk_menu`・`tk_topic`・`tk_banter`）が `S.tk.cur` から同じ選択肢を作り直す。
