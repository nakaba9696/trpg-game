# BGM の試聴（S4）

各曲の頭 20 秒（終わりは 2.5 秒で絞った）。ゲームの中では一巡りの終わりから頭へ途切れずに回り続ける。
作曲データは `src/data/s4_tracks.js`、鳴らす係は `src/ui/sound_bgm.js`。作り直すときは `node tools/bgm_render.mjs --out docs/sound/bgm 20`（Chromium と ffmpeg が要る）。
`node tools/bgm_render.mjs` だけなら、すべての曲を一巡りぶん鳴らして、大きさ・音割れ・無音・重さ（実時間の何倍で作れるか）を出す。
