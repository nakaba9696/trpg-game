# 覚え書きと記録（L1）の書き方と足し方

死んで覚えるのは**プレイヤー**。ゲームは、見たこと・起きたことを冒険をまたいで記録し、図鑑と墓碑で読めるようにする（`src/engine/zzz_know_l1.js`、画面は `src/ui/zk_know_l1.js`）。
仕組みの上での引き継ぎ（能力・知識による補正）はしない。覚えていても成功率は変わらず、選択肢も増えない。そのかわり世界の決まりを周回でぶれさせない。方針は [VISION.md](VISION.md) の「難しさの考え方」。

## 残るもの（G.P。死んでも引退しても残る。古い profile には無い＝まだ何も記録していない）
| 欄 | 中身 | 画面 |
|---|---|---|
| `G.P.know` | 覚え書き（魔物について分かったこと・魔物の癖と弱点・迷宮の罠と隠し部屋・使徒の守りの綻び）`{ id: { how, by, date, at } }` | 図鑑「覚え書き」の頁（埋まっていない数は「？？？」） |
| `G.P.kev` | 出来事でどれを選んで何が起きたか `{ 出来事: { 選択肢の番号: { n, ok, ng, fight, dead } } }` | 同じ頁の「出来事でどれを選んだか」（✓✗⚔☠の印） |
| `G.P.kfoe` | 戦って分かったこと `{ 敵: { a: { 手: [試した, 通った] }, wall, dealt, taken, slew } }` | 図鑑「魔物」の詳しい説明（試した手・効かなかった手・あなたを倒した・覚え書き） |
| `G.P.kshop` | 店の品と値段 `{ 町: { items: { id: 値段 }, date } }` | 図鑑「覚え書き」の頁 |
| 墓碑 `know`・`last` | その冒険で覚えたこと（死に際の印）・最期の様子（死因・場所・直前の出来事・戦っていた相手・HP・倒れる前の十行） | 年表と墓碑の「最期の様子」「次に活かせること」 |

出来事の記録は、どの出来事にも自動で付く（W4 などの新しい出来事も、何も書かずに載る）。

## 覚え書きが残るきっかけ（how）
| how | いつ |
|---|---|
| fail | 罠にかかった |
| seen | 罠を避けた・魔物を倒した（倒すたびに分かったことが一つ。冒険をまたいで三度倒すと癖の書きつけ）・使徒と戦った |
| death | 死に際（その場の敵について分かること・癖・使徒 → その階の罠 → その場所に関わること → まだ知らないどれか、の順で必ず一つ） |
| rumor | 酒場で噂を聞いた（二度に一度。近い場所のことから） |
| ally | 仲間がいて宿か野営で休んだ（五日に一度まで） |

乱数は使わない（噂も仲間の話も、近い順に決まる）。

## 書き方
`D.KNOW[id] = { kind, title?, text, ... }`。新しいファイル（`src/data/know_<名前>.js`）に書けば自動で読まれる。
**text** は手帳の書きつけ。「〇〇：……」の形で 60 字くらいまで。答えをそのまま書かない（✗「スライムは火に弱い」 ○「刃を入れると刃が減る。火を見せると縮んだ」）。[voice.md](lore/voice.md) の決まりを守る。

| kind | 欄 | 決まり |
|---|---|---|
| `fact` | （書かない。E4 が敵のデータに置く `e.know = [{ id, text }]` から作る） | 魔物について分かったこと。その魔物を倒すたびにデータの順に一つずつ分かる（死に際・噂・仲間の話でも）。データから作るので食い違わない |
| `foe` | `foe` 敵の id・`aim` | `aim` は書きつけが言っている弱点：`blade` 刃（守り ≤ 魔法の守り か ≤ 5）・`magic` 術（魔法の守り < 守り か ≤ 0）・`talk` 脅し（意志 ≤ 60）・`flee` 足が遅い（素早さ ≤ 35）・`habit` 癖だけ。**データと食い違わないこと**（テストが確かめる） |
| `trap` | `loc`・`floor`・`sign` 前触れ・`safe` 正しい手・`wrong` 誘う手・`stat`・`diff`・`dmg`・`spring`・`dodge`・`avoid`・`find` | その冒険で初めてその階に着くと出来事 `kn_trap_<loc>_<floor>` になる。選択肢は「正しい手／足元と壁を調べながら進む（判定）／誘う手」を罠ごとに決まった並びで。前触れから察せるようにし、`avoid` はキャラの記憶で避けた書き方にしない |
| `apostle` | `ap`（`D.E3.LIST` の id） | 使徒の名前は書かない。守りの綻びをかけらで |

### 新しい敵に、その場で書く
- 敵のデータに `know: [{ id, text }]`（配列）を書くと、E4（`src/engine/zzz_e4_foes.js`）がデータから分かること（弱点・行動・出る時など）を足し、L1 が `fact_<敵>_<id>` として拾う。
- 癖の書きつけ（手帳の一行）は `D.KNOW.foe_<敵の id> = { kind: "foe", foe, aim, text }` を `src/data/know_l1_foes.js` の形で足す。
新しい迷宮には、ボスのいない階ごとに `trap` を足す（`src/data/know_l1_traps.js` の形）。

## 確かめること
`tests/checks/l1_know.mjs`：覚え書きの数（魔物・罠は 30 以上）と整合、書きつけがデータと食い違わない、死ぬと覚え書きと最期の様子が墓碑に残る、出来事・戦い・店の記録が残って図鑑に出る、覚えていても得をしない、罠が周回でぶれない、図鑑の数、古いセーブ。
