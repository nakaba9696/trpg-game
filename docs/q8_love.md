# 節目・好感度・恋人の条件（Q8）

持ち主の声：
- 「ゴブリンとちょっと旅しただけで END になった」──死んだのではなく、ゴブリンの仲間と仲良くなったら「旅を終わりますか」と出た
- 「仲間と仲良くなるのが早すぎる」「仲間 END は恋人と結婚したらにして」
- 「恋人になるにはキャラによりますが、基本的に好感度のほかに条件をつけて。街でだべってるだけでどんどん好感度上がるので」
- 「『その人が嫌うことをしていない』は厳しすぎる。殺人をしていない、などの条件であればいい」

## 1. 節目（`src/engine/ending_m6.js`・`src/data/epilogue_m6.js`）
- その場で「ここで物語を終える／旅を続ける」を尋ねるのは、**その冒険の目的の終点だけ**（使徒を討つ・伝説の剣・王・大富豪・自分で決めた区切り）。光の壁は今までどおり出来事の中で尋ねる。
- ほかの節目（騎士・領主・小金・歌になる・一年・東の果てから・仲間との終わり・連れ合いとの暮らし）は尋ねない。記録に「（節目の名）ここで旅を終えることもできる、とふと思った。」と一行だけ出し、人物の表の「物語を終える」から選べる。
- 仲間との終わり（`bond`「焚き火の向こう」）は、**恋人と結ばれた（M10 の間柄 "wed"）ときだけ**。好感度 90 の条件は外した。文の {comp} は連れ合いの名前。
- 古いセーブで尋ねている途中（`S.m6.pending`）でも、そのまま答えられる。

好感度で開く話題（身の上の 6 話目は +60）・恋の筋の段（告白 +50・求婚 +62）・M10 の告白（bond 74）・求婚（bond 80）の線は変えていない。届く日が遅くなっただけで、出なくなったものは無い（恋仲になった人の数は 38 → 26／30 回）。

## 3. 恋人になる条件（`src/data/q8_love.js`・`src/engine/zzzzzzz_q8_love.js`）

## 4. 恋人・結婚の前の頼みごと（`src/data/q8_love_quests.js`・`src/engine/zzzzzzz_q8_quests.js`）
持ち主の声「恋人、結婚までにそれぞれ依頼をこなす必要がある認識です」。
- 恋人の前に、その人の頼みごと（C9。`D.Q9`）の**前半**（段の数の半分。切り上げ）を済ませる。上の表の「聞いている話」は、これに置き換えた（ほかの条件は残す）。
- 結婚の約束（求婚・約束）の前に、その人の頼みごとの**結末**まで済ませる。
- 好感度が足りていても、頼みごとが済んでいなければ告白・求婚の出来事は出ない。ほかの道から来たときは「言いかけた言葉を飲みこんだ。まだ片付いていないことがある、という顔だ。」と先送りになる。
- 古いセーブで約束・連れ合いまで進んでいる仲は、そのまま。格の違う相手（M11）は続き物そのものが頼みごとの形なので掛けない。
