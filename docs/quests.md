# 仲間の頼みごと（C9）

持ち主の声：「冒険で楽しいのは魅力的なキャラとの掛け合い。キャラの解像度を上げたい」

仲間 48 人それぞれに、**その人の身の上と結びついた頼みごと（個人の続き物）**がある。信頼が上がると、一人につき 3〜5 段で開く。最後の段の選び方で結末が決まり、その人が変わる。**全部データで動く（Claude を呼ばない）。**

- 仕組み：`src/engine/zzzzzz_c9.js`（`G.q9`）
- 中身：`src/data/quest_c9_<群>.js`（`D.Q9[人の id]`）
- 確認：`tests/checks/c9_quests.mjs`

## 遊び方の流れ
1. **頼まれる**：その人の身の上を二段目まで聞いていて、好感度が段の `min` に届くと、「話す」の一覧に頼みごとの段が出る（話題。種類は「相談」）。返すと段が開き、覚えていること（memo）に行き先が一行残る。前の段を済ませた日のうちは、次の段は頼まれない。
2. **行き先へ**：その人を連れて行き先（`at`）に着くと、行動に「頼みごと」の欄が出る（「〇〇の頼み：見出し」）。選ぶと一手番を使い、出来事が始まる。
3. **出来事**：解き方 2〜3（判定・戦い）と、判定なしの道が一つ。ほかの仲間（`mate`）が一党にいると、地の文が一つ足され、その仲間の選択肢が出る（選ぶと二人の間柄が動く。K7）。判定に失敗しても段は進む（文と手応えが違う）。戦いに負けて逃げたときだけ、段はそのまま残る（もう一度挑める）。
4. **結末**：最後の段の結果ごとに結末（`end`）が決まる。結末は 2 つ以上。その人が変わる：
   - ひとこと（M2 の `talk`）・話しかけたときの一言（`greet`）が、結末のものになる
   - 話題（`topics`）：結末のあとにだけ出る身の上の続き
   - 掛け合い（`banter`）：結末のあとにだけ起きる
   - 能力（`power`・`dmg`・`heal`・`fire`・才 `t`）
   - 人生の物語（M6）の一行（`line`）。物語の最期の前の段落に書き足す（一党にいる人を先に、二人まで）
   - 年表に一行・図鑑（人物の頁）に「頼みごとの結末」が残る（冒険をまたいで。`G.P.q9`）。まだ見ていない結末の数も出るので、周回で別の結末を見る楽しみになる

## 死んで覚える（周回の手がかり）
持ち主の方針：「何度も遊んで、死んで覚える感じにしたい。有利なこと・得することを徐々に覚えていって冒険をしていく」
- 頼みごとの段で失敗してよい。痛い失敗（`hp: -6` 以下。HP が少なければ死ぬ）を一人一つ以上。
- **覚え書きの元（`hint`）**：結果（ok・ng・win）や結末に一行。周回で知っていれば、よい結末に行ける手がかり（どこで誰に会うか、何を持っていくか、どの道が危ないか）。見たこと・聞いたことだけで書く。当てはめると、今の冒険の memo に「覚え書き：…」、冒険をまたいで `G.P.q9notes` に残り、次の冒険でその段を頼まれたとき「前の冒険の覚え書き：…」として memo に出る。図鑑の人物の頁にも出る。冒険をまたぐ覚え書きの仕組み（L1）が、この `hint` を拾える。
- 結末ごとに、そこへ行く手がかりの `hint` を一つ以上（最後の段のその結末の結果か、`ends[k].hint`）。一人 4 つ以上。
- **持っていく物（`need: { item }`）**：その物を持っているときだけ出る選択肢（選ぶと渡す）。一人一つ以上。何を持っていけばよいかは、前の段の `hint` で知れるようにする。

## データの形
```js
// src/data/quest_c9_<群>.js
(function (G) {
  const D = (G.data = G.data || {});
  D.Q9 = D.Q9 || {};
  D.Q9.dil = {
    title: "取り立ての冬",                // 頼みごとの名（図鑑・年表に出る）
    steps: [                              // 3〜5 段
      {
        min: 10,                          // 好感度（F3 の −100〜+100）。書かなければ 10・25・40・55・65
        ask: {                            // 話題（頼まれる）。口調は talk_<id>.js に合わせる
          title: "爺さんの本の行方", text: ["「……」", "地の文"],
          replies: [{ tone: "earnest", label: "引き受ける", text: "「……」", aff: 3 }, { tone: "tease", label: "…", text: "…", aff: 2 }], // 2〜3 個。どれを選んでも段は開く

                                          //   か { foe: "banditboss", name: "隻眼のロッソ" }（名のある敵）
        title: "港の役所の写し",           // 出来事の見出し（行動の欄にも出る）

      },

      { /* 最後の段：結果（ok・ng・win）に end: "結末の key" を必ず書く */ },
    ],
    ends: {
      expose: {
        name: "暴く",                       // 図鑑・年表に出る結末の名
        codex: "図鑑に添える一文（見たことだけ）",

        aff: 12,                            // 好感度（既定 12）
      },
      deal: { /* … */ },
    },
  };

```
- 段の結果に書けるもの：出来事の結果と同じ（`text`・`hp`・`gold`・`item`・`memo`・`aff`・`fame`・`grow` など）。`aff` を書かなければ、その人の好感度が段ごとに +6。
- 文の差し込み：`{n}` 頼んだ人・`{m}` その段のほかの仲間・`{you}` 主人公の名前。

## 書き方の決まり
- **身の上と結びつける。** その人の `past`・`life`（`secret`・`keep`）・身の上の話題（`talk_<id>.js` の `past`）・相談（`ask`）・出来事（`events_c?.js`）から筋を取る。仇・故郷・失くした物・昔の仲間・家族・夢・秘密。答え合わせはしない（断片で。真相を語らせない）。
- **結末でその人が変わる。** 救う／許す／討つ／見逃す。どれが正しいとは書かない。結末ごとに、その人の台詞・話題・能力・終わり方が違う。
- **ほかの仲間が絡む段を一つ以上。** 相性（`note.pairs`・掛け合い）に沿って。段ごとに別の仲間でもよい（その仲間がいないときは、その選択肢が出ないだけ）。
- **恋の段は書かない**（R2 が書く）。恋の相手の人でも、頼みごとは恋と別の筋。
- **18 歳未満・子どもの姿の人**は、それに合った頼みごと（家族・友だち・眠る前のこと・見送り）。酒・色恋・残酷な殺しは筋にしない。
- 文は日本語・ゲームブック風（[lore/voice.md](lore/voice.md)）。地の文は二人称か三人称で、叫ばない（「！」は台詞の中だけ）。説明役にしない。性的な描写はしない。作品名・他作品の名は書かない。書かない言葉（`tests/checks/c9_quests.mjs` の `BANNED`）を使わない（「胸」は「度胸」「胸に抱える」でも引っかかる）。
