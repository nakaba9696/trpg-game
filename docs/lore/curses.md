# 代償の力・正気・獣憑き・明けずの町・使徒と生贄

この世界で強い力を得るには、何かを差し出さなければならない。二振りの剣も、古い遺物も、魔人の血も、使うたびに持ち主から何かを奪う。力を得るほど、人間らしさから遠ざかる。

> このファイルはレーン D（世界観）が管理する（D2）。失われた王国ロゥムと古言は [history.md](history.md)、神々と魔王は [gods.md](gods.md)、十三魔人は [majin.md](majin.md)。
> **M5（正気・代償つきの力・獣の病）の子はここを元に作る。** 数値は案。釣り合いを見て変えてよい。セーブの形（`G.S`）に項目を足すときは、古いセーブで項目が無くても動くように（CLAUDE.md）。
> 今のゲームにある状態異常は「毒」「呪い」（`S.conds`）。「呪い」は判定に −5 で、教会の治療で祓える。下の案は、これとは別の、祓えない・積み重なる代償として書いている。

## 1. 二振りの剣の代償

二振りに代償を付けるかは、推しの案「軽めに付ける」で進める（変えるなら #39）。二振りは対になっている。**ヴォルグリムは他人とのつながりを喰い、白夜は持ち主自身を削る。** どちらも、魔人の絶界を斬るたびに代償が深くなる。

### 魔剣ヴォルグリム ――「縁（えにし）喰い」
- **何を奪うか**：持ち主と他人のつながり（仲間の信頼、覚えている人の顔、年表の思い出）。ヴォルグリムは混沌の神ネフィリアの剣なので、「番狂わせ」の燃料として、持ち主の人生の筋書きを少しずつ食べる。
- **剣の言い分**：「タダで魔人が斬れると思ったか？ 俺は腹が減るんだよ。お前の友達の一人や二人、安いもんだろ」
- **段階（案）**：絶界を斬った回数、または強い技を使った回数で深くなる。
  1. **空腹**（持った直後）：夜、剣がひとりごとを言う。仲間の好感度が少し上がりにくい。
  2. **つまみ食い**：年表の古い一行が、ときどき**黒塗り**になる（「――――を覚えていない」）。仲間の名前を一度呼び間違える。
  3. **食事**：絶界を斬るたびに、仲間の一人の好感度が大きく下がる。仲間がいなければ、酒場の顔なじみがあなたを忘れる。
  4. **満腹**：仲間が理由もなく去る、または裏切る。代わりに、ヴォルグリムの攻撃が強くなる。剣が妙に優しくなる（これが一番怖い）。
- **まぬけなところ**：本人は美食家を気取っているが、食べた思い出の味をいちいち品評する（「この初恋はしょっぱいな」）。暴食の魔人ゴルモアとは、話が合いそうで合わない。
- **ゲームでどう使うか**：
  - 仕組み：`S.volgrimHunger`（案。0〜）。絶界を斬る・呪われた技を使うと +1。段階ごとに上の効果。年表の黒塗りは、年表の行に印を付けて描くときに伏せ字にするだけでよい。
  - 戦闘の技（案）：「喰らわせろ」――ヴォルグリムに縁を差し出して、一撃の威力を倍にする（仲間の好感度か、年表の一行を失う）。
  - 出来事（案）：「剣の食べ残し」――宿で眠ると、黒塗りになった思い出の夢を見る。取り戻す（魔力・難しい：黒塗りが一行戻り、剣が不機嫌になる）／剣に食べさせる（判定なし：HP 全快）。

### 聖刀白夜 ――「白化（はっか）」
- **何を奪うか**：持ち主自身の熱（痛み・眠り・涙・笑い）。白夜は、月を喰うもの（宵姫）を「封じる」ための刀。斬るたびに、持ち主の中の何かを封じてしまう。
- **段階（案）**：
  1. **白い髪**：髪に白い筋が入る。夜目が利く。
  2. **痛まない**：傷の痛みを感じなくなる。HP が 0 に近くても判定の不利がない（あれば）。代わりに毒に気づかない（毒の表示が遅れる、など）。
  3. **眠らない**：眠れなくなる。宿で休んでも HP の戻りが少ない。ユラの夢にも出られない（夢の出来事が起きない）。
  4. **笑わない**：魅力の判定に大きな不利。酒場の出来事で、周りが気味悪がる。
  5. **鞘になる**：持ち主そのものが「封印」になる。宵姫を封じ直せるが、本人はもう人ではない（終わり方の一つ）。
- **秩序の神ソラスとの関わり**：白夜で絶界を斬る前に「誓い」を立てると、代償が一段軽くなる。ただし誓いを破ると、一度に二段進む。
- **ゲームでどう使うか**：
  - 仕組み：`S.byakuyaWhite`（案。0〜5）。絶界を斬ると +1。
  - 出来事（案）：「月の見えない夜」――白化が進んだ者は、新月の夜に自分の影を見失う。探す（知力）／放っておく（判定なし：影がないと、ミルザの糸に吊られない、という妙な得がある）。

### 二振りをそろえた者
- 魔王の絶界に届く唯一の組み合わせ。代償は**両方**かかる。つながりを喰われ、自分を削られた者だけが魔王の寝所にたどり着ける。
- 二振りは仲が悪い。ヴォルグリムは白夜を「お堅い」と罵り、白夜は一言もしゃべらない（しゃべれないのか、無視しているのかは分からない）。両方持っていると、ヴォルグリムのひとりごとが倍になる。

- **遺物の共通の決まり（案）**：装備していなくても「持っている」だけで代償が進むものがある。捨てると、数日後に荷物の中に戻っている（捨てても戻る遺物は、教会でも祓えない。ソラスの誓い・ハルガへの祈り・レヴィアンとの取引など、上位存在を通すと外せる）。
- **ゲームでどう使うか**：アイテムのデータに `curse: { kind, per }` のような印を付け、日の終わりや使うたびに代償を進める仕組みを M5 で作る。I レーンが遺物を作るときは、上の表から選ぶ。

## 3. 正気 ―― 知りすぎると狂う

この世界の本当の仕組み（神々の見世物・人間は観客席・魔王の座は神々の遊び）は、人間の頭には重すぎる。真実に近づくほど、正気が削れる。

### 正気の値（案）
- `S.sanity`（0〜100、無ければ 100 として扱う）。
- 始めは 100。職業や人物設定で少し変えてもよい（僧侶は減りにくい、魔法使いは古言を読みやすいが減りやすい、など）。

### 正気が減るきっかけ（具体例）
| きっかけ | 減る量（案） | 補足 |
|---|---|---|
| 魔人の本当の姿を見る（絶界の内側、変身、腹の中） | −10〜20 | 魔人ごとに違う。ノタリは見ても何も起きない（見るものがない） |
| 古言の碑文・ロゥムの壁画を読む | −5 | 読むと知識（フラグ）が手に入る |
| 赤い月の夜を外で過ごす | −5 | ヴェルムに覗かれている |
| 明けずの町で一日を過ごす | −3／日 | 町の外に出ると止まる |
| 使徒が人から変わる瞬間を見る | −10 | 生贄の儀式、ティンブルの人形作り |
| 仲間が死ぬ・人形にされる・食材にされる | −10 | |
| ハルガの帳面を覗く（自分の頁） | −15 | 死に日が分かる |
| 囁きの貝殻を使う | −3 | |
| ユラの夢で「目覚められない」 | −5／日 | |
| ゴルモアの料理を食べる | −5 | 美味しすぎて、人間の料理が味気なくなる |
| ルグゥの腹の中の町で暮らす | −2／日 | |
| 大失敗（ネフィリアの賽子） | −2 | 小さな狂い |

### 正気が戻るきっかけ
- 宿屋で眠る：+5（ユラの夢が出たら 0）。
- 酒場で飲み明かす：+10（金と、翌日の判定に −5）。
- 教会で懺悔する：+15（金。光天教会の司祭に秘密を一つ握られる）。
- **蒐集のレヴィアンに記憶を売る**：+30（年表の一行を渡す）。知りすぎたものを忘れれば、正気に戻る。
- 故郷の話をする（人物設定の「故郷」を使う出来事）：+10。
- 狂気の縁で「くだらないこと」をする（樽ゴブリンと飲み比べる、ドグーに話しかける）：+5。まぬけな魔物は、正気の薬。

### 段階（案）
| 正気 | 段階 | 何が起きるか |
|---|---|---|
| 100〜70 | 平静 | 何もない |
| 69〜40 | 動揺 | 記録に、ときどき**存在しない物音や人影**が書かれる（本当に敵がいるとは限らない）。魅力の判定 −5 |
| 39〜15 | 狂気の縁 | 見えないものが見える：古言の碑文が読めるようになる（知力の判定 +10）、隠された道が見える。代わりに、町の人に怖がられる（施設の値段が上がる・門前払い）。地の文が少しおかしくなる |
| 14〜1 | 崩れかけ | 行動の選択肢のうち一つが、ときどき勝手に入れ替わる。夜ごと「幕引きの夜」の夢を見る |
| 0 | 発狂 | 冒険の終わり。「明けずの町の住人になった」「影法師になった」など、墓碑に特別な一行が残る（推しの案「冒険の終わり」で進める。変えるなら #40） |

- **まぬけなところ**：狂気の縁の者にだけ、魔人たちの本当のまぬけさ（ゴルモアが甘い物の味が分からないこと、アズラグが着地で転ぶところ）が見える。狂った者の言うことを、誰も信じない。

## 4. 獣憑き（けものつき）―― 血と獣の病

正式な名は**赤牙病（せきがびょう）**。人々は「獣憑き」と呼ぶ。人が少しずつ獣に変わる病。

### 病の本当の出どころ
- 魔王ガイゼリクは、魔王に選ばれる前、**名もない巨大な獣**だった（[gods.md](gods.md)）。千年眠り続けるうちに、ガイゼリクは獣だったころの夢を見るようになった。
- その夢が、**血を通して**地上に漏れ出している。魔物界に近い土地、赤い月の夜、血を多く流した場所ほど、夢が濃い。
- 千年目（1131年）が近づき、神々が魔王を起こそうとするほど、眠りが浅くなり、夢が漏れる。**獣憑きは年々増えていく。** ユラはそれを知っていて、なんとか魔王をもう一度深く眠らせようとしている。
- 人間は誰もこれを知らない。光天教会は「罪深い者にくだる天罰」と説き、ゼファラの魔導師は「血の中の小さな虫」と言い、どちらも間違っている。

### うつり方
- 獣憑きに噛まれる・引っかかれる。
- 獣憑きの血、または赤い月の下で流れた血を飲む（酒場の「血酒」、闇商人の「力の出る薬」）。
- 明けずの町で眠る。
- 血吸いの指輪のような遺物を持つ。

### 段階（案）`S.beast`（0〜5、無ければ 0）
| 段階 | 名前 | 体と心 | ゲームでの効果（案） |
|---|---|---|---|
| 0 | 人 | ― | ― |
| 1 | 微熱 | 夜目が利く。生肉が美味そうに見える | 夜の判定に +5。宿の食事で HP の戻りが少ない |
| 2 | 爪 | 爪が伸びて硬くなる。血の匂いが分かる | 筋力の判定 +5、魅力 −5。素手の攻撃が強くなる |
| 3 | 毛と牙 | 腕に毛が生え、犬歯が伸びる。隠せなくなってくる | 町に入ると衛兵に疑われる出来事。教会・王城で門前払い。魔物に仲間と思われることがある（襲われにくい） |
| 4 | 夜の渇き | 満月と赤い月の夜に理性が飛ぶ | その夜、勝手に「狩り」の出来事が起きる（町の人を襲ったか、襲いかけて逃げたか。悪名・評判に響く）。筋力 +10、知力 −10 |
| 5 | 獣 | 人でなくなる | 冒険の終わり。墓碑に「獣として狩られた」。次の冒険で、同じ名前の獣が敵として出ることがある（推しの案で進める。変えるなら #40） |

- **進み方（案）**：うつった日から、七日ごとに一段、または血を飲む・噛まれるたびに一段。赤い月の夜は必ず一段進む。
- **治し方（案）**：
  - 段階1〜2：教会の高価な祓い（「呪い」の治療とは別。100G 以上）、腐爛の魔人モルドゥの使徒・疫医ベルナの薬（高い上に副作用）、聖刀白夜で自分の血を少し流す（白化が一段進む代わりに獣憑きが0に戻る）。
  - 段階3〜4：治らない。進みを止めることだけができる（ユラの夢の取引で「魔王をよく眠らせる手伝い」をすると、しばらく進まない）。
  - 段階5：戻れない。
- **まぬけなところ**：獣憑きの初期の者は、なぜか骨を埋めたくなる。夜中に宿の庭を掘って、主人に怒られる。月に向かって吠えたあと、恥ずかしくて一日じゅう無口になる。
- **ゲームでどう使うか**：
  - 敵（案）：**獣憑きの村人**（段1〜2、まだ人の言葉を話す。倒すと後味が悪い）、**成れの果て**（段3、群れで来る）、**夜番崩れ**（段4、獣を狩っていた者が獣になった）。
  - 出来事（案）：「骨を埋める」（判定なし・恥ずかしい）、「衛兵の検め」（段3以上で町に入ると起きる。隠す＝魅力・難しい／逃げる＝敏捷／賄賂）、「血酒」（酒場で力の出る酒を勧められる。飲むと一時的に筋力 +10、獣憑きがうつる）。

## 5. 明けずの町 ―― 夜の明けない呪われた町（新しい場所の案）

- **名前（案）**：**明けずの町カルヴァス**。
- **場所（案）**：聖王国リーヴェルと鉄血帝国ガルムントの境、凍てつく街道（`frost`）から外れた谷間。地図の空いているあたり（x 52・y 38 くらい）。つながり（案）：`frost` と 2 日、`fort` と 2 日。種別は町（施設は少なく、値段が高い）。奥に迷宮を付けてよい。
- **何があったか**：八十年前（ヴェルド暦1047年ごろ）、カルヴァスの領主**オスリック卿**の幼い娘が、流行り病で「明日の朝には死ぬ」と医者に言われた。オスリック卿は古代遺跡ロゥムから掘り出した古言の板を読み、「**朝よ、来るな**」と唱えた。
  - その夜から、カルヴァスに朝は来ていない。
  - 創世神ヴェルムは、この「娘のために朝を止めた父親」の話をたいそう面白がった。以来、カルヴァスの空には**赤い月が昇りっぱなし**になっている。神が見るのをやめないかぎり、夜は明けない。
  - 赤い月の下で八十年。町は獣憑きの巣になった。
- **今の町**：
  - 住人は八十年、同じ夜を生きている。歳は取るが、朝を知らない子どもが大人になり、年寄りになった。
  - **夜番（よばん）**：ランタンと鉈を持って、獣になった隣人を狩る町の自警団。狩っているうちに自分たちも獣憑きになる。夜番の隊長は、自分の毛深さを「生まれつきだ」と言い張っている。
  - **朝売り**：「瓶詰めの朝」を売る商人（中身はランタンの光と鶏の声を閉じ込めた、ただの瓶）。よく売れる。
  - **八十年鳴き続けている雄鶏**：朝が来ないので、鳴きやむ時を失った。声はかすれている。町の名物。
  - 町長は毎晩「明日は晴れる」と演説する。八十年分、外れている。
  - 教会は「朝は罪を清めた者にだけ来る」と説き、懺悔の料金を取っている。
- **本当のこと**：
  - オスリック卿の娘**リゼット**は、まだ生きている。朝が来ないので、死ぬはずの朝にたどり着けない。八十年、七つの子どものまま、領主館のベッドで熱にうなされている。
  - オスリック卿は、娘を守るために獣憑きを受け入れ、今は領主館を守る**巨大な獣**になっている。まだ娘の名前だけは覚えている。
  - 古言を逆に唱えれば、朝は来る。そのときリゼットは死に、八十年分の時間が町に一度に流れ込む。住人の多くは、朝日の中で塵になる。
- **ゲームでどう使うか**：
  - 場所（W レーン）：常に夜の背景（赤い月）。一日ごとに正気 −3、眠ると獣憑きのおそれ。店の値段が高いが、ここでしか買えない物（血吸いの指輪、瓶詰めの朝＝正気 +5 の気休め）。
  - 迷宮（案）：**領主館**（3階）。主は**獣になったオスリック卿**（段4〜5の強さ）。途中の主に**夜番の隊長**。
  - 出来事（案）：
    - 「朝売り」（瓶詰めの朝を買う・中身を暴く・一緒に売る）。
    - 「雄鶏の喉」（雄鶏に水をやる：判定なし・町の人に感謝される／絞める：町じゅうに恨まれる）。
    - 「リゼットの枕元」：領主館の最奥。朝を呼ぶ（古言を知っていれば・知力：町が救われ、そして滅ぶ。大きな名声と、大きな悪名）／娘に物語を読み聞かせる（魅力：何も変わらないが、リゼットが笑う。オスリック卿が見逃してくれる）／何もせず去る。
  - 敵（E レーン）：獣憑きの村人、夜番崩れ、瓶を割られて怒った朝売り（弱い、まぬけ枠）、獣になったオスリック卿。
  - トロフィー（案）：「朝を呼んだ者」「八十年目の読み聞かせ」。
- **魔人との関わり**：微睡のユラは、この町を嫌っている。魔王の夢（獣の病）が一番濃く漏れる場所だから。ユラは、朝を呼ぶ者を手伝いたがる。享楽のミルザは逆に、この町の「終わらない劇」が大好きで、ときどき見物に来る。

## 6. 人でなくなる道 ―― 使徒・生贄・変わり身

この世界では、人は簡単に人でなくなる。そして、ほとんどの場合、自分で選んでそうなる。

### 人でなくなる七つの道（一覧）
| 道 | なるもの | どうやって | 出どころ |
|---|---|---|---|
| 魔人の血を受ける | 使徒 | 魔人に誓いを立て、血を一滴飲む（下で詳しく） | 十三魔人 |
| 糸で吊られる | 人形 | ミルザとティンブルに「作り替えられる」 | 享楽のミルザ |
| 本に綴じられる | 栞 | レヴィアンの蔵書にされる | 蒐集のレヴィアン |
| 下ごしらえされる | 食材 | ゴルモアの厨房で | 暴食のゴルモア |
| 誓いを破る | 鬼 | ソラスへの誓いを破った八雲の侍が、角を生やす | 秩序の神ソラス／鬼ヶ島 |
| 獣の夢に呑まれる | 獣 | 獣憑きの五段目 | 魔王ガイゼリクの夢 |
| 台詞をもらえない | 影法師 | ヴェルムの名を呼ぶ、正気を失う | 創世神ヴェルム／ロゥム |

### 使徒になること
- **誘い**：魔人は、面白い人間・役に立つ人間・自分に似た人間を使徒に誘う。誘われるのは名誉なことで、断るのは命がけ（断り方がうまければ、かえって気に入られる）。
- **血の杯**：魔人は自分の血を一滴、杯に落とす。人間はそれを飲み、代わりに**一つを差し出す**。何を差し出すかは魔人が決める。
  - ミルザは「自由」、グラウは「負ける権利」、レヴィアンは「名前」、ザルヴェは「約束（契約書に署名）」、ゴルモアは「味覚」、アウレリアは「祈り」、宵姫は「帰る場所」、ユラは「眠り」、などなど。
- **変わり身**：使徒は、主の魔人に似てくる。ティンブルの背が曲がったのは糸を操るため、オルドのまぶたが縫われたのはユラの眠りを守るため、ギュスタがずぶ濡れなのはルグゥの腹にいるから。三年もすれば、人だったころの顔を誰も覚えていない。
- **ハルガの帳面から消える**：使徒になった者の頁は、ハルガの帳面から破り取られる。だから使徒が死んでも、**年表も墓碑も残らない**。灰になるか、主の元に還る。使徒を倒したときに落ちる「使徒の心臓」（アイテム `apostleheart`）は、飲んだ魔人の血が固まったもの。まだ脈打っているのは、主の魔人がまだ生きているから。
- **まぬけなところ**：使徒どうしには序列争いがあり、年に一度、魔物界の片隅で「使徒会」という飲み会が開かれる。誰が一番主に愛されているか、で必ずもめる。主の魔人たちは、この会があることを知らない。
- **ゲームでどう使うか**：
  - 出来事（案）：「使徒への誘い」――魔人に気に入られた（取引に成功した・玩具にされて生き延びた）者に、一度だけ起きる。受ける（能力値が大きく伸び、才能限界も上がる。代わりに冒険はそこで終わり、墓碑に「○○の使徒になった」。年表は残るが、最後の一行は破り取られている）／断る（魅力・至難：成功すると魔人に気に入られ、加護。失敗すると玩具にされる）／逃げる（敏捷）。
  - 仲間が使徒に誘われる出来事（M2 の裏切りと組み合わせる）。
  - 使徒会（案・まぬけ枠）：魔物界で、使徒たちの飲み会に紛れ込む出来事。

### 生贄の儀式
- **山の村の生贄**：断界山脈の山道の村々は、毎年、天墜の魔人アズラグに家畜か人を差し出している。選び方は**くじ**。くじの賽子は混沌の神ネフィリアの祭壇で振るので、ネフィリアは毎年これを楽しみにしている。
- **厨房への献上**：暴食のゴルモアへの生贄は、**味で選ばれる**。村々は「美味そうな」娘や若者を差し出そうと、太らせる。太らされた若者たちは、痩せようと必死で夜に走っている。
- **暁鐘会（ぎょうしょうかい）**：魔王を千年目より早く起こそうとする人間の秘密結社。「魔王が目覚めれば、選ばれた者だけが新しい世で使徒になれる」と信じている。鐘を千回鳴らし、千人の生贄を捧げれば魔王が目覚める、と教えられている。
  - 本当は、鐘の音で魔王が目覚めることはない。**ただ、眠りが浅くなり、獣憑きが増えるだけ**。
  - 裏で金を出しているのは、魔王を起こして次の魔王の座を得ようとする魔人の一体（推し：盤上のシェザール。「千年に一度の大一番」を自分の手で始めたい）。
  - **まぬけなところ**：鐘を千回鳴らす儀式で、毎回、誰かが数を間違える。まだ一度も千回に届いていない。近所から「うるさい」と苦情が来ている。
  - **ゲームでどう使うか**：生贄にされかける出来事（縄を切る＝筋力／説得する＝魅力／鐘の数をわざと間違えさせる＝知力）、暁鐘会に潜り込む続き物の出来事、鐘の塔の迷宮（案）。微睡のユラは、暁鐘会を止める者を助ける（夢で道を教える）。
