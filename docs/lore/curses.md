## 1. 二振りの剣（代償なし）

**二振りに代償は付けない**（持ち主の決定 #39「つけなくていいです」）。ゲームの効果も、文章での匂わせも入れない。二振りは、魔人の絶界を斬れる、ただ強い武器。由来と〔秘〕の設定は下のとおり。

### 魔剣ヴォルグリム
- 混沌の神ネフィリアの剣。意思を持ち、口が悪い。「番狂わせ」が好き。〔秘〕
- **まぬけなところ**：本人は美食家を気取っていて、食べてもいないものの味をいちいち品評する。暴食の魔人テルグリスとは、話が合いそうで合わない。
- 持ち主から何かを奪うことはない。奪うと脅すのは口だけ。

### 聖刀白夜
- 月を喰うもの（ベリエラ）を「封じる」ための刀。秩序の神ソラスに縁がある。〔秘〕
- 一言もしゃべらない（しゃべれないのか、無視しているのかは分からない）。夜になると「月が見たい」と泣く、という噂だけがある。
- 持ち主から何かを奪うことはない。

### 二振りをそろえた者
- かつては、魔王の絶界に届く唯一の組み合わせだった〔秘〕。魔王はもう死んでいて、今の人は魔王を知らない（D6。[world.md](world.md)）。
- 二振りは仲が悪い。ヴォルグリムは白夜を「お堅い」と罵り、白夜は一言もしゃべらない。両方持っていると、ヴォルグリムのひとりごとが倍になる。

> 以前の案（縁喰い・白化）は、持ち主の決定で取りやめた。ゲームにも文にも入れない。

## 3. 正気 ―― 知りすぎると狂う

この世界の本当の仕組み（神々の見世物・人間は観客席・魔王の座は神々の遊び。どれも〔秘〕で、プレイヤーに見せる文には書かない）は、人間の頭には重すぎる。真実に近づくほど、正気が削れる。

### 正気の値（案）
- `S.sanity`（0〜100、無ければ 100 として扱う）。
- 始めは 100。職業や人物設定で少し変えてもよい（僧侶は減りにくい、魔法使いは古言を読みやすいが減りやすい、など）。

### 正気が減るきっかけ（具体例）
| きっかけ | 減る量（案） | 補足 |
|---|---|---|
| 魔人の本当の姿を見る（絶界の内側、変身、腹の中） | −10〜20 | 魔人ごとに違う。オルネグスは見ても何も起きない（見るものがない） |
| 古言の碑文・ロゥムの壁画を読む | −5 | 読むと知識（フラグ）が手に入る |
| 赤い月の夜を外で過ごす | −5 | ヴェルムに覗かれている |
| 明けずの町で一日を過ごす | −3／日 | 町の外に出ると止まる |
| 使徒が人から変わる瞬間を見る | −10 | 生贄の儀式、ティンブルの人形作り |
| 仲間が死ぬ・人形にされる・食材にされる | −10 | |
| ハルガの帳面を覗く（自分の頁） | −15 | 死に日が分かる |
| 囁きの貝殻を使う | −3 | |
| ベルファスの夢で「目覚められない」 | −5／日 | |

| ガルメドの腹の中の町で暮らす | −2／日 | |
| 大失敗（ネフィリアの賽子） | −2 | 小さな狂い |

### 正気が戻るきっかけ
- 宿屋で眠る：+5（ベルファスの夢が出たら 0）。
- 酒場で飲み明かす：+10（金と、翌日の判定に −5）。
- 教会で懺悔する：+15（金。光天教会の司祭に秘密を一つ握られる）。
- **忘れ水のルアマリスに記憶を売る**：+30（年表の一行を渡す）。知りすぎたものを忘れれば、正気に戻る。
- 故郷の話をする（人物設定の「故郷」を使う出来事）：+10。
- 狂気の縁で「くだらないこと」をする（樽ゴブリンと飲み比べる、ドグーに話しかける）：+5。まぬけな魔物は、正気の薬。

## 4. 獣憑き（けものつき）―― ひとりの使徒だけが持つ病

正式な名は**赤牙病（せきがびょう）**。人々は「獣憑き」と呼ぶ。人が少しずつ獣に変わる病。

> **M9 #103 で形を変えた（持ち主の決定、#96・#99）。** 「獣の病はなしでいいです。使徒がもっている特殊な病気にしてください。その使徒にあわなければ大丈夫だと思います」。
> 獣憑きは、**腐爛の魔人セグリトスの使徒・疫医ベルナだけが持つ病**。ふつうの敵（人狼・獣憑きの者たち）に噛まれても、血を飲んでも、うつらない。ベルナに会わなければ、一生かからない。

### 病の本当の出どころ〔秘〕
- ベルナは元ゼファラの医術師。疫病の町を救う薬を求めて腐れ庭園に入り、セグリトスの血の杯を飲んだ。差し出したのは「自分の体」。セグリトスは庭師なので、使徒の体を**苗床**にした。
- セグリトスは、古い獣の血の染みた土（魔王ガイゼリクが獣だったころの血だという。[gods.md](gods.md)）から拾った一粒の種を、ベルナの血の中に植えた。それが赤牙病。**この種は、ベルナの体の中でしか芽を出さない。** 獣になった者の血や牙からは、もう次の者にうつらない（花は咲くが、種は結ばない）。
- ベルナは疫病（セグリトスの甘い匂いの病。M4 の「疫病」）の出た町を回り、よく効く薬を高く売る。薬は本当に疫病を治す。ただ、ときどき、薬といっしょにベルナの血が入る。ベルナは帳面に町の名前と数を書きつけ、どの町で何人が獣になったかを数えている。善意か研究かは、ベルナ本人にも分からない。
- だから獣憑きは「疫病のあとに出る」。人は順番を取り違え、「疫病がこじれると獣になる」「噛まれるとうつる」と言う。光天教会は「罪深い者にくだる天罰」と説き、ゼファラの魔導師は「血の中の小さな虫」と言う。どれも少しずつ外れている。
- 獣憑きが増えているのは、ベルナがよく働いているから。ベルナの帳面の数字は、年々よくなる（D6：魔王の眠りとは関わらない。魔王はもういない）。
- **獣人とは別もの**：獣人（狼・狐などの姿の種族。[life.md](life.md) 9.）は生まれつきの種族で、病ではない。獣人は獣憑きと一緒にされるのを何より嫌う。「獣人は獣憑きにかからない」という噂があるが、本当かどうかは書かない。

### うつり方（ゲーム）
- ベルナと戦って傷を負う（敵 `e2_berna` の `plague`。一度の戦いで一段まで）。
- 腐れ庭園の天幕で、検体に志願する（針を刺される）。仮面に手を伸ばして手首をつかまれる。
- 腐れ庭園の天幕の裏の針に触れる（出来事 `m9_needles`）。
- 疫病の町で、嘴の仮面の医者の薬を買う（出来事 `m4_plague_mask`。ときどき）。
- **うつらないもの**：人狼・獣憑きの村人・成れの果て・夜番崩れ・聖都の獣の司祭・前の冒険の獣に噛まれる。酒場の赤い酒・聖餐の血を飲む（筋力が付き、正気が削れるだけ）。血吸いの指輪を持つ（かかっている者の病を早めるだけ）。病の者に触れる（檻の男）。
- 表と文は `src/data/m9_plague.js`、仕組みは `src/engine/m9_plague.js`（うつる）と `src/engine/sanity_m5.js`（進む・症状・祓い・終わり）。確かめは `tests/checks/m9_plague.mjs`。

## 5. 明けずの町 ―― 夜の明けない呪われた町（新しい場所の案）

- **名前（案）**：**明けずの町カルヴァス**。
- **場所（案）**：聖王国リーヴェルと鉄血帝国ガルムントの境、凍てつく街道（`frost`）から外れた谷間。地図の空いているあたり（x 52・y 38 くらい）。つながり（案）：`frost` と 2 日、`fort` と 2 日。種別は町（施設は少なく、値段が高い）。奥に迷宮を付けてよい。
- **何があったか**：八十年前（1047年ごろ）、カルヴァスの領主**オスリック卿**の幼い娘が、流行り病で「明日の朝には死ぬ」と医者に言われた。オスリック卿は古代遺跡ロゥムから掘り出した古言の板を読み、「**朝よ、来るな**」と唱えた。
  - その夜から、カルヴァスに朝は来ていない。
  - 創世神ヴェルムは、この「娘のために朝を止めた父親」の話をたいそう面白がった。以来、カルヴァスの空には**赤い月が昇りっぱなし**になっている。神が見るのをやめないかぎり、夜は明けない。
  - 赤い月の下で八十年。町は獣憑きの巣になった。はじまりは、娘の熱の薬を売りに来た嘴の仮面の医者（疫医ベルナ。使徒は年を取らない）。オスリック卿は、娘に飲ませる前に自分で毒見をした。
- **今の町**：
  - 住人は八十年、同じ夜を生きている。歳は取るが、朝を知らない子どもが大人になり、年寄りになった。
  - **夜番（よばん）**：ランタンと鉈を持って、獣になった隣人を狩る町の自警団。狩っているうちに自分たちも獣憑きになる。夜番の隊長は、自分の毛深さを「生まれつきだ」と言い張っている。
  - **朝売り**：「瓶詰めの朝」を売る商人（中身はランタンの光と鶏の声を閉じ込めた、ただの瓶）。よく売れる。
  - **八十年鳴き続けている雄鶏**：朝が来ないので、鳴きやむ時を失った。声はかすれている。町の名物。
  - 町長は毎晩「明日は晴れる」と演説する。八十年分、外れている。
  - 教会は「朝は罪を清めた者にだけ来る」と説き、懺悔の料金を取っている。
- **本当のこと**：
  - オスリック卿の娘**リゼット**は、まだ生きている。朝が来ないので、死ぬはずの朝にたどり着けない。八十年、七つの子どものまま、領主館のベッドで熱にうなされている。
  - オスリック卿は、毒見をした薬で獣憑きになり、今は領主館を守る**巨大な獣**になっている。まだ娘の名前だけは覚えている。
  - 古言を逆に唱えれば、朝は来る。そのときリゼットは死に、八十年分の時間が町に一度に流れ込む。住人の多くは、朝日の中で塵になる。
- **ゲームでどう使うか**：
  - 場所（W レーン）：常に夜の背景（赤い月）。一日ごとに正気 −3。店の値段が高いが、ここでしか買えない物（血吸いの指輪、瓶詰めの朝＝正気 +5 の気休め）。
  - 迷宮（案）：**領主館**（3階）。主は**獣になったオスリック卿**（段4〜5の強さ）。途中の主に**夜番の隊長**。
  - 出来事（案）：
    - 「朝売り」（瓶詰めの朝を買う・中身を暴く・一緒に売る）。
    - 「雄鶏の喉」（雄鶏に水をやる：判定なし・町の人に感謝される／絞める：町じゅうに恨まれる）。
    - 「リゼットの枕元」：領主館の最奥。朝を呼ぶ（古言を知っていれば・知力：町が救われ、そして滅ぶ。大きな名声と、大きな悪名）／娘に物語を読み聞かせる（魅力：何も変わらないが、リゼットが笑う。オスリック卿が見逃してくれる）／何もせず去る。
  - 敵（E レーン）：獣憑きの村人、夜番崩れ、瓶を割られて怒った朝売り（弱い、まぬけ枠）、獣になったオスリック卿。
  - トロフィー（案）：「朝を呼んだ者」「八十年目の読み聞かせ」。
- **魔人との関わり**：逆夢のベルファスは、この町を嫌っている。開きっぱなしの覗き窓（赤い月）の下では、眠る者の夢がいちばん荒れるから（獣憑きの種もいちばんよく育つ）。ベルファスは、朝を呼ぶ者を手伝いたがる。微笑のカルマトスは逆に、この町の「終わらない劇」が大好きで、ときどき見物に来る。

## 6. 人でなくなる道 ―― 使徒・生贄・変わり身

この世界では、人は簡単に人でなくなる。そして、ほとんどの場合、自分で選んでそうなる。

### 人でなくなる八つの道（一覧）
| 道 | なるもの | どうやって | 出どころ |
|---|---|---|---|
| 魔人の血を受ける | 使徒 | 魔人に誓いを立て、血を一滴飲む（下で詳しく） | 十三魔人 |
| 糸で吊られる | 人形 | カルマトスとティンブルに「作り替えられる」 | 微笑のカルマトス |
| 本に綴じられる | 栞 | ルアマリスの蔵書にされる | 忘れ水のルアマリス |
| 下ごしらえされる | 食材 | テルグリスの厨房で | 灼け口のテルグリス |
| 誓いを破る | 鬼 | ソラスへの誓いを破った八雲の侍が、角を生やす | 秩序の神ソラス／鬼ヶ島 |
| 獣の病に呑まれる | 獣 | 獣憑きの五段目 | 疫医ベルナの血（種は古い獣の血の土から） |
| 台詞をもらえない | 影法師 | ヴェルムの名を呼ぶ、正気を失う | 創世神ヴェルム／ロゥム |
| 異形を体に入れる | 化け物 | 王国の研究所で異形の骸や力を移される。異形の骸の武具を長く使う | 王国に雇われた博士・帝国の女軍師の部隊（D4） |

### 異形を体に入れること（D4 で追加。持ち主のメモの「研究所」から）
- **王国の研究所**〔進〕：聖王国に雇われた博士が、討たれた異形の骸と、生きた異形から削った力を研究している。数十年先の人間のためだと言い、倫理を気にしない。研究所では、捕まった人・志願した兵・罪人が、異形の力を移されて**化け物**に変わる。国のために尽くしてきた実直な隊長が、研究所で真実を知って逃がす側に回り、自分が実験台にされた話がある。
- **異形の骸の武具**〔進〕：帝国の四騎士の女軍師の部隊が扱う、異形の骨・殻・糸・液から作った武具。強いが、使い続けると持ち主が少しずつ異形に寄る（指先が殻になる、声が出なくなる、夢に刻印が出る）。
- **ゲームでどう使うか**：異形の骸の武具を、呪われた遺物と同じ扱い（`curse`）で I レーンが作れる。研究所は続き物の出来事・迷宮の案（王国の南の研究者の都の地下）。
- 明かす段階：研究所があること（**断片**〔進〕）／異形の武具の代償（体験で分かる）。

### 使徒になること
- **誘い**：魔人は、面白い人間・役に立つ人間・自分に似た人間を使徒に誘う。誘われるのは名誉なことで、断るのは命がけ（断り方がうまければ、かえって気に入られる）。
- **血の杯**：魔人は自分の血を一滴、杯に落とす。人間はそれを飲み、代わりに**一つを差し出す**。何を差し出すかは魔人が決める。
  - カルマトスは「自由」、エンバルダは「負ける権利」、ルアマリスは「名前」、ドレイゼは「約束（契約書に署名）」、テルグリスは「味覚」、ユヴァリエは「祈り」、ベリエラは「帰る場所」、ベルファスは「眠り」、などなど。
- **変わり身**：使徒は、主の魔人に似てくる。ティンブルの背が曲がったのは糸を操るため、オルドのまぶたが縫われたのはベルファスの眠りを守るため、ギュスタがずぶ濡れなのはガルメドの腹にいるから。三年もすれば、人だったころの顔を誰も覚えていない。
- **ハルガの帳面から消える**：使徒になった者の頁は、ハルガの帳面から破り取られる。だから使徒が死んでも、**年表も墓碑も残らない**。灰になるか、主の元に還る。使徒を倒したときに落ちる「使徒の心臓」（アイテム `apostleheart`）は、飲んだ魔人の血が固まったもの。まだ脈打っているのは、主の魔人がまだ生きているから。
- **まぬけなところ**：使徒どうしには序列争いがあり、年に一度、魔物界の片隅で「使徒会」という飲み会が開かれる。誰が一番主に愛されているか、で必ずもめる。主の魔人たちは、この会があることを知らない。
- **ゲームでどう使うか**：
  - 出来事（案）：「使徒への誘い」――魔人に気に入られた（取引に成功した・玩具にされて生き延びた）者に、一度だけ起きる。受ける（能力値が大きく伸び、才能限界も上がる。代わりに冒険はそこで終わり、墓碑に「○○の使徒になった」。年表は残るが、最後の一行は破り取られている）／断る（魅力・至難：成功すると魔人に気に入られ、加護。失敗すると玩具にされる）／逃げる（敏捷）。
  - 仲間が使徒に誘われる出来事（M2 の裏切りと組み合わせる）。
  - 使徒会（案・まぬけ枠）：魔物界で、使徒たちの飲み会に紛れ込む出来事。

### 生贄の儀式
- **山の村の生贄**：断界山脈の山道の村々は、毎年、天墜の魔人ヴァルグレアに家畜か人を差し出している。選び方は**くじ**。くじの賽子は混沌の神ネフィリアの祭壇で振るので、ネフィリアは毎年これを楽しみにしている。
- **厨房への献上**：灼け口のテルグリスへの生贄は、**味で選ばれる**。村々は「美味そうな」娘や若者を差し出そうと、太らせる。太らされた若者たちは、痩せようと必死で夜に走っている。
- **暁鐘会（ぎょうしょうかい）**：魔王を千年目より早く起こそうとする人間の秘密結社。「魔王が目覚めれば、選ばれた者だけが新しい世で使徒になれる」と信じている。鐘を千回鳴らし、千人の生贄を捧げれば魔王が目覚める、と教えられている。
  - 本当は、鐘の音で魔王が目覚めることはない。眠っている者はもういない（D6。魔王は死んでいる）。鐘が千回鳴っても、何も起きない。今の会員は「魔王」という言葉も知らず、遺跡の古い祈祷文の「眠っている古いお方」を勝手に読んでいる。
  - 裏で金を出しているのは、千年目を口実に盤を広げたい魔人の一体（推し：百面のディエラン。退屈しのぎに、人間が鐘の数を数え間違えるのを眺めている）。
  - **まぬけなところ**：鐘を千回鳴らす儀式で、毎回、誰かが数を間違える。まだ一度も千回に届いていない。近所から「うるさい」と苦情が来ている。
  - **ゲームでどう使うか**：生贄にされかける出来事（縄を切る＝筋力／説得する＝魅力／鐘の数をわざと間違えさせる＝知力）、暁鐘会に潜り込む続き物の出来事、鐘の塔の迷宮（案）。逆夢のベルファスは、暁鐘会を止める者を助ける（夢で道を教える）。
