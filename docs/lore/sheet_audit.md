# スプレッドシートとの突き合わせ（D8 #136）

持ち主の声（2026-10-01）：「世界観ごちゃまぜ過ぎかも。スプレッドシートを主に参照して広げてください」。

持ち主のスプレッドシート「RPG世界観メモ」の5枚（**世界観**・**地図＋都市設定**・**年表**・**使徒リスト**・**キャラメモ**）を全部読み、`docs/lore/*.md` とゲームの文（場所・出来事・噂・人物・敵・アイテム・手引きの用語）に出てくる設定を、次の三つに分けた。

| 分類 | 意味 | 扱い |
|---|---|---|
| **1 シートにある** | シートの行にそのまま書いてあるもの | そのまま。シートと食い違っていたら、シートに合わせる |
| **2 シートを広げた** | シートの設定から自然に出てくる町の暮らし・人・出来事。または、持ち主がシートの外で決めたこと（**決**と書く） | 残す |
| **3 外から混ぜた** | シートと関係なく、よその物語の要素を寄せ集めたもの・シートと噛み合わない設定 | 削るか、シートの要素に置きかえる。この PR で直したものは **直した**、手が回らなかったものは **残り** |

- id（場所・敵・アイテム・出来事・フラグ）は変えていない（古いセーブとテストのため）。地方の名前（評判の鍵）を変えたものは、古いセーブを読むときに移す（`src/engine/d8_names.js`）。
- 「シートの元」の書き方：〔世界観〕〔地図〕〔年表 年〕〔使徒 番号〕〔キャラ 名〕。
- 入口の設定書は [world.md](world.md)（シートの5枚を軸に組み直した）。
