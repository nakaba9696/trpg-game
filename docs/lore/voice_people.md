# 仲間の「言わないこと」と手本（V16）

[voice.md](voice.md)（語りの手引き）と [voice_table.md](../voice_table.md)（一人称・呼び方・語尾の表。データは `src/data/k10_voice.js`）に添える表。仲間 53 人それぞれについて、**その人が絶対に言わないこと**を三つと、**その人らしい手本の台詞**を一〜三本。手本はすべて今ゲームにある台詞からそのまま引いた（`talk_<id>.js` の行番号つき。行は V16 時点）。無い人はいない。

- 根拠：人物の表（`c2_people.js`・`c4〜c8_people.js`・`cz_c12*_people.js` の memo・note・talk・secret）と口調の表。表に無い性格は書いていない（性格を変えない）。
- 使い方：その人の台詞を書くとき、手本と同じ温度・同じ長さを目安にし、「言わないこと」に当たる台詞を書かない。段で呼び方が変わる人（ミルレーネ・フェリクス・ブルーノ・ジークリンデ・タキマル）は [voice_table.md](../voice_table.md) の段に従う。
- 「言わないこと」は、仲間ごとの確認（`tests/checks/k10_voice.mjs`・`c18_voice.mjs`）が機械で見る一人称・呼び方・語尾の外側にある、人柄の線。機械では確かめないので、書く側がここを読む。
- 行番号は目安。文が直されてずれたら、台詞の方で探す。

## 名のある、仲間にならない人物
人物の表（`c*_people.js`）に台詞の控え（voice・memo）がある人は、そこが正。ここには仲間だけを並べた。使徒の口調は `docs/lore/majin.md` の頭の表と `e3_apostles.js` の lines、眷属は `enemies_e4_kin.js` の lines が手本になる。
