# 語りの手引き（voice）

プレイヤーに見える文（手引き・地の文・出来事・台詞・噂・アイテムの説明・覚えていること・年表・墓碑・ダイジェスト・GM の返事）を書く前に、ここを読む。
持ち主の方針（#1「情報の出し方・物語の見せ方」、#48）。設定そのものは [world.md](world.md) が正で、段階の印は〔知〕一般人が知っている／〔噂〕噂で知れる／〔進〕物語を進めて分かる／〔秘〕明かさない。プレイヤーに見える文に書いてよいのは〔知〕と、きっかけを踏んだあとの〔噂〕〔進〕だけ。暮らしの手触りは [life.md](life.md)。裏設定は [majin.md](majin.md)・[gods.md](gods.md)・[history.md](history.md)・[curses.md](curses.md)・[strata.md](strata.md)、明かす段階は [reveal.md](reveal.md)。

> レーン D が管理（U3 で作成）。これから文を書く子（U5 の導入、M2 の仲間の会話、B1 のボスの前口上、E2・V2 の直し など）は、書いたあとに下の「書いたら確かめること」を通す。

## 五つの決まり

1. **一般人は上位の存在を知らない。** 魔王・魔人の本当の格も、神々の本当の姿も知らない。神は良いものだと信じている。祈り・祭り・お守り・教会・神の名を借りた口癖が、暮らしに当たり前にある。
2. **それを説明しない。** 信仰は小物・習慣・口癖として背景に置くだけ。信仰や設定を語って聞かせる人物は出さない。
3. **一人一人に生活がある。** 通行人・宿の主・物売りは世界の説明役ではない。名前・仕事・悩み・家族・癖・その日の用事があり、あなたと関係なく暮らしている。あなたはその横を通りがかるだけ。
4. **断片で察させる。** 物の説明文・遺された手記・墓標・壊れた像・張り紙・噛み合わない証言。語らない人、はぐらかす人、知りすぎて狂った人。真相は書かない。つなげるのはプレイヤー。
5. **大いなる意志は感じさせるだけ。** 出来すぎた偶然・見られている気配・拍手のような音・答えの出ない碑文・祈りへの気まぐれな応え。「見世物」「観客」「客席」「舞台」「台本」、神々が世界を眺めている、とは**書かない**（裏設定の言葉。神々がもういないこと・仕組みだけが残っていることも同じ扱い。プレイヤーに見える文には最後まで出さない）。

世界の味は変えない：人間は取るに足らない。理不尽で残酷。でも、まぬけで憎めない魔物がいて、下品な笑いがある。

## 良い例・悪い例（このゲームの文から）

### 信仰を説明する → 暮らしに置く
- ✗ 手引き「創世神ヴェルム：世界は神の見世物であり、人も魔物も魔王すら、神を退屈させないための役者にすぎない」（人が知らないはずの答えを、全知の語り手が言っている）
- ✗ 「神様は良いお方じゃ。祈れば必ず見ていてくださる」と語る老人（信仰の解説役）
- ○ 宿の女将が、出ていく客の背中に向かって、指で小さく三つの印を切る。何も言わない。
- ○ 「ソラスさまに誓って、この鍋は昨日の残りじゃないよ」（口癖。神の名は、信じているから軽く使われる）

### 設定を語る通行人 → 暮らしのある人
- ✗ 「赤い月の夜には、神様がこっちを覗いてるんだってさ」（噂の形をしているが、裏設定の要約）
- ○ 「赤い月の晩は、うちの婆さまは窓に布を掛ける。なんでかは知らねえ。子どものころからそうなんだ」
- ✗ 老人が処刑台で「白夜は鬼の島に、魔剣は竜の骨の中に眠っておる」と地図のように言い残す
- ○ 同じ手がかりを残してよいが、言い方はかけらにする（「……鬼の、島……骨の……」）。どれを信じるかはプレイヤー。

### 碑文が答えを書く → 答えの出ない碑文
- ✗ 「世界は舞台。魔王は悪役。人は観客を楽しませる道化」（答えそのもの）
- ○ 読めたのは、目の紋章の下の一行だけ。「目が離れたとき、終わる」。何が終わるのかは、削り取られている。（`events.js` の古い石碑）

### 上位の存在が自分の正体を語る → 気配と振る舞い
- ✗ 声「見ていてやろう。もっと足掻け。もっと笑わせろ」、選択肢「『見世物になる気はない』と拒む」（台詞が設定を説明している）
- ○ 虫の声がやむ。どこか高いところで、誰かが手を打つ。ひとつ、ふたつ。それから、待つような沈黙。選択肢は「『誰だ、出てこい』と空に怒鳴る」。（`events.js` の赤い月の夜）

### 覚えていること（memo）も説明しない
- ✗ 「石碑：世界は神の見世物。魔王は神が選ぶ悪役」
- ○ 「古い石碑の一行：『目が離れたとき、終わる』。続きは削られていた」（見たことだけを書く。解釈は書かない）

## 人物の作り方（通行人・宿の主・物売り）
一人につき、次のうち二つ以上を持たせる。全部を文に書く必要はない（書くのは一つか二つ）。
- **名前か呼び名**（「粉屋のオットー」「片耳の渡し守」）
- **仕事と、その日の用事**（粉袋を運んでいる、娘の縁談の返事を待っている、税の取り立てから逃げている）
- **悩み・家族・癖**（腰が痛い、息子が砦から戻らない、何でも三回数える）
- **世界との接点は、その人の暮らしの側から**：魔人・魔物・神は、その人の生活に落ちた影として出る（「砦に行った息子の手紙が、先月から来ない」）。世界の説明はしない。

台詞は、その人が**あなたに向けて説明する**のではなく、**その人の用事の途中で漏れる**ようにする。

### 今の人が知らないもの（D6）→ 昔の断片の中にだけ
今の人は「魔王」という存在そのものを知らない（〔秘〕。[gods.md](gods.md)）。昔、魔王がいて、もう死んでいる。
- ✗ 酒場の男「魔王は寝てるのか死んでるのか」、砦の兵「山の向こうには魔物の王様がいる」（今の人が知っていることになる）
- ✗ 「この壁画は、千年前に死んだ魔王の姿だ」（答え合わせ）
- ○ 遺跡の壁画：玉座の大きな獣。顔のところだけ、丁寧に削り取られている。玉座の前に、小さな影がいくつも並んでひざまずいている。
- ○ 古い祈祷文の切れ端：「……王の眠りを妨げるな……」。何の王かは書いていない。今の人は、どこかの古い国の王のことだと思う。
- ○ 夢の子ども（昔から生きている者）だけが「魔王さま」と口にする。目を合わせない。

### 正体の分からない旅人（D6）→ 何者か言わない
「灰色の古い外套の旅人」に、長く遊ぶと何度か出会う。何者かは決めない（GM も）。
- ✗ 「その旅人こそ、〇〇だった」「旅人の目が一瞬、赤く光った」（答え合わせ・正体の演出）
- ✗ 「魔物たちは、主に道を譲った」（地の文が知っている）
- ○ ゴブリンたちが道の端に寄って縮こまった。あなたにではない。あなたの少し後ろを歩いてきた旅人に。旅人は「転んだのかと思いました」と言った。
- ○ 何度会っても、向こうはあなたを覚えていない（ように見える）。会うたびに、前にも会った気がする、とだけ書く。
- 旅人の台詞は丁寧で、少しずれている（人の暮らしが珍しい）。争いは止めない。説明もしない。

## 断片の出し方
- **一つの断片で一つだけ**：一枚の張り紙・一つの墓標に、情報は一つ。
- **噛み合わない**：同じことを、人ごとに違うように言わせる（「魔王は眠ってる」「いや死んだ」「いや、起きてるから魔物が増えてる」）。どれが本当かは書かない（今の人は「魔王」を知らないので、この食い違いは古い化け物の話にする。D6）。
- **語らない・はぐらかす**：知っていそうな人ほど話を変える（「その話はよしな。……で、泊まるのかい」）。
- **知りすぎた者**：真相に近い言葉は、狂った人・死んだ人・壊れた物にだけ言わせる。筋の通った説明にしない。
- **名前は後から**：固有名詞は、はじめは呼び名で。名前は二度目、三度目に、文脈で分かる形で。

## 語り手の立ち位置
- 地の文は二人称（あなた）か三人称。語り手はこの世界の住人の目の高さにいる。神の目線で「本当は〜」と書かない。
- 「〜らしい」「〜と言われている」「〜だった気がする」はよい。「〜である（世界の真実）」は書かない。
- 導入（U5）だけは、冒険を始めるのに要ることをはっきり書く。書くのは、この世界の普通の人が知っていることだけ（[reveal.md](reveal.md) の「導入で説明すること」）。

## 語りの調子（D7 #121）
持ち主の好みは、ゲームブック風の語り（調子だけ寄せる。よその作品の名前・固有の文・用語は写さない）。上の決まり（説明しない・断片と余白・分かったことだけ載る用語説明）は、そのまま。

- **落ち着いた地の文。** 二人称（あなた）か三人称。語り手は声を張らない。「！」は叫び声の台詞にだけ。地の文の驚きは、短い文と句点で出す（「空気が変わる。」）。
- **手触りを一つ二つ、短く重ねる。** 光・音・匂い・温度・足もとの感触。形容詞を並べるより、物を一つ置く（「焼き栗の煙」「手垢で黒く光る募金箱」）。一場面に三つまで。
- **説明より描写。** 「罠がある」と書かずに、罠のある通路を描く。読んだ人が先に気づけるように置き、答えは選択肢と判定に任せる。
- **一歩ごとに小さな発見。** 探索・町歩き・階段を降りる一手ごとに、一行の何か（刻み目・骨・誰かの用事）。大事件でなくてよい。発見は、そこで終わってよい（回収しない）。
- **場面は選択肢で開く。** 出来事の本文は、選ぶ直前で止める（「……今は昼のはずだが。」）。結果の文は、選んだことの手応えと、一行の余韻。
- **静かな不穏さと、時々のおかしみ。** 怖さは言い切らずに、少しずれた細部で（「数歩行ってから振り返ると、銀貨は、さっきより少し皿の端に寄っていた」）。笑いは乾いた一言で落とす（「酒は薄かった」「歯が三本しかなかった」）。
- **台詞は少なく、残るものだけ。** 人物は一言か二言。説明の台詞を削ったぶん、その人の癖・用事を地の文に一つ置く。
- **戦いも語りで挟む。** 戦いの始まりと終わりは、数字の前後に一行の地の文（`src/data/voice_d7.js` の `D.VOICE`）。数字の行（ダメージ・金・手に入れた物）は、そのまま短く。

## 用語説明（手引き）は分かったことだけ
持ち主の方針：「世界観も物語を進めてわかったことだけ用語説明に追加していってください」。
- 手引きに**はじめから載る**のは〔知〕だけ（大陸と国・人と暮らし・魔物。`src/data/world.js` の `D.WORLD`。一覧は [world.md](world.md) 14.）。
- 世界観の項目（用語説明）は、プレイヤーが物語の中で**知ったときにはじめて**、一行ずつ書き足される（`src/data/lore_u3.js` の `D.LORE`）。開くと「手引きに書き足された：〇〇」と一行出る。
- 載せる文は、**そのとき分かったこと**だけ。「〜と誰それは言った」「〜があった」。同じ項目に食い違う行が並んでよい。真相をまとめて書く行は作らない。
- 出来事が**起きた**ときに開くのは、出来事の文を読めば分かることだけ。選んだ結果で分かることは、結果に書く。
- これから出来事・敵・場所を足す子は、その内容で開く用語を一緒に書く。書き方：
  - 出来事の結果に `lore: "<項目>:<行>"`（配列でもよい。`:<行>` を省くと最初の行）。例：`ok: { text: "…", lore: "beast:village" }`
  - 出来事そのもの（起きたら開く）は、出来事に `lore: "…"`。通行人のひとことにも `lore` が書ける。
  - 新しい項目・行は `D.LORE` に足す（`Object.assign(G.data.LORE, {...})` か、項目の `lines.push(...)`）。
  - 覚えていること（memo）に言葉が入ったら開く行は、行に `{ hint: ["言葉"] }`。
  - 他のレーンのファイルを書き換えずに付けたいときは `D.LORE_ON`（出来事・施設・場所・敵・物・フラグ・目的）。

## 書いたら確かめること
- 用語説明の行は、そのとき分かったことだけか。真相をまとめていないか。
- `git grep -n -E "見世物|観客|客席|舞台|台本|言霊" -- src` で、プレイヤーに見える文に残っていないか（`D.LORE_GM` の中と、コメントはよい）。`tests/checks/u3_voice.mjs` が同じことを確かめる。
- 神・魔王・魔人の仕組みを、説明している人物や地の文はないか。
- 今の人の口や地の文に「魔王」が出ていないか（出してよいのは昔の断片だけ）。灰色の外套の旅人を、何かの正体として書いていないか（`tests/checks/d6_walker.mjs` が確かめる）。
- 通行人は、名前か仕事か用事を持っているか。あなたに世界を説明していないか。
- 語りの調子（ゲームブック風）：地の文が叫んでいないか（「！」は台詞だけ）。説明の代わりに、手触りを一つ置いたか。語り手が教訓を言っていないか。
- memo・年表に、見たこと以上の解釈を書いていないか。
