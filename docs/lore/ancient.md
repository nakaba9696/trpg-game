# 古い文明と四つの遺跡（W12）

> 古王国ルヴェナール（古い文書では「ロゥム」）の設定を、遺跡の側から書き直したもの。土台は [history.md](history.md)（古王国・幕引きの夜）・[gods.md](gods.md)（昔の魔王・赤い月）・[strata.md](strata.md)（刻印の環・失われた技術）・[world.md](world.md)（段階の印と〔秘〕）。食い違ったら world.md が正。
> 段階の印：〔知〕一般人が知っている／〔噂〕噂で知れる／〔進〕物語を進めて分かる／〔秘〕明かさない。〔秘〕の言葉はプレイヤーに見える文に書かない（`tests/checks/u3_voice.mjs`）。
> ゲームのデータは `src/data/w12_ruins.js`（断片・仕掛け・山場・隠し部屋）、仕組みは `src/engine/w12_ruins.js`、背景は `src/ui/scene_v2_w12.js`。

## 1. 古王国ルヴェナール

### 何だったか
- 断界山脈がまだ低い丘だったころ、大陸の真ん中にあった王国。王は神官を兼ねた。〔進〕
- 神々の落とした言葉の切れ端（**古言**）を拾い集め、声に出して世界を少しだけ動かした。竜を呼び、夜を昼にする灯りをともし、言葉で動く車や船を作った。〔進〕（古言が何の切れ端かは〔秘〕。history.md）
- 碑文はたいてい**自慢**で終わる。「我らは竜を犬のように呼ぶ」。滅びの前の夜まで、自慢しかしていない。〔進〕

### なぜ栄えたか
- 古言そのものより、**古言の代償を自分で払わない仕組み**で栄えた。古言は一言ごとに、話した者の中の何か（記憶・声・影・名前）を取る〔秘〕。ルヴェナールは、その支払いを子・奴隷・竜・雇われの運び手に回した。〔進〕（支払いを回していたこと）
  - 遺跡に残るのは、その帳尻の跡：神殿の蔵に積まれた名札の束、声を納めた数だけ穴の開いた運び手の札、籤で決まる観測所の「言葉を足す番」、名を捨てて石になった関守。
- 国の要は四つあった。都の神殿（言葉を集めて王が読む）・南の火山の観測所（山の封じと月を見張る）・東の境の関（向こうの者と取引し、量り、通さない）・北の鉄の道（山の白い金属を都へ運ぶ）。四つの遺跡はその跡。

### 東の境の向こう
- 境の東（今の使徒領）には、**玉座の獣**と、その前に並ぶ**七十余りの影**がいた。ルヴェナールの民はそれを知り、恐れ、関を挟んで取引した。〔進〕（壁画・碑文で分かること）
  - 玉座の獣が何者かは〔秘〕（昔の魔王。gods.md）。見える文では、壁画の「顔の削られた玉座の獣」としか書かない。「魔王」という言葉も W12 の文には出さない。
  - 七十余りの影が今の七十二の使徒であることは、プレイヤーが**繋げる**ものとして置く（関の碑文の印が、刻印の環の外側の印と同じ形をしている、まで）。刻印の環が名簿であることは〔秘〕。
- 火山の下には、境のこちらへ迷い出た一体が、古言で**封じて**あった（history.md の「魔人の一体を封じる」）。観測所の番は、毎夜その山の声を聞き、鳴れば封じの言葉を一つ足した。〔進〕
  - 封じは、言葉を足す者がいなくなってから少しずつ緩み、504年の南の火山の大噴火（マグザレムの覚醒〔年表 504〕）で切れた。封じられていたのがマグザレムかどうかは書かない（余白。噴火の年と観測所の帳面の途切れ方が合う、まで）。

### なぜ滅びたか
- 最後の王アルダン七世は、赤い月の夜を選んで、神殿で最後の古言を唱えた。何を願ったかは〔秘〕（history.md）。観測所はその夜を王のために数えて出し、都はその夜を「民みなで喜ぶ夜」と触れ回した。〔進〕（王が赤い月の夜に神殿で最後の言葉を唱えたこと）
- その夜、**四つの要の記録が、同じ夜に止まる**。神殿の祈りの句は彫りかけで終わり、観測所の帳面には「都の合図の灯が消えた」、関の数える刻みは四人目で止まり、「向こうの灯も消えた」、鉄の道の最後の車は運び手の手が見えなくなって止まった。〔進〕（四つの断片をそろえると分かる）
- 民は一人も残らなかった。死体もない。民がどうなったか（端役にされた）は〔秘〕。遺跡では、車の座席に残った人の形の煤・名を呼ばれても返事のない影、で匂わせるだけ。
- 同じ夜、境の向こうの灯も消えた。玉座の獣が死んだことは〔秘〕。見張る者のいなくなった関を、向こうの者たちがくぐり、大陸じゅうに散った（人から見れば「ある夜、あれが来た」）。

### いまどう伝わっているか
- **一般人**〔知〕：「昔、古い国があった。ある夜、あれが来て、古い国は潰れた」。遺跡は「神々の時代のもの」。遺跡の品は高く売れる。
- **四つの断片がそろって分かること**〔進〕：順番が逆だった。あれが来て国が潰れたのではない。**国の民は、自分たちの王の祈りの夜にいなくなっていた**。境を見張る者がいなくなってから、あれは門をくぐった。古い国の人々は、あれを前から知っていた。
  - 分からないまま残すこと：王が何を願ったか／民はどこへ行ったか／向こうの灯はなぜ消えたか／玉座の獣は何者か（どれも余白）。
- **光天教会**：古言を「口にすると禍を呼ぶ」として禁じ、切れ端を禁書庫にしまう（history.md）。古王国を「神々の時代を汚した国」とも「神々に近すぎた国」とも言い、教えは定まっていない。四つの要の記録を突き合わせた者はいない（遺跡は国も教会もまたぐので、誰も全部を見ていない）。〔噂〕
- **帝国**：鉄の道を掘り直し、遺物を兵器として抱え込む。何に使われた道かには興味がない。〔知〕
- **王国**：観測所を「古い観測所」と呼び、火山の都の学者が年に一度見に行くだけ。〔知〕
- **ギルド**：刻印の環の拓本を本部に貼り、エル・ナフ遺構に発掘人を送る。断片を書き留めた冒険者の帳面は、高くは売れない。〔噂〕

## 2. 遺跡ごとの設定

どの遺跡も「なぜそこに建てたか・何に使ったか・何が起きて廃れたか」から、碑文・仕掛け・遺物・背景を出す。仕掛けは、その建物が本来していた仕事の名残で、理由の無い仕掛けは置かない。

### エル・ナフ遺構 ―― 沈んだ都の神殿
- **なぜそこに**：ルヴェナールの都の真ん中。王が神官として古言を読み上げる神殿。拾い集めた言葉は神殿の蔵に納め、王だけが読んだ。
- **何に使ったか**：祈り（言葉を読む）と、言葉の代償の帳尻（名札の蔵）。赤い月の夜だけ、天井の細い隙間から月の光が祭壇に落ちるように建ててあり、その光が祭壇の奥の王の通い路を開く。
- **何が起きたか**：幕引きの夜、王が最後の言葉を唱え、民がいなくなった。そのあと神殿は地面ごと沈み、上から土と砂が流れ込んだ（history.md）。いちばん古い遺跡として、100年に刻印の環が掘り出された〔年表 100〕。今は眷属カインが本を読み漁っている。
- **断片**（下りるほど時代が下る）：
  1. 碑文（地下1階）「入口の自慢」――竜・灯り・言葉の自慢。読める者には、余白の小さな字「言葉一つにつき、一人を蔵へ」。
  2. 遺物（地下2階）「名札の束」――蔵の名札。名の欄が空になった札が混じる。
  3. 壁画（地下2階・仕掛け「光の筋を祭壇へ」）「灯りの都」――栄えていたころの都。隅に、首に札を下げて蔵へ入る小さな人の列。
  4. 碑文（地下3階）「最後の祈り」――「赤い月の夜、王は最後の言葉を唱える。民はみな、これを喜ぶ」「喜べと言われた」。彫りかけの一画。
- **仕掛け**：光の筋（知力）。割れた鏡の板で昼の光を祭壇へ渡す。赤い月の夜の月光の代わり。
- **隠し部屋**：断片がそろうと出る古い鍵で、祭壇の下の**王の練習部屋**が開く。王が最後の夜のために言葉を練習した部屋で、壁は書き損じだらけ（「ヴェ、ヴェル、ヴェルム。噛んだ」。history.md の「王の練習帳」）。部屋の奥の窓から、地の底に沈んだ都がまるごと見える。机の上に、夜を昼にした灯りの石。
- **迷宮の作り**：W11 の大きな迷宮の一つ（[dungeons.md](dungeons.md)）。階ごとに部屋と分かれ道があり、断片は階ごとに一つ必ずある「かけらの部屋」（地下1階 碑文の間・地下2階 壁画の回廊・地下3階 祈りの間）で読む・解く・調べる。ほかの三つの遺跡は各階の行動。
- **背景**：迷宮の中は今の絵（`ruins_in`）。仕掛けを解いた先は「光の回廊」（`w12_hall_in`：鏡の光が壁画の回廊を走る）。隠し部屋は「沈んだ都を見下ろす窓」（`w12_vault_in`）。

### 灰の観測所 ―― 山の封じと赤い月の番所
- **なぜそこに**：南の火山の中腹。山の下に封じた一体の声を聞くためと、火山の上の澄んだ空で月を数えるため。
- **何に使ったか**：二つの番。山が鳴ったら封じの言葉を一つ足す（足す者は籤で決める。代償を払うのは籤に当たった者）。もう一つは赤い月の夜を数えて都に知らせること。床の大きな円盤は、月の巡りを数える暦の盤。
- **何が起きたか**：観測所は王のために、幕引きの夜を数えて出した。その夜、都の合図の灯が消え、交代が来なくなった。最後の番人は、交代を待って書き続け、今も灰で同じ一行を書いている（灰の書記）。封じは緩み、504年に山は鳴った〔年表 504〕。のちの時代、王国の者が入口に板を打ちつけた（events_w3_wild.js の「内側の板」）。
- **断片**：
  1. 碑文（地下1階）「番の規則」――「毎夜、山の声を聞き、空の月を数えよ」。読める者には「山が鳴ったら、言葉を一つ足せ。足す者は籤で決める」。
  2. 遺物（地下2階）「曇らない筒眼鏡」――覗くと今と少し違う昔の空が見える。
  3. 壁画（地下3階・仕掛け「回る床の暦を合わせる」）「赤い月の暦」――月の巡りの輪に、一つだけ赤く塗った夜。その下に冠と神殿。
  4. 碑文（地下3階）「番人の最後の記録」――「今宵、月は赤い。都の合図の灯が消えた。山は鳴らない」「交代が来ない。それでも書く」。
- **仕掛け**：回る床の暦（知力）。壁の印は月の巡りの数。赤く塗った夜に合わせると、床の真ん中が沈む。
- **背景**：仕掛けを解いた先は「星図の天井」（`w12_dome_in`：天井いっぱいの星図、真ん中の赤い月、灰の積もらない円い部屋）。

### 断界の古関 ―― 東の境の取引の関
- **なぜそこに**：今の断界山脈がまだ低い丘だったころの、ルヴェナールの東の境。向こうは玉座の獣の土地。山が高くなったのは後の時代で、関は山の中に取り残された。
- **何に使ったか**：通す・量る・数える・帰す。向こうの者がこちらへ来ないよう、こちらの者が向こうへ行かないよう、門を閉じておく。取引の日だけ門を開け、運ぶ物を秤で量って釣り合わせた。背丈の刻み目と手形の穴は、量る相手の大きさ。いちばん上は人の背丈の三倍。関守は名を捨てて石になった（名を持てば向こうの者に呼ばれるから）。
- **何が起きたか**：幕引きの夜、数える刻みは止まり、向こうの灯も消えた。門を見張る者がいなくなり、向こうの者たちは門をくぐった。石の関守だけが今も背丈を測り、出し方の分からない手形を求める（関守の石人）。
- **断片**：
  1. 碑文（地下1階）「門の上の三つの言葉」――「通す。量る。帰す」。読める者には「向こうの者はこの門より内へ来ない。我らの者は向こうへ行かない」と、刻印の環の外側の印と同じ形の印の列。
  2. 遺物（地下2階）「関守の分銅」――持つ者の大きさで重さが変わる。
  3. 壁画（地下3階・仕掛け「秤を釣り合わせる」）「玉座の獣と七十余りの影」――門の向こうに顔の削られた玉座の獣、その前に並ぶ七十余りの影。門のこちらで冠の男が秤に物を載せている。
  4. 碑文（地下4階）「関守の最後の刻み」――「関守は名を持たない。名を持てば、向こうに呼ばれる」。読める者には「赤い月。誰も通らない。向こうの灯も消えた。門を閉じる手が、もう無い」。
- **仕掛け**：重さの扉の秤（筋力）。取引の秤の名残。釣り合えば扉が開く。
- **背景**：仕掛けを解いた先は「取引の大広間」（`w12_gate_in`：人の三倍の高さの大扉が開き、天井の高い広間の奥に、上へ続く巨きな階段）。

### 古い鉄の道 ―― 白い金属を都へ運んだ道
- **なぜそこに**：北の山（今の鉱山の都カースヴェルグ）で、錆びない白い金属が採れた。都の灯りと車の体はこの金属で作る。鉄の道は山の腹から都へ、まっすぐ一本。
- **何に使ったか**：言葉で動く車。運び手は声を一つ納めて車を一日動かした（声が代償）。声を払い尽くした運び手のために、乗り場は声を使わずに動くよう、水の栓で扉と車を動かす作りになっている。
- **何が起きたか**：幕引きの夜、都へ向かう最後の車が坂の途中で止まった。運び手も客も消え、座席に人の形の煤だけが残った。のちに帝国が掘り直し、機械の部隊が坑道の地喰いを追い、九五八年に坑道を閉じた（locations_w4.js）。
- **断片**：
  1. 碑文（地下1階）「乗り場の札」――「山の白い鉄を都へ。都の灯を山へ」。読める者には「運び手は声を一つ納めて、車を一日動かす」。
  2. 壁画（地下2階・仕掛け「水の栓で台車を動かす」）「口を結んだ運び手たち」――白い金属を積んだ車、空の竜、口に一本の線を引かれた運び手。
  3. 遺物（地下2階）「穴だらけの札」――運び手の札。声を納めた数だけ穴がある。
  4. 碑文（地下3階）「運転台の書きつけ」――「赤い月。都へ向かう最後の車。合図の灯が消えた」「車が止まった。わたしの手が把手を握れない。手が見えない」。
- **仕掛け**：水の栓（敏捷）。声の無い運び手のための乗り場の作り。
- **背景**：仕掛けを解いた先は「待合の間」（`w12_station_in`：白い金属の車が並ぶ地下の乗り場。天井の灯の石がまだ少し光る）。

## 3. 断片の並べ方
- どの遺跡も、**下りるほど時代が下る**：浅い階は栄えた頃（自慢・規則・札）、中の階はその仕組みと代償（名札・籤・秤・声の札）、深い階は赤い月の夜（祈り・最後の記録・最後の刻み・運転台）。
- 遺跡をまたいで読むと、**同じ夜**が四か所から見える。神殿の彫りかけの祈り、観測所の「都の合図の灯が消えた」、関の「向こうの灯も消えた」、運転台の「手が見えない」。
- 全部そろうと、山場（`D.W12_SECRET`）で「順番が逆だった」ことが分かる。分かるのは一端だけで、王の願い・民の行方・玉座の獣・向こうの灯のわけは書かない。
- 碑文は古文字読み（k1_letters）が無いと一行目しか読めない。一行目は表の顔（自慢・規則）、続きは裏の帳尻（代償・止まった夜）。技を覚えて読み直すと、裏が見える。

## 4. 書かないこと
- 「魔王」「ガイゼリク」、古言の正体、民が何にされたか、神々がいないこと、刻印の環が名簿であること（〔秘〕）。
- 誰が玉座の獣を殺したか（余白。gods.md）。
- 火山に封じられていたのがマグザレムだと言い切ること（余白）。
