# 使徒の不死（設計案）

> **案の文書。** 持ち主が読んで選ぶためのもので、まだゲームには入っていない。決まったら、選ばれた所だけをデータに入れ、この文書の頭に「決まったこと」を書き足す。レーン E（敵・使徒）。
> 由来（創造主・兵器）の正は、世界観の書き換え（ブランチ d-creators）が書く文書。ここの「兵器としての理屈」は不死のギミックの筋を通すための案で、由来の文書と食い違ったら由来の文書が勝つ。ここの理屈はすべて〔秘〕（プレイヤーに見える文には書かない。見えるのは姿と起きることだけ）。

## 0. 持ち主の決定（2026-10-15）

- 「使徒は何かしらの不死性をもたせたい。不死性があると強さの説得力にもなるし、ギミックを攻略すれば戦いになるので強さのインフレも抑えられる。魔人の無敵結界のように共通した不死性ではなく各使徒毎に異なるギミックをもたせたい」
- 「使徒はこの世界の創造主によって作られた存在です。創造主は文明が異常に発達した人間です。創造主同士の争いの兵器として使徒は作られました。なので物理法則にまで干渉できるものもいますし、強いです。創造主は全員死んでいて、世界は徐々に滅びていく終わった世界です」
- あわせて：魔王という設定はなくす（使徒は魔王の配下ではなく、創造主の兵器）。神々は人の信仰で、創造主とは別。

この文書では、上の決定を次のように読む。
1. 不死は**門**。門を開ける（ギミックを破る）までは戦いにならない。開けたら、今の格のままの普通の戦い。
2. 門の形は一体ずつ違う（型を全員ばらばらにする）。共通の「絶界」ではない。
3. 不死は「兵器の仕様」。その使徒が戦場で何を壊すために作られたかから出す。だから姿・二つ名・性格・まぬけな所と一つながりになる。

## 2. 共通の決まり（案）

### 2.1 門と、門の向こうの戦い
- **門の条件**：一体ずつ一つ（S 級は二つ）。たいていは今の `zekkai` の条件をそのまま使う（品と手がかりはもうゲームにある）。今の品が型に合わない使徒だけ、新しい条件にする（6. に一覧）。
- **門の判定**：条件をそろえて挑むと、その場で一回の判定。能力値は使徒ごと（下の表）。難しさは格で決まる：B「普通」・A「難しい」・S「難しい」を二段（条件ごとに一回）。
  - 手がかりを知っていると一段易しくなる：その使徒の図鑑の項（`D.E3.LORE`）を開いた、会う出来事の「様子をうかがう」の覚え書き（`peek.memo`）がある、のどちらか。答えは書かず、知っているほど楽になる形（GAM-32：読み逃しを罰にしない）。
- **破れなかったとき（条件が無い・判定に落ちた）**：戦いにならない。「不死の場面」を一段落だけ出す（今の `GUARD` の一行を膨らませたもの。その使徒のギミックが目に見える）。体力を少し失い（仮：最大 HP の 2 割）、その場を退く。死なない。挑んだ回数（`G.e3Tries`）は増える（「何度も挑んで癖を覚えた」の条件はそのまま効く）。
- **破れたとき**：破れた一行を出して、普通の戦いに入る。強さは**今の格のまま**：`frac`（E3 の条件＋E10 の出来事）の計算は変えず、門の条件も今と同じく `frac` に数える。だから `e8_power` で測った「すべてそろえた」勝率は動かない。
- 門は一回の挑戦ごと。破ったことはセーブに残さない（次に挑むときもまた条件と判定が要る）。逃げたあと立て直して挑み直すときも同じ。

### 2.2 守りの効き目（E11 の FX）との関係
- FX（再生・回避など）は「門を破ったあとに残る名残」として今のまま残す。`1 − frac` で弱まるのも同じ。文（`on`・`broken`）だけ、型と食い違う使徒は直す（6.）。
- 黒鎧の絶界は、今は戦いの中で刃が弾かれる形。ほかとそろえて「破るまでは戦いにならない」にする（選んでほしい所 1）。

### 2.3 討てない使徒
- 「破り方が無い」か「破っても逃げる（戦わない）」のどちらかを、一体ずつ理由つきで決める。挑んだときの一行は今の `D.E8.UNSLAY` のまま使う（どれも型と合っている）。
- 長編の中でだけ討てる使徒（黒曜）は、門の条件を長編の決戦の中で満たす形にする（今の `zz_v17a_golvan.js` の仕組みのまま）。

### 2.4 書かないこと
- 「兵器」「作られた」「創造主」は、この文書と由来の文書の中だけの言葉。プレイヤーに見える文（不死の場面・破れた一行・噂・図鑑）では、姿と起きることだけを書く（voice.md の〔秘〕）。
- 魔王の名残という説明はしない（`majin.md` の頭の「絶界は昔の魔王の血の名残〔秘〕」は、由来の書き換えで取り下げになる見込み。この文書では使わない）。

似ている所の分け方：
- 再生（灼け口）と宿り（苔衣）と核（酸溜まり）：灼け口は**食べて**治す（腹を空かせれば止まる）。苔衣は**よそに預けた命**で治す（預け先との根を切る）。酸溜まりは治すのではなく、**死ぬ形が無い**（形を持たせる）。
- 場所（剣翼）と位相（黒翼）：剣翼は空に**いる**が降ろせる。黒翼は空にも**いない**（影だけ）。
- 反射（蝶翅）と時間（閉じ月）：どちらも「見るな」の使徒だが、蝶翅は目を合わせた者が**自分を壊す**、閉じ月は見た者の**時間が進む**。破り方も、目隠し（見ずに戦う）と水鏡（映して射る）で違う。
- 記憶（忘れ水）と意思（香煙）：忘れ水は**何を**斬るかを抜く。香煙は**なぜ**斬るかを溶かす。

## 7. ゲームに入れるときの仕組み（案）

- **データ**：新しいファイル `src/data/zz_e13_immortal.js` に `D.E13.GATE[id] = { type, stat, keys: [条件 id…]（S は二段で [[…],[…]]）, item?: true（伝説の武具でも可など）, scene: 不死の場面の文, broken: 破れた一行 }`。条件そのものは今の `D.E3.LIST[id].keys` を id で指す（品・出来事の id を二重に書かない）。新しい条件（砂の証文・罪）は `D.E3.LIST[id].keys` に足す。
- **エンジン**：新しいファイル `src/engine/zz_e3y_e13_immortal.js`（`zz_e3_apostles.js`・`zz_e8_unslay.js` の後、`zz_e3z_e10_events.js` の前に読まれる名前）。`G.startCombat` を包み、相手が門を持つ使徒なら：条件がそろっていなければ「不死の場面」を出して戦いを始めない／そろっていれば判定（`G.check` の形。手がかりを知っていれば一段易しく）→ 成功で破れた一行を出して元の `startCombat` へ、失敗で不死の場面。長編（E7）の決戦は、長編の備えで門を開ける印を渡す（`opt.gate`）。黒鎧の絶界（`zz_e3y_e11_wall.js`）は、門を破ったら `e3Open` を立てる形にまとめる。
- **セーブ**：足さない（門は挑むたび。回数は今の `G.e3Tries`）。罪を言った印だけ `S.e13 = { said: n }`（無ければ 0）。
- **テスト**：`tests/checks/e13_immortal.mjs`
  1. 討伐できる十六体すべてに門がある。型が全員違う。
  2. 条件がそろっていないと戦いが始まらない（`S.combat` が立たない）、そろって判定に通れば始まる。
  3. 門の条件の品・出来事・印の id がすべて実在する（整合チェック）。
  4. 手がかり（噂・断片・図鑑・覚え書き）が一体につき二本以上ある（STY-12）。
  5. `e8_power` の「すべてそろえた」勝率が変わらない（門を通ったあとの強さは今のまま）。正面は「戦いにならない」で 0%。
  6. 不死の場面・破れた一行に「兵器」「創造主」「作られた」「魔王」が出ない（〔秘〕の禁止語）。
- **更新履歴**：入れる PR で `src/data/changelog.js` の次の版に「使徒は一体ずつ違う不死を持つようになった。手がかりを集めて破らないと戦いにならない」。

## 8. 持ち主の決定（2026-10-15「全部おしで」）

1. **黒鎧の絶界**：ほかとそろえて「破るまでは戦いにならない」にする。
2. **微笑の門**：A（笑わない面＋判定で吊られた人を下ろす）。B は弱りに残す。
