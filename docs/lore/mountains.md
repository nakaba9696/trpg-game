## 1. 眠り山ロウネ（`w10_roune`。レオネスト王国・危険度 1）

### 地理と歴史
- 火山の都フロスレイアの北にある、火の消えた古い火山。南の火山（「怒る山」）と同じ山並みの、北の端の一つ〔知〕。
- **504 年**、南の火山が大噴火して王国の南が潰れた（world.md 年表 504〔知〕）。同じ山並みなのに、ロウネだけは火も煙も上げなかった。それで「眠り山」と呼ばれるようになった〔知〕。前の名は残っていない。
- 噴火の灰が北の斜面に降り積もり、それが草地になった。今の牧草地は 504 年の灰の上にある〔知〕。斜面のガレ場は、そのとき崩れた岩〔知〕。
- 頂の火口には湖がある。底から温い水が湧き、冬でも凍らない〔知〕。湖の温みで、頂には霧がよく湧く〔知〕。

### 誰が住み、何をしているか
- **山羊飼い**：504 年に南から逃げてきた人々の子孫。畑を失い、灰の斜面で山羊を飼うしかなかった〔知〕。今も夏は上の牧草地、冬は麓で暮らす（山を上り下りする暮らし）。
- 声の通る者が尊ばれる。山羊飼いは谷越しに歌で知らせ合う（峠の歌）〔知〕。
- **祀るもの**：光天教会の三柱。とくに死のハルガ。504 年に死体の見つからなかった者の名を、火口の縁の**石の輪**に一つずつ刻んで並べた。今は山羊飼いが死ぬと、家の者が石を一つ運び上げる。新しい石ほど印が白い〔知〕。

### 峠と山小屋
- **風切りの峠**：504 年の避難の道。逃げてきた人々が、山の肩を越えて北の平野へ出た道〔知〕。峠の石積みは、そのとき道に迷わないように積んだ道標が始まり。越えるとき石を一つ載せる習わしは、山の民（3.）と同じ〔知〕。
- **石積みの山小屋**：山羊飼いが夏の牧草地のために、黒い溶岩の石で建てた。戸口の上の山羊の角は、小屋を建てた家の印〔知〕。誰が使ってもよく、使った薪は戻していくのが決まり〔知〕。
- **馬の背の尾根**：火口の縁へ続く細い尾根。上昇気流があり、大鷲が棲む。

### 言い伝え
- 「迷った山羊は上へ行く」。迷うと山羊は頂へ登る。羊飼いは山羊を探すとき、まず上を見る〔知〕。
- 「眠り山は眠っているのではなく、聞いている」。火口湖に向かって大声を出すと、南の怒る山が答えるという。答えた話は残っていない〔噂〕。（フロスレイアの学者が三十年つけている咆哮の記録は一度きり。life.md）
- 〔秘〕南の怒る山の 504 年の噴火は、使徒マグザレム（31。山の腹。大地と一つになった巨体）の目覚め。ロウネが同じ山並みなのに眠っているわけは決めない。見える文では「同じ山並み」「聞いている」で匂わせるだけ。

### 魔物（設定からの理由）
| 魔物 | 理由 |
|---|---|
| 岩跳び山羊（段 1〜3） | 504 年の避難で群れからはぐれた山羊の子孫。人の荷の干し肉の匂いを覚えている |
| ガレ場の土竜（段 1〜2） | 504 年の崩れ岩と灰の斜面を掘って棲む |
| 霧かぶり（段 2〜4） | 火口湖の温みで湧く霧に棲む小鬼。道標の石をずらす。避難の道の石積みが、ちょうどよい遊び道具になった |
| 尾根の大鷲（段 3〜4） | 尾根の上昇気流 |
| 麓の野犬・ゴブリン | 王国の南の野のふつうの魔物 |
| 年経た岩喰い鳥（名のある強敵。今ある敵） | 岩を食う大鳥。火口の縁の黒い溶岩と、その中の光る石をかじりに来る |

### 山頂の絶景の意味
火口湖の縁から、504 年に潰れた南（今は火山の都と、煙を立てる怒る山）と、逃げた人々がたどり着いた北の平野と西の海を一度に見渡す。逃げた人々の子孫の山羊が、先に頂に立っている。発見は**石の輪**（504 年から今までの死者の名）。

## 2. 鉄冠岳ドラウゼ（`w10_drause`。ノルディア帝国・危険度 3）

### 地理と歴史
- 鉱山の都カースヴェルグの北東にそびえる、赤錆色の山〔知〕。岩が鉄を多く含み、雨に濡れると赤く錆びる。頂の黒い岩は冠の歯のように尖って並ぶ〔知〕。
- カースヴェルグの鉄はもともとこの山から掘っていた。帝国の発足（**312 年**）より前、部族の時代から〔知〕。鉄の都の名の起こりの山。
- 鉱脈を追って坑道は年ごとに上へ延び、中腹に坑夫の村ができた。**およそ四十年前**、上の坑道で大きな崩れがあり、坑夫の村は捨てられた〔知〕。今カースヴェルグが掘っているのは、北の廃坑（古い鉄の道）と、町の山の腹〔知〕。
- 〔噂〕崩れの前の年から、上の坑道で鉄を打つような音がしていた。崩れのあとも止まない。カースヴェルグの「掘りすぎるな」は、このころから言われるようになった（life.md）。
- 〔秘〕決めない。腹ぺこ岩（igyo.md 39 ヴェドローク。鉱山が広がると地割れと共に現れる）と結びつけてもよいが、見える文では「鉄を打つ音」「鉄が呼ぶ」「上で待ってる」だけ。正体は書かない。

### 誰が住み、何をしているか
- **坑夫の村跡**：捨てられた村に、元坑夫の老人が一人だけ残っている。片手の指が三本。上へ登った相方を待っている〔知〕。
- **山の民（塩運び）**：北の凍った海の塩田で作った塩を、背負子で峠を越えて南の村々へ運ぶ人々（3.）。坑夫の道を使っている〔知〕。
- **祀るもの**：坑夫は死のハルガを祀る。坑道で死体の見つからなかった坑夫の名をハルガさまに覚えてもらうため、**鈴を一つ**峠の道標に下げる〔知〕。数えると一つ増える、と言う〔噂〕。

### 峠と山小屋
- **鈴落としの峠**：坑夫の鉱石を、山の東の製錬場へ運ぶために拓いた道。今は塩運びの道〔知〕。鈴は 2. の「祀るもの」。
- **雪室の小屋**：上の坑道の坑夫が、交代の待ち合わせに雪を掘って建てた小屋。壁に坑夫の名が刻んである。最後の名の下は空いている〔知〕。
- **鉄錆の尾根**：上の坑道の口が並ぶ尾根。岩の鉄で方位磁石が狂う〔知〕。

### 言い伝え
- 「上の方は鉄が呼ぶ」。上の坑道に入った坑夫は、帰ってきてもまた上がる。三度目は帰らない〔噂〕。
- 「尾根では岩に手をつくな。耳をつけるのはもっといかん」（村跡の老人）〔噂〕。
- 頂の岩陰に、坑夫の弁当箱が置いてあるという。蓋の裏に「上で待ってる」〔噂〕。

### 魔物（設定からの理由）
| 魔物 | 理由 |
|---|---|
| 氷柱蝙蝠（段 0〜2） | 捨てられた坑道の口に棲む。坑口が多い山だから |
| 雪の大猿（段 0〜3） | 帝国の山の獣。捨てられた村から帽子を拾って集める |
| 尾根の大鷲（段 3〜4） | 尾根の上昇気流 |
| 坑夫の亡者（段 4。今ある敵） | 上へ登って帰らなかった坑夫 |
| 石肌の巨人・崖の鳥女・氷柱の霊・雪狼（今ある敵） | 境と帝国の山の魔物 |
| オーク（麓） | 捨てられた村に入りこむ |
| 雪狼の頭目（名のある強敵。今ある敵） | 帝国の雪原の雪狼の群れ。冬は獲物を追って峠の下まで来る |

### 山頂の絶景の意味
冠の歯のあいだから、北の凍った海（塩運びの塩の来る所）と帝都の煙、足もとの鉱山の都、東の空いっぱいの断界山脈を見る。人の国の端と、その先を一度に見る場所。鉄を打つ音が、ここでも鳴る。発見は**凍った弁当箱**（「上で待ってる」）。

## 3. 山の民

- 国に属さず、季節で峠を渡り歩いて塩・毛織物・干し肉を運ぶ人々〔知〕。どこの国の言葉も少しずつ話す。
- 峠の石積みに石を一つ載せてから越える。載せずに越えた者は、帰り道で二つ載せることになる〔知〕。
- 山小屋で火を分けてもらうと、礼に短い歌を一つ置いていく。歌は峠ごとに違う〔知〕。
- 眠り山ロウネの峠の石積みの習わしは、504 年に逃げてきた人々が山の民から教わったもの〔噂〕。

## 4. 見せ方（持ち主「景色が見たいわけではなく、冒険した先で絶景を見たいだけ」）

- 「景色を眺める」行動は置かない。**冒険の節目に着いた瞬間**に、背景と短い文で絶景を見せる：はじめて峠を越えたとき（下の世界を振り返る）と、山頂に着いたとき（毎回。はじめての頂だけ山場の長い文と発見）。
- 背景は段ごとに別の絵（麓・峠・山小屋・尾根・山頂）。山頂は時間帯（朝焼け・昼・夕焼け・夜）と天候（霧・雪・雨）で変わる。
