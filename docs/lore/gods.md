# 神々と魔王

上位存在の順は **創世神ヴェルム と 三天神 → 魔王 → 十三魔人 → 使徒**。十三魔人は [majin.md](majin.md)。

> このファイルはレーン D（世界観）が管理する。人間はここに書いた「仕組み」をほとんど知らない。出来事や GM が明かすときは、少しずつ、噂や壁画や夢の形で出す。
> 世界の基調（人間はたいしたことのない存在／恐ろしい者ほどどこかまぬけ／独自の名前と設定）は [majin.md](majin.md) の冒頭にまとめてある。

## 創世神ヴェルム
- **何者か**：この世界を作った神。名前しか伝わっていない。姿を見た者はいない。
- **世界との関わり**：世界はヴェルムの見世物。人も魔物も魔王も、ヴェルムを退屈させないための役者にすぎない。ヴェルムは筋書きを書かない。ただ観て、面白ければ喜び、つまらなければ――幕を下ろす。
- **赤い月**：赤い月の夜、ヴェルムがこちらを覗いている。その夜は、奇跡も惨劇も起きやすい。
- **証拠**：古代遺跡ロゥムの最奥の壁画に「三柱の神と、それを見下ろす巨大な目」が描かれている。鏖殺の魔人グラウが倒れたとき、空のどこかで誰かが拍手をした。
- **ゲームでの使い方**：直接は登場させない。拍手、視線、赤い月、ありえない偶然として匂わせる。

## 三天神
ヴェルムの下で世界の仕組みを回す三柱。仲はよくない。三柱とも、祈りに応えるかどうかを「面白いかどうか」で決める。ただし、何を面白いと思うかが三柱で違う。

### 秩序の神ソラス
- **司るもの**：光、法、約束、王の位。
- **姿**：天秤を持つ、顔のない白い巨人。
- **面白いと思うもの**：約束が守られるか破られるかの、張りつめた瞬間。誓いを立てて、苦しみながらそれを守る者が大好き。あっさり破る者は大嫌い。
- **信者**：騎士、王侯、裁判官、光天教会の表の顔。
- **加護と罰（案）**：誓いを立てると、その誓いに沿った判定に補正が付く。誓いを破ると、名声が落ち、しばらく判定に不利が付く。
- **聖刀白夜**：ソラスが八雲の刀鍛冶に「月を喰うものを封じよ」と夢で命じて打たせた刀、と八雲の古文書にある（[majin.md](majin.md) の宵姫）。

### 混沌の神ネフィリア
- **司るもの**：偶然、博打、笑い、裏切り、変化。
- **姿**：賽子を転がす、笑い転げる女。毎回、姿が違う。
- **面白いと思うもの**：番狂わせ。弱い者が強い者を倒すこと、忠臣の裏切り、大一番の大失敗。
- **信者**：盗賊、博打打ち、道化、傭兵。光天教会では三天神の一柱として祀られるが、その祭りは表に出せないので夜に行われる。
- **ダイス**：大成功（成功率の1割以下）と大失敗（96以上）は、ネフィリアが賽子に触れた印だと言われる。
- **加護と罰（案）**：祈ると、次の判定で大成功と大失敗が両方起きやすくなる。

### 死の神ハルガ
- **司るもの**：死、墓、記録、終わり。
- **姿**：分厚い帳面を抱えた、黒い衣の老いた書記。
- **面白いと思うもの**：人の一生の物語。ハルガは死者の人生を帳面に書き写し、夜ごと読み返すのを楽しみにしている。短くても、派手でも、みじめでも、よく書ける一生が好き。
- **信者**：墓守、葬儀屋、年寄り、死にかけた冒険者。
- **年表と墓碑**：冒険者が死んだあとに残る**年表**と**墓碑**は、ハルガの帳面の写しだと言われる。死ねば終わりだが、記録は残る。
- **加護と罰（案）**：死に際に祈ると、一度だけ死を見逃すことがある（「まだ話の続きが読みたい」）。代わりに、次に死んだときは容赦がない。

### 三天神と光天教会
- 光天教会は三天神を等しく祀ると言うが、実際はソラスの教えだけを表に出し、ネフィリアを隠し、ハルガを墓守に任せている。
- 教会は「魔人は神の試練」と説く。これは半分本当。神々にとって魔人は、物語を盛り上げるための敵役だから。
- 聖都の「生き聖女」の正体は、神の座を狙う**偽聖の魔人アウレリア**（[majin.md](majin.md)）。三天神はこれに気づいているが、面白いので放っておいている。

## 魔王の座
- **仕組み**：千年に一度、三天神が「世界の敵」を一人選ぶ。選ばれた者は魔王となり、魔物界を統べ、人類を脅かして物語を盛り上げる。人間は誰もこの仕組みを知らない。
- **魔王の血**：魔王は自分の血を十三に分け、十三体の魔人を作る。魔人の絶界は、この魔王の血から生まれる。
- **千年の交代**：千年が過ぎると、三天神は次の魔王を選ぶ。三柱の意見が合ったことは一度もなく、毎回、最後は賽子で決まる。
- **人間の立場**：人間は魔王に選ばれない。神々にとって人間は「観客席の賑やかし」で、舞台に上がる役者ではない。人間の国がいくつ滅んでも、神々の筋書きには一行も書かれない。

## 魔王ガイゼリク
- **何者か**：当代の魔王。ヴェルド暦131年に魔王の座に就いた。**ヴェルド暦1131年で千年目**を迎える（物語の始まりは1127年の春）。
- **元の姿**：断界山脈より古い時代から生きる、名もない巨大な獣だった、と夜哭城の壁の古い文字にある。
- **眠りの理由**：人の世に飽きた、と言われている。本当は、千年前のある晩、退屈しのぎに人間の国を七つ滅ぼしてみたら、翌朝あまりにつまらなかったので、ふて寝した。それきり起きない。**起こされるのが何より嫌い**で、寝起きの機嫌で大陸の地図が変わる、とユラは恐れている。
- **まぬけなところ**：寝言がうるさい。夜哭城が夜ごと泣くような音を立てるのは、実は魔王のいびきと寝言。魔人たちは聞こえないふりをしている。
- **居場所**：魔物界の最奥、**夜哭城（やこくじょう）**（新）。夜になると城が泣くような音を立てる。寝所の隣では、**微睡のユラ**が眠りを守っている。
- **目覚め**：千年目が近づき、神々は次の魔王選びのために、ガイゼリクを起こそうとしている。魔人の中にも、魔王を起こして自分が次の座を得ようとする者がいる。ユラだけは、魔王が二度と目覚めないことを願っている。人間の国がそのとき巻き添えになるかどうかは、誰も気にしていない。
- **絶界**：魔王の絶界は魔人よりはるかに強い。魔剣ヴォルグリムと聖刀白夜の**二振りを両方**そろえて、はじめて届くと言われる。

## 二振りの剣の由来
- **魔剣ヴォルグリム**：混沌の神ネフィリアが、魔人ばかりが勝つ筋書きに飽きて、「番狂わせの種」として地上に放り投げた剣。性格の悪さと口の悪さは、作り手ゆずり。ネフィリアは作ったことを半分忘れている。竜の墓場で屍竜ネクロザ（天墜の魔人アズラグの母）が、光り物と間違えて呑み込んでいた。ヴォルグリムは呑まれていた百年のことを話したがらない。
- **二振りの釣り合い**：秩序の神と混沌の神が一振りずつ地上に置いた、という点で二振りは対になっている。どちらも、人間を助けるためではなく、筋書きを面白くするために置かれた。
- **聖刀白夜**：秩序の神ソラスが夢で命じ、八雲の刀鍛冶が打った刀。月喰いの宵姫を封じる要だったが、鬼の酒呑に奪われた。

## ゲームで明かす順番（案）
1. 最初から知られていること：創世神と三天神の名、魔王と魔人、二振りの剣（`src/data/world.js` の手引き）。
2. 噂で知ること：十体の魔人の二つ名と居場所、赤い月、ハルガの帳面。
3. 冒険の先で知ること：遺跡の壁画（見下ろす目）、千年の交代、夜哭城の泣き声の正体。
4. 最後まで行った者だけが知ること：ヴォルグリムの正体、ガイゼリクの眠りの本当の理由。
