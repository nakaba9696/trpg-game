# 神々と魔王

上位存在の順は **創世神ヴェルム と 三天神 → 魔王 → 十三魔人 → 使徒**。ただし**神々はもういない**（〔秘〕）。残っているのは、神々が作った**仕組み**だけ。十三魔人は [majin.md](majin.md)。

> このファイルはレーン D（世界観）が管理する。人間はここに書いた「仕組み」をほとんど知らない。出来事や GM が明かすときは、少しずつ、噂や壁画や夢の形で出す。
> 世界の基調（人間はたいしたことのない存在／恐ろしい者ほどどこかまぬけ／独自の名前と設定）は [majin.md](majin.md) の冒頭にまとめてある。
> **入口と正は [world.md](world.md)（D4）。** 段階の印〔知〕〔噂〕〔進〕〔秘〕の意味は [world.md](world.md) 0.。
> **このファイルの「見世物」「観客」「客席」「舞台」「台本」は、すべて〔秘〕。** プレイヤーに見せる文には言葉として書かない。GM に渡すときも「プレイヤーに明かさない」と添える。
> **D6（#106）で持ち主の決定に合わせて直した**：神々は仕組みだけを残してもういない／魔王は争いに興味がなく、正体を知られずに人の世界を歩いている／人を襲うのは魔王の配下が勝手にやっていること。千年目の大事件は無い。

## 住人が信じていること〔知〕
この世界の一般人は、神々の本当の姿を知らず、**神々は良いものだと本当に信じている**。今も神々がいて、見守ってくださっていると思っている。信仰は祈り・祭り・お守り・口癖として暮らしの中に当たり前にあり、それを説明する人はいない（[life.md](life.md) 4.・7.）。
- **ヴェルム**：世界を作った父なる神。名を軽々しく呼ばない。今は眠っておられる。
- **ソラス**：光と法と約束の神。誓いを守る者を守ってくださる。春の誓い祭。
- **ネフィリア**：幸運と笑いの神。博打打ちと旅芸人の守り神。冬至の賽の夜。
- **ハルガ**：死者の名を帳面に書き留め、覚えていてくださる優しい書記。秋の帳面祭。
- 祈りが通じた話は誰でも一つ持っている。通じ方が妙だった話も、誰でも一つ持っている。〔噂〕

## 神々がもういないこと〔秘〕
- **かつて眺めていた者たちがいて、もういない。客席には誰もいない。** ヴェルムと三天神は、この世界を見世物として作り、眺めるための**仕組み**を組んだ。そして、いなくなった。死んだのか、飽きて去ったのか、仕組みの一部になったのかは書かない（余白）。いつのことかも書かない（魔王ガイゼリクを選び、二振りの剣を地上に置いたよりあと、とだけ）。古王国ロゥムの幕引きの夜（[history.md](history.md)）は、神々がまだいたころのこと。
- **残っている仕組み**（どれも、誰も見ていないのに、決まりどおりに今も動いている）：
  - **賽子**：判定の大成功・大失敗。三柱の意見が割れたときのために作られた賽子が、今も勝手に転がる。
  - **誓いの重さ**：誓いを守る者に補正、破る者に罰（ソラスが面白がったもの）。
  - **帳面**：死者の一生を書き写す帳面。冒険者の**年表**と**墓碑**は、その写し。読み返す者はもういない。
  - **才能の器**：生まれたときに一人一人に配られた、技能ごとの伸びしろ（M8 #102 の才能レベル）。暮らしの才能・役に立たない才能まで、細かく配られている。誰が何のために配ったのかは、誰も知らない。
  - **術の貸し借り**：借りたら返す決まり（M1 の「借り」）。貸し手が人ならざる者でも、決まりは仕組みが守らせる。
  - **魔王の座**：千年ごとに「世界の敵」を一人選ぶ決まり（下の「魔王の座」）。
  - **覗き窓**：赤い月。神々がこちらを覗くための窓が、覗く者もいないのに、決まった夜に開く。
  - **拍手**：神々が面白がった瞬間に鳴っていた音。叩く手はもう無いのに、決まった条件で、今も空のどこかで鳴る。
- **仕組みが「面白い」と判じるもの**：三柱がそれぞれ面白がったもの（誓い・番狂わせ・よく書ける一生）が、決まりとして残っている。だから祈りへの応えは、気まぐれに見えて、実は決まりどおり。決まりが人には分からないだけ。
- **一般人との落差**：人々は今も神々に祈り、祭りを開き、お守りを握る。祈りは、たまに仕組みに引っかかって応えが返る。だから信仰は揺るがない。応えたのが誰でもないことを、人は知らない。
- **ゲームでの使い方**：神々を登場させない。プレイヤーに見える文で「神々はもういない」と言わない。手触りだけ：誰も祈っていない祭壇で鳴る賽子の音、埃をかぶったまま誰も直さない像、決まりどおりすぎる偶然、才能の器の妙な細かさ、読み返されない帳面。答えは出さない。

## 創世神ヴェルム
- **何者か**：この世界を作った神。名前しか伝わっていない。姿を見た者はいない。
- **世界との関わり**〔秘〕：ヴェルムは世界を見世物として作り、筋書きは書かず、ただ眺めるつもりだった。眺めるための仕組み（覗き窓・拍手・幕を下ろす決まり）を組んだ。そして、もういない。仕組みだけが、眺める者のいない席に向かって動き続けている。
- **赤い月**〔噂〕（覗き窓であることは〔秘〕）：赤い月の夜は、奇跡も惨劇も起きやすい。覗き窓が開くと、仕組みが「面白いこと」を起こしやすくなる。覗いている者は、もういない。
- **証拠**：古代遺跡ロゥムの最奥の壁画に「三柱の神と、それを見下ろす巨大な目」が描かれている。鏖殺の魔人グラウが倒れたとき、空のどこかで誰かが拍手をした（拍手の仕組み）。
- **ゲームでの使い方**：直接は登場させない。拍手のような音、誰かに見られている気配（見ている者はいない）、赤い月、ありえない偶然として感じさせる。正体は言葉で明かさない。

## 三天神
ヴェルムの下で世界の仕組みを組んだ三柱。仲はよくなかった。三柱とも、祈りに応えるかどうかを「面白いかどうか」で決める決まりを残した〔秘〕。何を面白いと思うかが三柱で違うので、仕組みの中にも三つの癖が残っている。三柱とも、もういない〔秘〕。

### 秩序の神ソラス
- **司るもの**：光、法、約束、王の位。
- **姿**：天秤を持つ、顔のない白い巨人（像）。
- **残した癖**：約束が守られるか破られるかの、張りつめた瞬間を面白がった。仕組みは今も、苦しみながら誓いを守る者に応え、あっさり破る者に罰を返す。
- **信者**：騎士、王侯、裁判官、光天教会の表の顔。
- **加護と罰（案）**：誓いを立てると、その誓いに沿った判定に補正が付く。誓いを破ると、名声が落ち、しばらく判定に不利が付く。
- **聖刀白夜**：ソラスが八雲の刀鍛冶に「月を喰うものを封じよ」と夢で命じて打たせた刀、と八雲の古文書にある（[majin.md](majin.md) の宵姫）。ソラスがまだいたころの話。

### 混沌の神ネフィリア
- **司るもの**：偶然、博打、笑い、裏切り、変化。
- **姿**：賽子を転がす、笑い転げる女（像。毎回、姿が違う）。
- **残した癖**：番狂わせを面白がった。弱い者が強い者を倒すこと、忠臣の裏切り、大一番の大失敗。賽子の仕組みは、ネフィリアが作った。
- **信者**：盗賊、博打打ち、道化、傭兵。光天教会では三天神の一柱として祀られるが、その祭りは表に出せないので夜に行われる。
- **ダイス**：大成功（成功率の1割以下）と大失敗（96以上）は、ネフィリアが賽子に触れた印だと言われる〔噂〕。本当は、ネフィリアの残した賽子が勝手に転がっただけ〔秘〕。
- **加護と罰（案）**：祈ると、次の判定で大成功と大失敗が両方起きやすくなる。

### 死の神ハルガ
- **司るもの**：死、墓、記録、終わり。
- **姿**：分厚い帳面を抱えた、黒い衣の老いた書記（像）。
- **残した癖**：人の一生を読み物として楽しんだ。帳面に死者の人生を書き写す仕組みは今も動いている。読み返す者はいない。
- **信者**：墓守、葬儀屋、年寄り、死にかけた冒険者。
- **年表と墓碑**：冒険者が死んだあとに残る**年表**と**墓碑**は、ハルガの帳面の写しだと言われる。死ねば終わりだが、記録は残る。
- **加護と罰（案）**：死に際に祈ると、一度だけ死を見逃すことがある（帳面の決まり「書きかけの一生は閉じない」）。代わりに、次に死んだときは容赦がない。

### 三天神と光天教会
- 光天教会は三天神を等しく祀ると言うが、実際はソラスの教えだけを表に出し、ネフィリアを隠し、ハルガを墓守に任せている。
- 教会は「魔人は神の試練」と説く。試す神はもういない〔秘〕。
- 聖都の「生き聖女」の正体は、神の座を狙う**偽聖の魔人アウレリア**（[majin.md](majin.md)）。アウレリアは、神々の座が**空いているのではないか**と疑っている（〔秘〕。だから本気で座ろうとしている）。止める者はいない。
- 祭壇で神々に何を告げても、応えるのは仕組みだけ（賽子の音・帳面の頁がめくれる気配）。

## 魔王の座
- **仕組み**〔秘〕：千年に一度、仕組みが「世界の敵」を一人選ぶ。選ばれた者は魔王となり、その血は十三に分かれて十三体の魔人になる。神々がいたころは、魔王が人類を脅かして物語を盛り上げる決まりだった。人間は誰もこの仕組みを知らない。
- **魔王の血**：魔王の血は、座に就いたときに勝手に十三に分かれ、十三体の魔人になった。魔人の絶界は、この血から生まれる。魔王が分けようとしたわけではない。
- **千年の交代**：千年が過ぎると、仕組みが次の魔王を選ぶ決まり。三柱の意見が合ったことは一度もなく、毎回、最後は賽子で決まった。今は賽子だけが残っている。
- **人間の立場**〔秘〕：人間は魔王に選ばれない。神々にとって人間は「客席の賑やかし」で、舞台に上がる役者ではなかった。その客席にも、もう誰もいない。

## 魔王ガイゼリク
- **何者か**：当代の魔王。ヴェルド暦131年に選ばれた（三柱の意見が割れ、最後は賽子で）。神々がいなくなる前の、最後の魔王選び。元は、断界山脈より古い時代から生きる、名もない巨大な獣だった、と夜哭城の壁の古い文字にある。
- **争いに興味がない**〔秘〕：選ばれたものの、世界の敵の役に興味がなかった。人を滅ぼしたことも、攻めろと命じたこともない。**魔人と使徒が人を襲うのは、配下が勝手にやっていること**。魔王は止めもしない。人間の国がいくつ焼けても、気にしていない。それがこの魔王の残酷さ。
- **人の世界を歩いている**〔秘〕：魔王はとうに城を出て、**人の姿で、人間の世界のそこらへんを普通に歩いている**。宿の隅の席でスープの湯気を眺め、広場の喧嘩を止めもせず眺め、針のない釣り糸を垂らし、賭場で負け続ける。人間の暮らしの細かいところが、珍しくて仕方がない。**正体は誰にも知られていない**（人間にも、魔人にも）。
  - **姿**：灰色の古い外套の旅人。年の分からない顔、眠たそうな色の薄い目。男とも女とも書かない（見た人ごとに言うことが違ってよい）。丁寧で、腰が低い。
  - **まぬけなところ**：人間の決まりごとが分からない。古すぎる硬貨で払おうとして断られる、パンを買う列と別の列に並ぶ、晴れた日に傘をさす、同じ宿に毎回はじめて来たような顔で来る、季節を一つ間違えた服を着ている。
  - **気づかれ方**：魔物は理由も分からず道の端に寄る。魔人も、なぜか道を譲ってしまう（血が覚えている。本人たちは不思議がる）。賽子は、なぜかこの旅人には一度も良い目を出さない（仕組みは座に就いた者を「面白さ」の外に置く。〔秘〕の余白）。ルグゥは旅人が海辺にいる日は歌わない。ユラだけは夢の中でときどき姿を見かけるが、どこで何の顔をしているかは知らない。
  - **長く遊ぶと何度か出会う**：出会うたびに、前にも会った気がする。向こうは覚えていない（ように見える）。何も起きない。それで終わる。正体を明かす出来事は作らない（`src/data/walker_d6.js`）。
- **居場所の噂**：魔物界の最奥、**夜哭城（やこくじょう）**。夜になると城が泣くような音を立てる〔噂〕。本当は**城は空っぽ**〔秘〕。主のいない城が、夜ごと主を呼んで泣いている。寝所の隣には**微睡のユラ**が眠っていて、ほかの魔人には「魔王さまは奥でお休みだ。起こすな」と言い張っている（[majin.md](majin.md)）。
- **千年目**：131年に選ばれたので、1131年で千年になる。仕組みが次の魔王を選ぶのか、何も起きないのかは、誰にも分からない〔秘〕。**大事件にはしない**（持ち主の決定）。ガイゼリクは気にしていない。起きるとしても、千年目を口実に魔人や暁鐘会が勝手に騒ぐくらい。
- **絶界**：魔王の絶界は魔人よりはるかに強い。魔剣ヴォルグリムと聖刀白夜の**二振りを両方**そろえて、はじめて届くと言われる。とはいえ、本人が城にいないので、届かせる場面はまず無い。

## 二振りの剣の由来
- **魔剣ヴォルグリム**：混沌の神ネフィリアが、魔人ばかりが勝つ筋書きに飽きて、「番狂わせの種」として地上に放り投げた剣（ネフィリアがまだいたころ）。性格の悪さと口の悪さは、作り手ゆずり。竜の墓場で屍竜ネクロザ（天墜の魔人アズラグの母）が、光り物と間違えて呑み込んでいた。ヴォルグリムは呑まれていた百年のことを話したがらない。作り手がもういないことを知っているのかどうかも、話さない。
- **二振りの釣り合い**〔秘〕：秩序の神と混沌の神が一振りずつ地上に置いた、という点で二振りは対になっている。どちらも、人間を助けるためではなく、筋書きを面白くするために置かれた。置いた者たちは、もういない。
- **聖刀白夜**：秩序の神ソラスが夢で命じ、八雲の刀鍛冶が打った刀。月喰いの宵姫を封じる要だったが、鬼の酒呑に奪われた。
- 二振りの代償の扱いは C1 #104（持ち主の決定：剣に代償は付けない）に従う。

## ゲームで明かす順番
1. **〔知〕一般人が知っている**：ヴェルムと三天神の名と、良い神々としての姿（上の「住人が信じていること」）。魔物界の奥に王がいるらしいこと。魔人がいて、剣も魔法も通じないこと。
2. **〔噂〕噂で知れる**：魔人の二つ名と居場所（一体ずつ）、赤い月の言い伝え、ハルガの帳面と年表の言い伝え、魔人を斬れる剣が二振りあるという言い伝え、魔王は眠っている／死んでいる／起きている、夜哭城の泣き声。
3. **〔進〕物語を進めて分かる**：遺跡の壁画（三柱の神と、それを見下ろす巨大な目）、ヴォルグリムの台詞、ユラが目を合わせずに「魔王さまはぐっすり寝てる」と言い張ること、灰色の外套の旅人と何度か出会うこと（正体はつながらない）。
4. **〔秘〕明かさない**：見世物、神々がもういないこと、仕組みだけが残っていること、魔王の座の仕組み、千年目、ヴォルグリムの本当の由来、夜哭城が空っぽなこと、**旅人が魔王であること**（用語説明にも載せない）。
