# 大きな迷宮の由来（W11）

迷宮の部屋・罠・宝・休み場・巣・最奥・背景は、ここに書いた由来から作る（持ち主「ダンジョンありきで設定を作るのではなく、設定からダンジョンを作ってほしい」）。
設定は [world.md](world.md) が正。古い docs（[history.md](history.md)・[curses.md](curses.md)・[majin.md](majin.md)）の呼び名は world.md の 18. で読み替える（ロゥム＝ルヴェナール、八雲＝シェルアーク、酒呑＝ゴズ、鏖殺の魔人＝黒鎧の使徒エンバルダ、侍＝剣士・武士）。
段階の印は [voice.md](voice.md) と同じ（〔知〕〔噂〕〔進〕〔秘〕）。〔秘〕はプレイヤーに見える文に書かない。迷宮の中のかけら（壁の刻み・日誌・亡者の言葉）は〔進〕で、潜るほど深い層が分かる。

仕組みは `src/engine/zw11_dungeon.js`、データは `src/data/dungeon_w11.js`（どの大きな迷宮にも使える部屋の型）と `src/data/dungeon_w11_places.js`（四つの迷宮）。背景は `src/ui/scene_v2_zw11.js`。

## 大きな迷宮と小さな迷宮
迷宮は 12 か所。物語の重さ（使徒・伝説の武具・名のある人物とつながるか）と危険度で、次の四つだけを**大きな迷宮**にした。ほかは**小さな迷宮**で、今までどおり「奥へ進む」だけ（階ごとの出来事・L1 の罠・W8 の脇道はそのまま）。

| 迷宮 | 選んだ理由 |
|---|---|
| 竜の墓場 `graveyard` | 伝説の武具（鉤槍ヴォルグリム）の眠る所。剣翼のヴァルグレアの母ネクロザ。骨の番の一族（ヴァルドゥン）。ルヴェナールの竜番という深い歴史がある |
| 黒鎧の使徒の居城 `majincastle` | 物語で会う使徒の居城。危険度がいちばん高い。眷属リゼ・元門番イズラ・果たし状（E10）とつながる |
| エルヴィナの地下墓地 `w1_catacomb` | 生き聖女（蝶翅のユヴァリエ）の企みの証拠がある所。中ボスの審問官ヴェスパ・墓守グレゴル・墓掘り修道士アンセルモ。王家発祥の古都の下 |
| 鬼ヶ島の洞窟 `onigashima` | 伝説の武具（明けの鎖）と、誓いを破った剣士が鬼になる道（人でなくなる）。シェルアークの若い衆・香煙のベリエラとつながる |

判断待ち：エル・ナフ遺構（`ruins`）は W12 の遺跡の設定と重なるので小さいままにした。W12 が `D.W11_DUNGEONS.ruins = { size: "large", … }` を足し、遺跡の部屋を `D.W11_ROOMS` に push すれば、同じ仕組みで大きな迷宮になる。

## 竜の墓場（`graveyard`）

**誰が・いつ・なぜ**：谷そのものは人が造ったものではない。断界山脈の北の端、風が一方向にしか吹かない深い谷。使徒が現れる前、古い国ルヴェナールの**竜番**たちが、名前で縛って飼っていた竜を、年老いると最後にここへ連れてきて看取った。竜番は谷の岩棚に石の見張り小屋と、骨を渡す石の橋と、死んだ竜の名前を骨に刻む作法を残した。竜番の石組みは、エル・ナフ遺構やエルヴィナの地下墓地のいちばん下の層と同じ手の技（〔進〕。どこまで同じかは W12 の遺跡の設定に合わせる）。

**何が起きたか**：幕引きの夜（元年）、ルヴェナールの民が消え、竜番もいなくなった。名前を呼ぶ者を失った竜は、名前を忘れはじめた。竜は名前を失うと長くは生きられない〔秘：古言で縛られていたから〕。大陸じゅうの竜が、教わってもいないのに、この谷へ死にに来た。いちばん古い王家の竜の一頭は、腹の中に**鉤槍ヴォルグリム**を掛けられたまま、百年ほど空を彷徨ってから谷に降り、骨になっても死にきれずに**屍竜ネクロザ**になった（報酬の文「腹の中から掛けられたまま百年」はこの百年。誰が鉤を掛けたのかは書かない〔余白〕）。ネクロザは剣翼のヴァルグレアの母〔秘：majin.md〕。

**なぜ魔物が棲むか**：竜の骨には、まだ温かいものがある（骨の奥でまだ何かが燃えている）。その熱に翼竜とキメラが卵を産みに来る。骨並べ（骨を拾って並べる、まぬけな骨好きの魔物）が骨の山に巣を作り、骨削りの墓荒らしを呪術師が雇い、夜番崩れが谷の口をうろつく。いちばん奥では、ネクロザが緑の火を眼窩に灯したまま、何かを歌うように首を振っている。

**いま誰が潜るか**：
- 骨削り（竜の骨と鱗を削って売る墓荒らし。竜鱗の鎧の出どころ）。仲間を出し抜くための仕掛けを谷のあちこちに残している。
- 骨の番（竜の血を引く山の民。ヴァルドゥンの一族）。墓荒らしを追い払い、谷を静かにしておく役目を、帰らない父から継いでいる。
- 巡礼と物好き（四百年ほど前から、肋骨の笛に名前と年を刻んで帰るのが度胸試しになった）。
- 学者（竜の肋骨の内側に、刻印の石碑の写しがあるという話〔噂：C9 の依頼〕）。
- 槍を探す者（竜の腹の鉤の噂）。

**世界とのつながり**：人と魔の境のいちばん北。ルヴェナールが竜を飼っていたこと〔進〕、名を失うと竜が死ぬこと〔進〕、鉤槍は人が作ったこと（E11）、ヴァルグレアが槍を憎むこと（ヴァルグレアの出来事）。

**階ごとのかけら**（潜るほど古い層。〔進〕）
1. 肋骨の笛の刻み：四百年前の巡礼の名前と年。その下に、もっと古い、読めない字の刻み。
2. 骨削りの帳面：どの骨が高く売れるか。「頭の骨の内側に刻まれた字のある骨は、なぜか高く売れない。誰も買わない」。
3. 竜番の見張り小屋の石の帳：短い古言の音（「ヴァ・エル」）と、竜を呼ぶ自慢。「我らが名を呼べば、竜は膝を折る」。
4. 名を刻んだ骨の列：骨に一頭ずつ刻まれた竜の名。最後の何十本かは、名前の欄が空いている。刻む者がいなくなったから。

**部屋が置かれる理由**
- 罠：骨削りが仲間を出し抜くために仕掛けた（骨の鳴子・肋骨の橋の切れ目）。谷そのものの危うさ（崩れる骨・熱い風の穴）。
- 宝の箱：竜は光るものを抱いて死ぬ（竜番が死に際の竜に宝を持たせた名残）。巡礼の供え物。
- 休み場：竜番の石の見張り小屋の跡。風の止む骨の陰。
- 巣：肋骨の籠に巣くう翼竜・骨並べ。
- 隠し部屋：竜番の物置（看取りの道具）。
- 最奥（背景）：**竜の骨の大広間**。谷の底が丸く抉れ、大きな竜の骨がいくつも輪になって眠る。天井の裂け目から一筋の光、骨の輪の真ん中の緑の燐火。

## 黒鎧の使徒の居城（`majincastle`）

**誰が・いつ・なぜ**：使徒が現れる前、人と魔の境のこの尾根に、昔の主〔秘：魔王〕の軍の**出城**があった。ルヴェナールの方を睨むための砦で、戦で倒した大きな獣と竜の骨を石の代わりに積み、鉄で留めて造った（骨と鉄の城、の始まり）。主の本当の城（夜哭城）は使徒領のずっと奥にあって、ここではない〔秘〕。

**何が起きたか**：幕引きの夜、主が死に、出城は主の兵とともに崩れた。長いあいだ骨と鉄の山だった。いつのころからか、昔の主の血をいちばん濃く受けた使徒、**黒鎧のエンバルダ**がここに来て、骨と鉄を拾い集め、城を組み直した。組み方はでたらめで、浮き彫りが逆さまになり、天井が床になっている所がある。エンバルダが組み直したのは、住むためではない。人と魔の境は、強い人間が通る所だから。門に「強い者のみ歓迎」の看板を掛けて、強者を待っている（字は眷属のリゼが書いた）。

**なぜ魔物が棲むか**：住んでいるのは魔物というより、エンバルダに負けて「負ける権利」を差し出し、眷属になった強者たち（黒鎧の従騎士・角兜の将・黒騎士）と、猟兵頭が飼う鎖の黒犬。リゼは、剣を交えた相手の名を帳面に書き留め、討たれた挑戦者の鎧に名前を書いて回廊に並べる。弱い者は相手にされず、外へ放り出される。

**いま誰が潜るか**：名を上げたい冒険者・帝国と王国の腕自慢（回廊の鎧の名）・黒鉄の砦の兵（果たし状。E10）・剣翼のヴァルグレアの縁を持つ者（抜け羽）・伝説の武具を手にした者。

**世界とのつながり**：使徒は昔の主の配下だった〔秘〕。絶界はエンバルダだけの守りで、主の血の名残（E11）。宿敵ヴァルグレア。人の手で使徒が倒れるのは久しぶり（報酬の年表）。

**階ごとのかけら**
1. 逆さの浮き彫り：天井に、ひざまずく兵の列が逆さに刻まれている。列の先の、玉座の大きな獣の顔だけ丁寧に削り取られている。
2. リゼの帳面の頁：剣を交えた者の名と、勝ち負けと、短い評。「よい。また来い」が多い。また来た者はいない。
3. 鎧の名：回廊の鎧の内側に書かれた名。いちばん古い鎧の名は、今の三国より古い国の字で書かれている。
4. （最奥）玉座の間：大小の椅子が向かい合う。大きい椅子の前に、小さい椅子が何度も運びこまれた跡。

**部屋が置かれる理由**
- 罠：エンバルダは罠を嫌う。罠は昔の出城の仕掛けで、城を逆さに組んだせいで、思いもよらない所で動く（天井の落とし穴、床から降る槍）。
- 宝の箱：討たれた挑戦者の遺品。リゼが帳面と一緒に、律儀に箱にしまっている。
- 休み場：**挑戦者の控えの間**。エンバルダは疲れた相手と戦っても面白くないので、リゼが水と黒パンを置いている（まぬけで憎めない）。
- 巣：眷属の兵舎・鎖の黒犬の小屋。
- 隠し部屋：昔の出城の武具庫。
- 最奥（背景）：**骨の玉座の大広間**。骨の柱が天へ伸び、壁の裂け目から使徒領の赤い夕空と山並みが見える。大小二つの椅子。

## エルヴィナの地下墓地（`w1_catacomb`）

**誰が・いつ・なぜ**：聖都エルヴィナは王家発祥の古都。光天教会の大聖堂より古く、王国（348 年）より古い。いちばん下の層は、誰が積んだか分からない古い石組みで、エル・ナフ遺構と同じ手の技に見える〔進。中身は W12 の遺跡の設定に合わせる〕。その上に、教会が聖都を開いたときから、聖職者と巡礼を葬る**納骨堂**を掘り広げた。死者は祈る形に手を組まされて壁に納められた。墓守は、死の神ハルガに仕える役目とされる〔知〕。

**何が起きたか**：何百年か前、大聖堂に**生き聖女**が現れた〔知〕。聖女に祈った巡礼は、本当に傷が治る。代わりに、祈るたびに何かが少しずつ吸われ、やがて干からびて死ぬ〔秘：蝶翅のユヴァリエが祈りを集めている〕。干からびた信者は、地下墓地へ下ろされた。墓守の老司祭**グレゴル**は、「聖女さまはまだお腹を空かせておられる」と信じ、死者に祈りを続けさせるために、死体を歩かせはじめた。死者の首筋から、光の糸が上へ、大聖堂の祭壇へ伸びている。真上の祭壇から、聖女の血が「聖餐の泉」に滴っていて、飲むと獣憑きになる。

**なぜ魔物が棲むか**：祈り殻（干からびた巡礼）、聖歌の髑髏、獣憑きの司祭（聖餐を受けすぎた者）、蝋燭かじり（祭壇の蝋を食う虫）。異端審問官**ヴェスパ**は、聖女を疑って地下へ証拠を探しに来る者を狩る。

**いま誰が潜るか**：墓掘り修道士（アンセルモ。疫病の年に千人を葬った）・行方知れずの巡礼の家族・副葬品を狙う墓荒らし・聖女を疑う者（証拠を集めて告発する。majin.md）。

**世界とのつながり**：光天教会と三柱の神への信仰〔知〕、生き聖女〔知〕と、その正体〔秘〕。王家発祥の都の、さらに古い層〔進〕。

**階ごとのかけら**（上の層ほど新しい）
1. 巡礼の名札：壁龕ごとの名札と、来た年。新しい名札ほど、骨が軽い。
2. 墓守の古い帳面：「献上した祈りの量」の欄。昔の帳面には、その欄が無い。ある年から、急に欄が増えている。
3. 骨の壁の文字：干からびる前の巡礼が爪で刻んだ「聖女さまはわたしたちを見ていない。空の上を見ている」。
4. いちばん古い層：手を組んでいない骨。祈る形に組まれる前の死者。壁の字は、教会の字ではない。

**部屋が置かれる理由**
- 罠：昔の墓守が墓荒らし除けに仕掛けた（香炉の眠り煙・名前を読む棺・崩れる骨の壁）。
- 宝の箱：家の紋のある副葬の箱（聖都の古い家は、地下に財を持たせて葬る）。
- 休み場：**小さな祭壇**。グレゴルが蝋燭を絶やさない。聖餐の泉の水は飲まない方がよい。
- 巣：祈り殻の列（祈りを続ける死者の群れ）。
- 隠し部屋：昔の墓守の隠し納骨所（教会の帳面に無い死者）。
- 最奥（背景）：**光の糸の大聖堂の根**。祭壇の真下の大空洞に、何千もの祈り殻が跪き、首筋から伸びる光の糸が天井へ吸いこまれて、星空のように光っている。美しく、おぞましい。

## 鬼ヶ島の洞窟（`onigashima`）

**誰が・いつ・なぜ**：シェルアークの南の、外海に突き出た岩の島。洞は潮が掘った天然のもの。シェルアークでは昔から、誓いを破った剣士を、刀を取り上げてこの島へ**流した**。誓いを破った者は、やがて角が生え、人でなくなる〔進：curses.md の「人でなくなる道」〕。最初に流された剣士がゴズで、流された者たちは洞を掘り広げて住み、鬼と呼ばれるようになった。

**何が起きたか**：流される剣士たちは、島へ渡る前の晩に、社から**明けの鎖**を盗んだ。社の鍛冶が、香煙の女（ベリエラ）を朧島に留めるために打った白い鎖で、夜明け前になると輪が鳴る〔秘：その音が煙を払う〕。鬼の頭目ゴズは、鎖を蔵の水の底に沈めた。鎖が島を離れて、ベリエラは目を覚ました〔秘〕。沈めても、夜明け前になると水の底から鎖が鳴るので、鬼たちは朝寝ができない。それで毎晩、朝まで飲んで騒ぐ。ゴズは酒の甕を覗いては「空だ。……また空だ」と言う。

**なぜ魔物が棲むか**：鬼（流された剣士のなれの果て）と、オーガ、抜け忍、提灯お化け。鬼たちは悪ふざけが好きで、洞のあちこちに子どもじみた罠を仕掛けている（落とし穴の底に「ばか」）。宴の灯に、煙の猫や賭場の用心棒（ベリエラの縁の眷属）が寄ってくる。

**いま誰が潜るか**：シェルアークの若い衆（度胸試し。入口に刀が七本立っている）・社の者（鎖を取り戻したい）・鬼が博打で巻き上げた銭を狙う者・流された身内を探す者。

**世界とのつながり**：誓いの重さ〔秘：仕組み〕と人でなくなる道、ソラスへの誓い〔知〕、明けの鎖と香煙のベリエラ（E11）、シェルアークの島ごとの顔役〔知〕。

**階ごとのかけら**
1. 洞の壁の名：流された剣士の名と、破った誓いが、刀の先で刻まれている。新しいものほど字が乱れている。
2. 鬼の数え歌：子分たちが太鼓に合わせて歌う。歌の中に、流された順の名前が数えこまれている。
3. 古い名の刻み：いちばん奥の壁に、ゴズの人だったころの名と、破った誓い。誓いの言葉だけが削られている。

**部屋が置かれる理由**
- 罠：鬼の悪ふざけ（筵の落とし穴・鳴子の綱で降る金棒・煙の甕）。
- 宝の箱：鬼が博打で巻き上げた銭と、流されるときに隠し持った刀の鍔。
- 休み場：宴の火の残り。潮の届かない岩棚。
- 巣：子分たちの寝床（いびき）。
- 隠し部屋：流された剣士が隠した、人だったころの持ち物。
- 最奥（背景）：**外海へ開いた大洞**。洞のいちばん奥が海へ口を開け、夜明けの光が水平線から洞の中まで差しこむ。大盃と酒樽、水の底で白く光る鎖。鬼たちが朝寝できない理由の景色。

## 書いたら確かめること
- 〔秘〕の中身（魔王・神々の不在・ユヴァリエの正体・ベリエラと鎖の関わり）を、見える文に言葉として書いていないか。
- 年の数字（四百年・百年）を地の文に数字で書いていないか（漢数字で書くか、ぼかす）。
- 竜番・ルヴェナールの石組みが、W12 の遺跡の設定と食い違っていないか（W12 の PR が出たら合わせる）。
