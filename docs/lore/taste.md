# 持ち主の好きな人物の型（taste）

持ち主が「他の作品の好きなキャラ」をまとめた表（39 人）から、**型と、どこが好きか**だけを抜き出したメモ。人物を作る子は、ここを指針にする（C4）。

- **作品名・キャラ名・固有の設定・台詞は、ここにも、ゲームにも書かない。** 一人の元キャラを写した人物は作らない。下の型を **二つ以上混ぜて**、この世界の住人（国・町・仕事・暮らし・悩み）として作る。
- 性的な好み（体つき・露出・情欲・セクハラ）は、ゲームでは**下品な笑い・ほのめかし・場面転換**にする。服は着ている。体つきは書かない（[voice.md](voice.md)）。
- 図鑑や紹介の文は口癖をそのまま書かず、「独特な喋り方をする少女」のようにぼかす。

## 好きな構造（いちばん大事）
- **ギャップ**：見た目・肩書きと中身が逆。強いのにだらしない／可愛いのに暴力最強／子どもの姿なのに年寄りで母のよう／粗暴なのに本と絵が好き／自信家なのにポンコツ。
- **失敗しても成功しても面白い**：調子に乗っても、絶望しても、何をしても絵になる人。話を転がしやすい。
- **ふざけている人が、急に真面目になる**：いつもは友達のような距離なのに、いざとなると腹を割って話す・本気を出すとめちゃくちゃ強い。
- **決めるところは決める**：完璧ではない、ダメなところもある。でも、ちゃんと立つ。折れても仲間のために立ち上がる。
- **信念が一貫している悪**：善ではないが筋が通っている。道化の役回りで、話を動かす。
- **敵の側にいるのに、こちらに理解がある**：格上なのに、妙に人に親身。頼れる。
- **報われなさが美しい**：民のために清濁を併せ呑んで頑張ったリーダーが、取り返しのつかない形で報われない。主人公が気ままに遊んでいた裏で、もう手遅れになっている。在りし日のささやかな日常（宝箱に目がない、など）がその対比になる。
- **不憫が魅力になる**：ずっと不憫な人。曇っている顔がかわいい。
- **周りが驚いてくれる**：伝説の人がそこにいると、周りがざわつく。連れていると気分がいい。

## 好きな型（混ぜる材料）
### 指導者・強者
- 民のために折れずに頑張る、清濁併せ呑む女のリーダー（知的・英雄・悲しき過去）。最後は報われない。
- 武闘派の王なのに民を思い、思慮深い。根は熱血で、困ったら殴りに行く。簡単には心が折れない。
- 現実主義の情熱家。味方とは思えない卑劣な手を平気で使う長。
- 折れても仲間のために立ち上がる軍師・リーダー。主人公の周りから一歩引いた位置にいる。仕事のできる味方。
- 欲望に忠実な小悪党だが、規格外の英雄。鬼畜だが性根は甘い（子どもに優しい・拷問は嫌い）。どんな卑怯な手でも使って強敵を倒す。
- 導く先輩のくせに考えなしに突っ込む。でもちゃんと強い。伝説の人がいると周りが驚く。
- 強いのに飄々とした師匠のおじさん。だらしなく、冗談に乗ってくれる友達の距離。いざ喧嘩をすると圧倒的に強い。ときどき真面目に、真の目的のために腹を割る。復讐者の顔も持つ。

### 智将・天才・技術屋
- 失敗しても成功しても美味しい智将。調子に乗っても絶望しても面白い。悲しき過去と復讐。
- 自信家の智将で王族なのに自由奔放。女の子にちょっかいを出すのが趣味（→ゲームでは下品な笑いで済ませる）。
- 自信家で大口を叩くのに、実際にすごい天才。車椅子なのに本人はまったく気にしていない。
- 最強の天才には及ばないと割り切って頑張る天才。後輩・苦労人・融通が利く。猫っぽい。
- 基本は無表情で、恐ろしいことを淡々と提案する毒舌のマッドサイエンティスト。苦労人なのに気にしないほどの天才。
- 糸目の悪巧み。隠そうともしない。でも根はいい奴だと分かっている。はんなりした話し方。

### お姉さん・女傑
- 調子に乗る妙な自信家の大人のお姉さん。密偵なのにポンコツで愛嬌がある。ドジでも調子こきでも面白い。
- おっとりしたお姉さん。すぐ騙されるお人好し。なのに覚悟を決めたときの芯が強い。
- 姉御肌の優等生なのにアホ。貧乏でウブ。ポンコツ風で実力は優秀な先輩。
- 有能で自立した女社長。たくましい。自分の容姿に自信があり、商品の顔も自分。
- 正統派のお嬢様。真面目でポンコツ。曇っているとかわいい。

### 少女・子どもの姿
- 男勝りの小さな女の子。ウブ。
- 生意気な妹分のヤンキー。兄貴分に懐く。
- 母ちゃん気質のツンデレの小さな子（ツンのさじ加減が大事）。
- 小さいのに母のよう。大和撫子。
- 気弱な天才。見た目だけで「どんな人か知りたくなる」。
- 可愛い見た目なのに暴力は最強クラス。すぐ勝手に傷ついて落ち込む。根はいい子。
- 真面目で堅物、めちゃくちゃ良い子。からかうと反応がいい。押しに弱い。
- 真面目な娘だが、いやしい（甘え上手で欲しがり）。病んではいないが、束縛は強い。
- 小さな強者の昼行灯。自分を年寄り扱いして呼ばせる。悲しき過去。やりすぎるとうざいので加減する。
- 儚いゲーマーのヒロイン。天然でクール。

### 上位存在
- 子どもの姿をした年経た上位存在（いわゆる、見た目は幼く中身は年寄り）。母のよう。人のことをとても思っている。わからせたくなる生意気さ。
- 強いのに妙に人間に親身で、元は敵側なのに味方に理解がある。頼れるお姉さんで優等生。
- 不意にすべてをひっくり返す強者の登場。何も着ていないような姿でも威厳がある（→ゲームでは服を着せ、威厳だけ残す）。
- おじさんと見せかけて、中から美少女が出てくる。強いのに妙におっとり。まつ毛ではっきり美人と分かる。
- 見た目とポジションだけで惹かれる、カリスマのある美人の上位存在。ミステリアスで我が強い戦闘狂。幼いころの姿も良い。

### 若い男・主人公格
- 愛すべきアホ。でも決めるところは決める、かっこいい。純粋。悲しき過去。完璧ではないが憎めず、ちゃんとリーダーをしている。
- 厨二で容赦ない。頭も良くて強い。粗暴なのに読書や芸術が好き。ボケもツッコミも面白い。行動の裏に悲しき過去があるので、嫌味にならない。
- 童顔の美少年の敵幹部。人形や糸を使い、傀儡で正体を隠す。

## 作るときの手順（C4 のやり方）
1. 型を二つ三つ選ぶ（なるべく別の段から）。一つは「ギャップ」になるように。
2. この世界の人にする：国（王国・帝国・共和国・シェルアーク・使徒領）・町・仕事・家族・好物・癖・その日の用事（[voice.md](voice.md) の人物の作り方）。
3. 悲しい過去や秘密は**断片で**：覚えていること（memo）・独り言・持ち物の説明。答え合わせをしない。
4. 好感度の始まり（−100〜+100）を決める。生意気・警戒する人はマイナスから。
5. 見た目は固定（髪の色2語・髪型・目・体格・服・持ち物）。男は型（`ojisan` を多めに、`brute`・`bishonen`・`classic` も）。
6. 名前は国の響きで（王国は南欧〜仏風、帝国は北の硬い響き、共和国とエルフは柔らかい響き、シェルアークは島の響き）。元の作品の名前に似せない。

C4 で作った人物の一覧は `src/data/c4_people.js` の `D.C4_PEOPLE`（どの型を混ぜたか `mix` を書いてある）。
