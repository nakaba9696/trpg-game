# 世界をどう見せるか ―― 明かす段階と、手引きの見直し案

持ち主の方針（#1 のコメント）：
- はじめて遊ぶ人が困らないように、世界観は**少しずつ察せる**ようにする。手引きや地の文で一度に説明しない。通行人のひとこと・張り紙・墓標・落書き・物の説明・敵の台詞・噂から分かるように。
- ただし、冒険を始めるのに要る**導入**（何者で、どこで、何を目指すか、最低限の世界の状況）は、ちゃんと説明する。
- **すべてを説明しない。** 最後まで遊んでも分からないこと、人によって言うことが食い違うこと、断片しか残っていないことを、わざと残す。

> このファイルはレーン D（世界観）が管理する（D3）。**U3（#48）の子**が、導入・通行人の台詞・調べられる物を作るときの元にする。直すのは U3。ここは案だけ。
> GM 向けの裏設定（`D.LORE_GM`・`D.MAJIN` の `secret`）と `docs/lore/` は、詳しくてよい。プレイヤーに見せる文（手引き・地の文・出来事の文）は、断片と匂わせにとどめる。
> **D4（#75）から、世界の入口と正は [world.md](world.md)。** 各設定の段階は world.md とその先のファイルに〔知〕〔噂〕〔進〕〔秘〕の印で付けた。下の表の「導入・匂わせ・断片・明かさない」と同じ意味。語りの書き方は voice.md（U3）が正。
> 持ち主の方針（2026-10-01）：**一般人は上位の存在を知らず、神は良いものだと信じている。それを説明する人物は出さない。一人一人に生活がある人を出す。説明しない。断片から察させる。** 用語説明は、物語の中で知ったことだけが載る（下の「用語説明」）。

## 明かす段階

| 段階 | 印 | 意味 | どこで見せるか | 書き方 |
|---|---|---|---|---|
| **導入** | 〔知〕 | この世界の一般人が知っていること | 始まりの導入、最初の町の施設、手引きのはじめ、通行人の世間話 | はっきり、短く。住人の目線で |
| **匂わせ** | 〔噂〕 | 噂で知れること | 通行人のひとこと、張り紙、墓標、落書き、物の説明、酒場の噂、敵の見た目 | 一行。説明しない。固有名詞は文脈で分かる形で |
| **断片** | 〔進〕 | 物語を進めて分かること | 迷宮の壁画・碑文、古い日記、敵の台詞、魔人との会話、ボスを倒したあとの文 | かけらだけ。人によって食い違ってよい。答え合わせをしない |
| **明かさない** | 〔秘〕 | 決して明かさないこと | どこにも出さない（`docs/lore/` と GM 向けの裏設定だけ） | ― |

- **固有名詞の出し方**：はじめて出る名前は、文脈で何となく分かる形にする。
  - よくない：「十三魔人の一体、享楽のミルザが現れた」
  - よい：「日傘の少女が笑った。周りの人々が、糸で吊られたように踊り出す。誰かが叫んだ。『享楽の……！』」
- **食い違い**：同じことを、通行人ごとに違うように言わせる（教会・学者・酒場の老人・子ども）。どれが本当かは書かない。
- **先へ進むほど深く**：最初の町と最初の数日は、身近なこと（宿・酒場・依頼・近くの魔物）だけで遊べるようにする。魔人と神々は、遠くの噂・壊れた町の跡・怯える人として、ちらりと見せる。

## 導入で説明すること（これだけ）
1. **あなたは何者か**：職業と人物設定（今の作成画面のまま）。
2. **どこにいるか**：始まりの町の名前と、どんな町か（一文）。
3. **何を目指すか**：目的（今の作成画面のまま）。
4. **最低限の世界の状況**（三、四文。例。導入は U5 #63 が作る）：
   > ヴェルド大陸。東の山脈の向こうは魔物の土地で、人の三つの大国は砦でそれを食い止めながら、協定を結んだまま互いににらみ合っている。
   > 国と国のあいだには、「あれ」の縄張りがある。人は道を曲げ、畑を移し、見張り塔の鐘を数えて暮らしている。ときどき、剣も魔法も通じない「魔人」が、町をひとつ気まぐれに消していく。
   > あなたにできることは、たぶん、そう多くない。それでも、今日から冒険者だ。
   - 導入に使ってよいのは [world.md](world.md) 1. の「表」と 2. の〔知〕だけ。
5. **遊び方**：最初の数手番で、実際にやる場面で短く（判定の見方は、最初の判定のときに一度だけ）。

- 導入で**言わない**こと：神々が世界を見世物にしていたこと・もういないこと（言葉としても書かない）、**魔王という存在そのもの**（今の人は知らない）、二振りの剣の由来、十三という数、七十二という数、異形という言葉とその正体、古王国ロゥム、世界樹の正体。
  - 例外：目的が「魔人を討つ」「伝説の剣を得る」のときは、導入で「魔人を斬れる剣が二振りあるという言い伝え」だけを一文足す（目的の説明に要るから）。

## 今の手引き（`src/data/world.js` の `D.WORLD`）の見直し案

今の手引きは、はじめから全部読める。D1・D2 で足した分も含めて、説明が多すぎる。**直すのは U3。** 推しの案：

| 今の節 | 今の問題 | 見直し案 |
|---|---|---|
| `intro` | 「強い者が好き勝手に…」まではよいが長い | 導入の三、四文（上の例）に置き換える |
| 上位存在（創世神・三天神・魔王の座） | 「世界は神の見世物」「魔王の座は神々が選ぶ」は**人間が知らないはずの秘密**。手引きに書くと矛盾する | 手引きからは外す。三天神の名だけ、教会で聞ける噂にする。魔王の座と見世物は GM だけ（**明かさない**〜**断片**） |
| 魔王と魔人 | 「十三体」「魔王の血」「使徒の作られ方」まで書いてある | 「魔王がいる」「魔人がいて、剣も魔法も通じない」だけ残す。残りは噂で |
| 絶界を破るもの | 二振りの名前と性格まで書いてある | 「魔人を斬れる剣があるという言い伝え」だけ。名前は噂で |
| 知られた魔人（三体） | 一度に三体の説明 | 外す。酒場の噂・出来事で出会う |
| 人の国（六つ） | 導入には多いが、地図と旅で要る。D4 で国の形が変わった（王国の国王と七人の子、帝国の四騎士と皇女、ゼファラは共和国） | 残す。ただし一文ずつ短く、[world.md](world.md) 4. の〔知〕に合わせる。行ったことのない国は「名前だけ」でもよい |
| 魔物 | よい | 残す |
| 噂に聞く魔人（D1・十体） | 最初から十体の噂が全部読める | 外す。**聞いた噂だけが手引きに増える**ようにする（酒場で聞いた噂を `S.heard` などに記録して、手引きに「聞いた噂」として並べる） |
| 神々の言い伝え（D1） | 赤い月・賽子・帳面は、よい匂わせ。ただし一度に並ぶ | 聞いた噂と同じ扱いにする。教会・賭場・墓地で聞いたら増える |
| 古い言い伝えと呪い（D2・八件） | 明けずの町・獣憑き・魔剣の渇きなど、先の話を最初から全部見せている | 外す。聞いた噂と同じ扱いにする |
| キャラクター作成の冒頭の文（`src/ui/setup.js`） | 「その上では、神々が世界を見世物として眺めている」は明かさないはずの秘密 | この一文を外し、導入の四文にそろえる |
| 判定のしくみ | 遊び方の説明として要る | 残す（手引きの一番上に移してもよい） |

- **手引きを「聞いた噂の帳面」にする**（推し）：手引きは、はじめは「導入の四文・人の国・魔物・判定のしくみ」だけ。旅の途中で噂や言い伝えを聞くたびに、項目が一行ずつ増える。埋まらない項目があってよい。
- データの形の案：`D.WORLD.sections` の各行に、見せる条件を付ける（例：`["赤い月", "…", { heard: "red_moon" }]`）。条件の無い行は今までどおり、はじめから見える。古いセーブで `S.heard` が無くても動くように。
- GM（`D.worldPrompt()`）には、今までどおり全部渡してよい。GM には「プレイヤーに一度に説明しない。断片だけを出す」と一行添える（下の `LORE_GM` の D3 の行）。

## 用語説明 ―― 分かったことだけ載る（U3 向け）

持ち主の方針（2026-10-01）：「世界観も物語を進めてわかったことだけ用語説明に追加していってください」。
- はじめは〔知〕の用語だけ。世界観の項目は、プレイヤーが物語の中で知ったときにはじめて載る。載る文も、そのとき分かったことだけ。知るたびに一行ずつ書き足してよく、食い違う行が並んでもよい。真相をまとめて書く項目は作らない。
- **はじめから載る用語・きっかけで開く用語・最初の一行と書き足される行の例は [world.md](world.md) 14.**（上の「手引きを聞いた噂の帳面にする」案を、用語ごとの表にしたもの）。
- 七十二の異形は、会った・聞いたものだけを開く。呼び名で開き、刻印の読み（学者の名）は〔進〕で書き足す（[igyo.md](igyo.md)）。

## わざと残す余白（最後まで分からないこと）
作る子は、ここに挙げたことの**答えを書かない**。
- 閉じ月は、創世神の眼なのか、別のものなのか。
- 神々は死んだのか、去ったのか（D6。そもそも「いない」とはプレイヤーに書かない）。
- 灰色の外套の旅人は、何者なのか（D6。GM も決めない）。
- 誰が・どうやって魔王を殺したのか。本当に死んだのか（D6）。
- 刻印の環の、空いた枠と、彫りかけの剣を持った小さな人の形は、誰なのか。
- 光の壁の向こうに、何が見えたのか。
- ヴォルグリムが、屍竜の腹の中の百年のことを話さない理由。
- 魔人は本当に十三体なのか（名前の伝わらない魔人がいる、という噂だけ残す）。
- 古王国ロゥムが滅んだのは、神の罰か、異形のせいか、自分で呼んだのか。
- （D4 で追加。全部の一覧は [world.md](world.md) 13.）国王ヴァレオンが若返った本当の理由、帝国の皇帝の病は誰の仕業か、眠り子を眠らせたのは誰か、討たれた異形は本当に死んだのか。
