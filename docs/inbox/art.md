# 絵のセッションへの指示（配り役が書く）

絵のセッション（手元の PC）は、このファイルを定期的に読み、「未着手」の指示を上から順に行う。終えた指示は、下の「済み」に移して push する（このブランチ art-inbox に）。
配り役はクラウドから手元のセッションへ直接は送れない（Remote Control のセッションには本人かそのセッション自身しか予約を作れない決まり）ため、ここで受け渡す。

ブランチ fix-moods-1 の上で行い、同じブランチに push する。

3. **残す全部を目視する（持ち主「キャラの表情はキャラを表す重要なものですし、変な表情やゴミがまざってると没入感をそこなうのでちゃんと作ってほしい」）。** 顔の窓の四角（src/data/u41_face_box.js）を拡大し基本と並べた表で、残す一枚一枚を自分の目で見る。表情の自然さ・目の焦点・ひげ・眼鏡・前髪・傷・マスク・手・ゴミ・にじみ・つぎはぎ・輪郭の二重・透過の縁。少しでも怪しい物は消す。
4. node tools/build.mjs && node tests/run.mjs を通す（表情の決まりのテストは、喜怒哀楽がそろっていなくてよい形に直してある）。
5. 「済み」に、何人・残した枚数・消した枚数（理由ごと）を書いて push。
