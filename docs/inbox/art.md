# 絵のセッションへの指示（配り役が書く）

絵のセッション（手元の PC）は、このファイルを定期的に読み、「未着手」の指示を上から順に行う。終えた指示は、下の「済み」に移して push する（このブランチ art-inbox に）。
配り役はクラウドから手元のセッションへ直接は送れない（Remote Control のセッションには本人かそのセッション自身しか予約を作れない決まり）ため、ここで受け渡す。

## 未着手

### 2026-10-14 顔だけを大きく作るやり方の試し（持ち主「キャラタグ＋表情で作れる気がする」→「お願いいたします」）
上の「fix-moods-1 の仕上げ」が終わってから行う。WebUI を使うので、持ち主がメモリを使うと言ったら止める。
1. **道具の確かめ**：WebUI に ControlNet（lineart・reference・openpose など）と IP-Adapter（顔の手本）が入っているか、入っているモデル名と一緒に「済み」に書く。無ければ入れ方と必要な容量を書き、入れるのは持ち主に聞いてから。
2. **1 人で試す**（表情の差がはっきり要る人：nora を推し。崩れの多かった otmar か aubin（ひげ）をもう 1 人）：
   - 顔の窓の四角（src/data/u41_face_box.js）を基本の絵から切り出し、512 に拡大する。
   - その顔に、docs/art/portraits.json の identity・tags と表情のタグ（variants）で、顔全体（輪郭・頬・顎・目・口）を描き直す。ControlNet（基本の顔の線画）で輪郭と向きを、IP-Adapter（基本の顔）で同じ人の顔を保つ。髪・ひげ・眼鏡・傷・小物は基本と同じに（守る所は戻す）。
   - 出来た顔は、全身の絵には戻さず、顔の窓専用の絵として assets/portraits/faces/<id>_<表情>.webp に置く案で（置き場所は配り役が画面側と合わせる）。
   - 喜・怒・哀・楽と、その人らしい表情 1 つを作り、今のゲームの顔（顔の窓の四角）と並べた表を作る。
3. 生成の値（seed・ControlNet の重み・IP-Adapter の重み・denoise）は docs/art/gen/<id>_face.json に残す。push 先はブランチ face-trial-1。
4. 「済み」に、道具の有無・試した人・自分の目で見た所感（輪郭・同じ人に見えるか・表情の強さ）を書く。
