# 仲間の口調の表（K10）

持ち主の声：「急に『お前』とか言い始めた。キャラの口調は統一してください。打ち解けるとくだけるのであればそれでいいですが、文章量が少ないので仲良くなる過程が分からず混乱します」

- データ（テストが読む表）：`src/data/k10_voice.js` の `D.K10_VOICE`。**この文書と食い違ったら、データが正。** 値は各人の設定（`c?_people.js` の memo・note・talk、`talk_<id>.js` の頭の「口調」）に従う。
- 仕組み：`src/engine/zzzzzzzzz_k10_voice.js`。呼び方が変わる場面：`src/data/zk10_scenes.js`。
- 確認：`tests/checks/k10_voice.mjs`（台詞の集め方は `tests/k10_lines.mjs`）。

## 決まり
1. **台詞の一人称と、主人公の呼び方は、表の通り。** 表にない一人称・呼び方は出さない。「その他の呼び方」は、ほかの仲間・子ども・敵に向けるもの（主人公には使わない）。
2. **段で呼び方が変わる人（下の表で「段」に書いた人）だけ、好感度で呼び方が変わる。** 変わるのは、その段の「変わる場面」を聞いてから。場面は、好感度が段に届くと、会話（話す）の話題の一覧のいちばん上に出る。好感度が段より下がれば、前の呼び方に戻る。
3. 段で変わる呼び方は、場面の外の台詞に**生で書かない**。`{U}`（会話・出来事の主役の仲間の今の呼び方）か、`{U:id}`（掛け合いの部品など、話し手が決まっている文）で書く。だから、くだける前に、くだけた台詞は出ない。
4. **仲間をひとり選ぶ出来事（M2・M10・M11・信頼の出来事など、だれが選ばれるか分からない文）の台詞**は、一人称を `{I}`、呼び方を `{U}` で書く。語尾は `{v:くだけた|丁寧}`（表の「丁寧」の人は後ろ）か、だれが言ってもおかしくない形（「……なんでもない」）にする。「〜ねえよ」「お前」を地の文のまま書かない（持ち主が見た「お前が無駄遣いしなきゃ」は、これだった）。
5. 台詞の中の『』（ほかの人の言葉の引き写し）と（）（仕草）は数えない。人の言葉を引くときは『』で囲む（「『お前のだ』って」）。
6. 例外（表と違って見えるが、そのままにする台詞）は `D.K10_VOICE_EXCEPT` に理由つきで書く。ほとんどは、地の文で話し手を書いていない、名の無い人の台詞。

- ミルレーネ（30）：「わたし、ずっと『あなた』とお呼びしているでしょう。お屋敷の作法なの。……{you}さん、とお呼びしても、いいかしら。……変じゃない？」
