# 隠れた罪（Q8）

持ち主の声「悪名は誰かにバレなければ上がらないようにして」。仕組みは `src/engine/zzzzzzz_q8_hidden.js`、数は `src/data/q8_hidden.js`（`D.Q8H`）。

- 罪（`G.crime`：裏路地の盗み・イカサマ、出来事の悪行、衛兵殺し）を犯すと、その場で**見られたか**を決める。
  1. 人目に入るか：罪の見つかりやすさ（seen）× 場所（町 1.3・荒野 0.6・迷宮 0.4）× 夜（0.6）
  2. 人目に入っても、罪ごとの能力の判定（`G.chance`）で紛れれば、成功率 × 0.7 の見込みで気づかれない
- 見られたら、その場で悪名が上がる（「誰かに見られた。」）。見られなかったら「隠れた罪」（`S.q8hid`）として残る。
- 隠れた罪は、日が変わるたびに発覚するかを決める。発覚する見込みは「発覚の強さ（later）＋口の軽い仲間 × 0.15」× 0.12 × 0.85^（たった日数）。好感度の高い仲間がいれば × 0.7（かばう）。60 日たったら、もう発覚しない。発覚すると一行（「盗品を流した先から、足がついてしまった。」など）と年表に残し、悪名が上がる。
- 罪の匂い（`S.sin`）と犯した行い（`S.q8deeds`。恋人の条件）は、見られなくても残る。
- 悪名の上がり方の数（「〇〇での悪名 +6」）は、今までどおり画面の案内（記録の sys の行）で出る。物語の文には数を出さない。

罪ごとのバレやすさ（盗賊・ふつうの振りの人物で計算。その場で見られる割合は「町の昼／町の夜／荒野の昼／荒野の夜」、あとで発覚する割合は隠れた罪が 60 日のうちに発覚する見込み）：
