# R4：プレイレビューの点検（目的の導線・行動の返り・記録・正気・目的達成後）

第三者のプレイレビューを受けて、今の実装を確かめた記録。方針は「点検が先、変更は本当に必要な所だけ」。新しいクエストや目的の仕組みは足していない。
「成功率と選ぶ理由」は S8 の担当なので見ていない。

確かめ方：`dist/site` を charset=utf-8 付きで配り、Playwright（Chromium・1280×860）で「はじめる → おまかせのまま旅立つ → 導入 → 最初の町」を通した。そのあとは画面の上で行動を数百回進め、正気・目的達成は状態を書き換えて再現した。エンジンは `tests/lib.mjs` の `loadEngine` で直に動かした。

## 1. 目的の導線（F2・R3・噂・依頼の印）：点検した結果、十分（変更なし）
- 導入の最後の頁で目的を言い切る（「目指すのは、伝説の剣を手に入れること」）。最初の町の行動の欄のいちばん上に、因縁の名の組（「錆びた鍔」「笑う証文売り」など）と、R3 の「気になること」が出る。
- 因縁の一段目を選ぶと、記録に「依頼『錆びた鍔』を引き受けた。（右上の「依頼」で見られる）」、次の段の行き先は「『錆びた鍔』の行き先：迷いの森」と出る。依頼の窓には因縁・ギルドの依頼・噂（続きがありそうな所・人つき）が並ぶ。
- 行き先の手順や答えは出ない。どこへ行くかはプレイヤーが決める形が保たれている。
- 目的そのものは「ステータス」の「能力」の表の頭（「目的」の行）にある。依頼の窓には目的の行は無いが、因縁と噂が導線になっているので足していない。

## 2. 選んだ行動が後で返ってくる：一か所だけ補った
- 働いているもの：F4 の覚え（見逃した・助けた・見捨てた相手が、日がたって別の町で現れる。「あのときの…」の一文に印）、町の空気（着いた文・通行人・施設・値段）、F2b の因縁の続き、M12 の世の大事の傷あと（墓碑にも残る）、評判と悪名、仲間の好感度、R3・L1 の墓碑の手がかり、前の冒険で獣になった者。
- 足りなかった所：F4 の返りの出来事 33 件は、起きた場面の記録には一文が出るが、**年表には何も残らなかった**（年表に書くのは echoChron のある F2b の 10 件だけ）。年表は墓碑からも開くので、「あのとき見逃した子が、あとで返ってきた」が一代の記録から抜けていた。
  - 直し：返りの出来事が起きたとき、覚えの名（`D.ECHO_KEYS` の name）と町の名から「港町ヴァレンツァでスリの子を見逃したことが、王都レオネストで返ってくる」の形の一行を年表へ（`src/engine/zzzzzzzzzzzz_r4_echo.js`・`src/data/r4_echo.js`）。echoChron のある出来事はそちらだけ。
- 前の冒険者の痕跡：今の冒険の世界に出てくるのは「前の冒険で獣になった者」だけ。図鑑の過去の行・覚え書き（L1）・C9 の「前の冒険の覚え書き」はあるが、町や人が前の冒険者を覚えている形は無い。冒険ごとに世界はやり直す決まりと、「前の冒険で行った場所は表示しなくていい」（W5）の持ち主の声があるので、今回は足していない（下の「今後」）。

## 3. 情報量と UI（メモ・噂・依頼・年表）：点検した結果、十分（変更なし）
- 依頼の窓：受けている依頼（状態・依頼主・受けた町）と噂（続きがありそうな所・相手・日付・新しい印）。噂が入ると記録に「噂を書き留めた。続きの手がかりは、右上の『依頼』の噂の欄に」。
- ログの窓：記録の全部（判定の出目・成功率つき）。年表：ステータスの「年表」・墓碑から。図鑑：魔物・人物・用語の「聞いた話」。
- 出来事の `memo`（あらすじ・行き先）は画面に出さない。これは V12 の持ち主の声（「プレイヤー自身が覚えればいいものは書かなくていい」）による決定なので変えていない。
- 謎の説明は増やしていない。

## 4. 正気が低いときに選んだのと違う行動をする：直した
- 仕組み（崩れかけで、押した行動が同じ欄の別の行動に入れ替わる見込み）は変えていない。
- 見つけたこと：入れ替わりの一行（「手が、勝手に別のことをしていた。」）が、入れ替わった行動の「あなた」の行より**前**に書かれていた。PC の本文の欄（`ui/v9_pc.js`）は最後の「あなた」の行より前を隠すので、この一行は**画面に出ていなかった**。頁の頭には押したボタンの名（例「▶ 宿屋」）が出て、その下に「▶ 商店に入る」が続くため、押し間違いか不具合に見えた。
- 直し（`src/engine/sanity_m5.js`・`src/data/sanity_m5.js`）：入れ替わった行動の「あなた」の行のすぐ後に、何をするつもりだったかの地の文（「『宿屋』と決めて、歩き出したはずだった。気づくと、足は別のほうを向いていた。」など三つ）と、短い一行「正気が削れて、選んだのとは別のことをしていた。」を出す。「あなた」の行を書かない行動では、その行動の頭に、した行動の名と一緒に置く。印は行動の前に付けるので、判定の振り直し（M7）でやり直しても同じ行が出る。
- 正気が崩れかけに落ちたときの前触れ（「自分の手が、自分の手に見えない。動かすと、少し遅れてついてくる。」）とステータスの「正気」の行はもとからある。

## 5. 目的達成後：つなぎを補った
- 「ここで物語を終える／旅を続ける」（M6）はそのまま。節目の場面の文は十分に書かれている。
- 足りなかった所：「旅を続ける」を押したあとは「あなたは荷を背負い直した。まだ、歩ける。」と案内の一行だけで、まだ途中の因縁・依頼・世の大事があっても、それに触れなかった。
- 直し（`src/engine/zzzzzzzzzzzz_r4_goon.js`・`src/data/r4_goon.js`）：続けたとき、今の冒険でまだ終わっていないことを地の文で一〜三行。因縁（行き先の町）・まだ返ってきていない覚え・聞いた世の大事（決着の前）・受けたままの頼みごと（名前に数字のあるものは飛ばす）、仲間がいれば一行。何も無ければ「地図の端には、名前しか知らない土地がまだいくつもある。」。新しい目的・依頼は作らない。

## 今後検討する価値がある所（今回は変えていない）
- 前の冒険者の痕跡：獣になった者のほかに、前の冒険者の墓碑（名前・死んだ町）を、その町の通行人のひとことや墓地の出来事でまれに出す余地はある。世界はやり直す決まり・W5 の持ち主の声と合わせて、持ち主が決めること。
- 年表の中身：トロフィー・初めて行った町・技を覚えた行が多く、出来事での選択は F4 の返りと世の大事くらいしか残らない。迷う選択（F4 の `f4d_*`）を選んだ時点でも年表に残すか、は検討してよい。
- 依頼の窓に「目的」の一行を置くか（今はステータスの「能力」の表の頭だけ）。
- 正気の入れ替わりは出来事の選択肢でも起きる（もとから）。重い選択（命や仲間に関わるもの）でも入れ替わってよいかは、持ち主の判断の余地がある。
