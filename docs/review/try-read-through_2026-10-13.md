## 1. 全体の講評

**心が動いた所**
- 第一章の広場（e7m_2）。排水の溝の中身と「桶は二杯目だった」。被害を数で言わず、掃除の手間で見せていて、これだけで使徒の格が分かる。
- パン屋のマチュー（e7m_2 の靴を返す道）。「右から踏み出す癖があった」。入口で靴売りが言った「右足から踏み出す癖のある子」（品の説明）が、父親の口から同じ事実として戻ってくる。
- 第三章のベルトランとミュゼット（e7m_6「ベルトランに任せる」）。剣を抜かずに扉を三回叩く。「絵描きだ」と言い直す掠れ声。
- 第五章の最後の糸のベルトラン（e7m_9_last）。前夜の「見るな。描きかけだ」が「勝った顔。……前の晩に、先に描いといた」で閉じ、「目だけが、まだ入っていなかった」で弟子の絵と重なる。この長編でいちばん強い。
- 終章のリュドガー。「最後の小節で、拍子がひとつ抜ける。跳ねていた子どもたちが、そこでつまずいて、転んで、笑った」。第一章で張った「止めるための曲」が、笑いで回収される。

**止まった所**
- 第四章（備え直す）。五つとも「町に行く→主に会う→金か日数か判定で払う→一行の手応え」の同じ形で、二つ三つ続けると目録になる。鉄鍋団だけは人柄があって止まらない。
- 一度目の対面（e7m_7）の若君の長台詞二段。「虫かごの虫」「人のいちばんいい顔を見せてあげている」と、主題を本人が説明する（NOV-21）。直前の「茶碗の中身は灰だ。男はそれを、うまそうに飲んだ」で足りている。
- 最後の糸（e7m_9_last）の頭で、若君が仕組みを二段かけて説明する所。選択肢の前提なので要るが、長い。

**回収していない物**
- **清い結末（clean）で、ベルトランとミュゼットのその後が一行も無い。** 主な筋（皆が生きる道）のいちばんの報いの場面で、ベルトランの「帰ってきたら、また付けで飲む」「勝ったら、お前の顔を描かせろ」も、ミュゼットが人形に戻らずに済んだことも拾われない。終章 e7m_10 の clean の文は、フィーネとリュドガーとブロンベルクだけ。
- 一度目の対面でベルトランが死んだとき、灰に突き立った剣（「取りに戻れる場所ではない」）。第五章で同じ庭へ戻るのに、剣のことが出ない。
- フィーネに「どんな顔だったか教えて」と頼まれる約束は、clean の終章で拾われている（良い）。ほかの結末では拾われない。

**いちばん直すべき三つ**
1. 清い結末（主な筋）の終章に、生き残った仲間（ベルトラン・ミュゼット）の一行ずつを足す。
2. 分かれ道によって数・知っていることが崩れる所（「三度目だった」、ミュゼットが知らないはずの「階段の三段目」、子どもの父親が知らないはずの「町の顔」、フィーネの母の靴が片方先に町にある）。下の 4. の表。
3. 一度目の対面の文に、若君の胸の内を地の文が言う所（`e7_0_saga.js` の `toy.held`「若君は、倒れた顔より、立ったまま泣く顔のほうが好きなのだ」）。voice.md の「使徒の胸の内は書かない」に反する。

**骨は立っているか**：立っている。噂 → 現場 → 調べる → 仲間 → 負ける → 備える → 決戦 → 誰が払うか、の芯が通り、仲間三人それぞれに「払う」結末があって、選んだ道が最後に効く。直すのは主に分かれ道の継ぎ目。

## 2. 章ごとの要約

- **入口 広場の音楽（e7m_1）**：どこかの町の酒場で、靴売りのコルネリウスが芸の町サリュエスの三日三晩の踊りを語る。底の抜けた子どもの靴を押しつけられる。
- **第一章 踊りのあと（e7m_2・e7m_2b）**：サリュエスの広場。擦れた敷石、排水の溝、刺さったままの日傘で木戸銭を取る会頭ブロンベルク。日傘の骨を折り取る／靴を返す／会頭を蹴る。夜、弦弾きのリュドガーから綱の上の娘フィーネと「止めるための曲」の話を聞く。
- **第二章 糸の出どころ（e7m_3_lib・_old・_rope・e7m_4・e7m_4b）**：写本の町メルヴィの記録（骨を折れ、一本では足りぬ）、峠の庵ザレムの老婆ヴィルマ（糸は顔から掛かる）、商都ブランデールの糸屋ロザ（十年前、酒場の二階の絵描きが同じ糸を持ってきた）。絵描きベルトランが加わり、サリュエスから歩いてきたフィーネが付いてくる。
- **第三章 灰の荒野へ（e7m_5・_5b・_6・_7・_7_after）**：断界山脈を越えた斜面の「ポチ」の村、笑い面の侍従、日傘の庭と人形の客。人形師の娘ミュゼットがベルトランの弟子だと分かる。一度目の対面で若君に弄ばれて負け、尾根で目を覚ます（フィーネは吊られて連れ去られる）。
- **第四章 備え直す（e7m_8_*）**：闘技の都ザルグロスの鈴の糸、鍛冶の都ドランヘルツの糸断ちの刃、首都エルメシアの糸返しの陣、傭兵の町グラッツの鉄鍋団、峠の庵の顔の漆。二つ以上で決戦へ。
- **第五章 日傘を閉じる（e7m_9・_9a・_9a2・_9b・_9c・決戦・_9_last／_9_flee）**：前夜の焚き火、踊り手の列、綱の上のフィーネの救出、ミュゼットの縫い留め、日傘の下の若君。骨をすべて折ると、町につながる最後の一本が残り、誰がその重さを持つかを選ぶ。
- **終章 糸のあと（e7m_10）**：音の戻ったサリュエス。結末ごとに広場の真ん中へ日傘の骨を埋める。
- **返ってくる出来事（e7r_*）**：骨を取り返しに来る侍従、村の寡婦、跳ねてきた男。

## 3. 章ごとのいちばんの場面（直すときに壊さない目印）

- **入口**：「コルネリウスは靴を卓に置き、指で押しやった。押しやった先に、あなたがいた。」（e7m_1）
  - 噂を聞く場面が、主人公に物を渡す場面に変わる一行。説明なしに「あなたの話」になる。
- **第一章**：「噴水の排水の溝が、詰まっていた。剥がれた爪。擦り切れた靴底の革。足の指の先が、何本か。……掃除の男が、火箸で溝の中身を桶に移していた。桶は二杯目だった。」（e7m_2）
  - 惨状を乾いた筆で（柱 A）。最後の「二杯目」で量が分かる。
- **第二章**：「余白に書いた人は、どうすればよかったかを書きます。たいてい、手遅れになってから」（e7m_3_lib、ヒルデ）／「わしは、笑うのに五十年かかった」（e7m_3_old、ヴィルマ）
  - どちらも手がかりを渡す人に、その人の暮らしと傷を一つずつ持たせている（voice.md の人物の作り方）。
- **第三章**：「子どもの札には『ポチ（小）』。」（e7m_5）と、「絵描きだ」ベルトランは言った。声が掠れていた。咳払いをして、言い直した。「絵描きだ。お前の顔を、描きそびれててな」（e7m_6）
  - 前者は笑いの形をした一番重い一行（柱 A・D の同居）。後者は「大事なことほど口にしない」男の台詞（柱 B）。
- **第四章**：「打ち上がった刃を、オズヴァルトは試しに絹糸に当てた。絹糸は、刃が触れる前に、自分から切れた。」（e7m_8_arms）
  - 刃の力を数字でなく物の振る舞いで見せる。
- **第五章**：「懐の帳面には、描きかけの絵が一枚あった。あなたの顔だ。目だけが、まだ入っていなかった。」（e7m_9_last、ベルトランの結末）
  - 前夜の「描きかけだ」、第二章の「目だけ思い出せねえ」を一度に閉じる。この長編の芯。
- **終章**：「最後の小節で、拍子がひとつ抜ける。跳ねていた子どもたちが、そこでつまずいて、転んで、笑った。」（e7m_10 clean）
