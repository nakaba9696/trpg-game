# A20：囲まれた背景も透明にした絵の確かめ

`tools/a20/a20_gaps.py` で、髪のすき間・腕と胴のあいだ・武器と体のあいだなどの囲まれた背景を消した **301 枚**（人物の表情違いを含む・魔物）の一覧。
各升は左から「今（ゲームの白抜きだけ・暗い地）」「新（暗い地）」「新（明るい地）」。

- 変えたのはこの 301 枚だけ（一覧は `docs/art/a20_gaps.json`）。囲まれた背景が見つからなかった絵と、自動では白い服・白い髪・肌・光が崩れる絵は元のまま（ゲームの白抜きで外周だけ消える）。
- 消した塊はすべて元の絵と並べて一つずつ見た。崩れた人は `tools/a20/overrides.json` で「残す」（"keep"）か「残す四角」にした。
