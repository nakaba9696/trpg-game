# 設定点検の結果（R14・2026-10-11）

持ち主の原則：「やりたいことをやるために設定や世界観、キャラの性格をねじまげるのは創作で一番やってはいけない」。
既存のストーリー・出来事・会話が設定と食い違っていないかを総点検した。設定の正は [canon_2026-10-11.md](canon_2026-10-11.md)（第一部：世界・国・場所・使徒、第二部：人物）。**コードは直していない。** 直し方はすべて「設定に合わせる側」で書き、設定を変える提案はしない。設定どうしが食い違っている所は、末尾の「設定側で一つに決めること」に分けた。

## やり方
- 正を先にまとめ（canon_2026-10-11.md）、src/data/ を八つに分けて照らした：地方の出来事と噂・用語行／使徒・眷属・敵・使徒の長編／状態で現れる選択肢・世の大事・エピローグ／仲間の会話（前半・後半と掛け合い）／恋／人物の出来事／頼みごとと依頼。
- 人物名・使徒名・地名・国名・年数・〔秘〕の語（魔王・見世物・観客・客席・舞台・台本・神々はもういない）・旧名（八雲・自由都市・魔剣・聖刀・魔物界・天災／国難／討伐・グレオル・港の都）を grep と短い script で集め、疑いのある所だけ読んだ。仲間の台詞は `tests/lib.mjs` の `loadEngine()` で z\* の上書き後のデータを話し手ごとに書き出して読んだ。
- `src/data/z*.js`（zv3_\*・zc3_names・zk10_\* など）が set(...) で差し替えた文は、差し替え後で判断した。差し替えで直っているものは書いていない。
- 重さ：**重**＝物語の筋が壊れる（使徒が「できないこと」をする・国の体制が違う・死んだはずの人が生きて出る・〔秘〕が明かされる）。**中**＝人物がぶれる（性格・口調・過去が別人、関係や地名が食い違う）。**軽**＝細かな事実（年数・数・方角・呼び名・同名）。「疑い」は確信の無いもの。

## 先に答え
- **重 3 件・中 27 件・軽 71 件**（設定側で決めることが別に 11 件）。
- 〔秘〕の漏れは無い。今の人の台詞の「魔王」は逆さの夢の子どもと古い祈祷文だけ（許されている口）。旧名の残りも見える文には無い。死んだはずの人が生きて出る文も無い（順序の守りが抜けている所が一つ）。王子・四騎士・十指の「治める都」の取り違えも無い。使徒十三体の性格・居場所・眷属の主は、E3・長編（E7）・恋（ベリエラ・ドレイゼ）でよく揃っている。R9 の「秘密が二通り」16 人は C18 で一本になっていることを本文で確かめた。
- 重いものは三つとも、あとから足した使徒の出来事（`zz_e10b_events.js`）にある：黒鎧が剣を抜いた、黒鉄の砦を王国の王命で動かす、皇帝が病で御簾の奥にいる。
- 中の大半は二種類：(1) 使徒の眷属や使徒の守りが、E11（絶界は黒鎧だけ）・ハイデルの設定より前の書き方のまま。(2) 掛け合い（banter・頼みごとの {m} の台詞）で話し手の口調が別人になる。K10 の機械の検査は `mateText`・C15・C13 を集めていない（`tests/k10_lines.mjs`）ので、そこに集まっている。
- 軽の大半は年数の揺れと同名の別人。C19 で解いた「同じ名前の別人」が頼みごとの中にまだ十組ほど残っている。
