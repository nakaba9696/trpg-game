# Morsveld プレイレビュー（v0.6.0・main 22b73eb）

遊び方：`node tools/build.mjs` で `dist/site/` を作り、Playwright（Chromium）で実際に操作した。PC は 1366×768 を主に、1920×1080 とスマホ幅 390×844 でも同じ場面を見た。
画面からたどり着きにくい所（迷宮の最奥・仲間連れの戦闘・使徒戦・長編・絆と求婚・王城・節目）は、`tests/lib.mjs` の `loadEngine` でセーブを作って画面に読ませた（注入したセーブでは、読み込んだ瞬間にトロフィーがまとめて付くなど、注入のせいの見え方があるので、それは指摘から除いた）。
主人公は三人。
- 一人目：傭兵セラ（使徒を討つ）。導入・潰れた荷車・片目の女まで（Enter 連打の事故で途中まで）。
- 二人目：傭兵フィオ（使徒を討つ）。商店・ギルド・鐘撞きの丘への旅・戦闘五回・脇道の崩れた物見の塔・町へ戻って酒場（春 1 日〜5 日）。
- 三人目：作った状態の傭兵「試し」。エル・ナフ遺構を最奥の眷属カインまで、仲間二人（ディル・カイデル）の戦闘、忘れ水の使徒ルアマリス戦（弱点の品と弱体の出来事あり／なし）、長編「微笑の糸を断つ」の入口、ディルとの絆の褒美と求婚、王都の王城で王位を奪う、節目「膝をついたもの」で物語を終えて人生の物語を読む。

## 総評
0.6.0 で前回の指摘の大半が直っている。立ち絵と背景の食い違い（片目のシグルン・旅の戦闘の背景・酒場の中）、商店の並び、所持金の重複、教わるの二重、トロフィーの隠し方、墓守の語り、成長の文、仲間の札、いずれも確かめた範囲で直っていた。
行動 → ログ → 結果 → 得たものの流れと「戦いのあと」の画面は分かりやすく、使徒戦の山場の見せ方（暗転と大きな一行）、王位を奪う場面の文、人生の物語（帳面祭の読み上げ役）は読み応えがある。仲間連れの戦闘で手を順に決めて「一つ前に戻る」も自然に動く。
いちばん大きな課題は四つ。**Enter 連打で最初の選択肢が選ばれてしまう**こと、**節目の知らせがダイスの前に出て結果が漏れる**こと、**仲間連れの戦闘で攻撃の手が 2/5 しか見えない**こと（前回の指摘が仲間連れでは悪化）、**長編の依頼が「依頼」の窓に出ない**こと。次いで、港の用心棒の絵（現代の警備員）と、港の敵が丘に出ること。

## 直したほうがよいこと（優先度つき）

### 高
1. **Enter 連打で最初の選択肢が選ばれる。** 本文は「Enter で早送り」と案内しているが、本文が出終わったあとの Enter は「わかった」を押し → 最初の選択肢に焦点 → さらに Enter でそれを押す（`src/ui/v9_pc.js:498` 以降）。選択肢を押してから Enter を連打して読み飛ばす、というふつうの手で、片目のシグルンの質問が勝手に選ばれ、大失敗の「振り直す」まで押されて貴重な振り直しが一つ消えた。早送りの Enter と、選択肢を押す Enter を分けてほしい（本文が出終わった直後の Enter は何もしない、か、焦点を当てるだけで押さない）。
2. **節目の知らせがダイスの前に出る。** 筋力が 20 に届く攻撃で、ログが「▶ 鉄の長剣で棘猪に斬りかかる → 節目「力自慢」：重い物をどけ… → 攻撃【筋力】成功率 69% → 出目 32 → 成功 → 筋力が伸びた 19→20」の順（019）。節目は成功して伸びたあとに出るものなので、出目の前に見えると成功が分かってしまう。節目の行を成長の行のあとに回してほしい。
3. **仲間連れの戦闘で、攻撃の手が 2/5 しか見えない（1366×768）。** 狙いの札・一行の帯・「あなたの手を選ぶ 1/3」で押し下がり、手の一覧の枠が 68px しかない（スクロールできるが分からない）。3・4 件目は見出しの帯の下に隠れ、5 件目は画面の外（078）。前回の 4d が仲間連れでは悪化。本文の欄を低くする・一行の帯を一行にまとめる・手の一覧を先に置く、のどれかで、少なくとも 5 件が見える高さを確保してほしい。
4. **長編の依頼が「依頼」の窓に出ない。** 「微笑の糸を断つ：広場の音楽」を聞いたあと、ログに「依頼『微笑の糸を断つ：踊りのあと』を引き受けた。（右上の「依頼」で見られる）」と出るのに、依頼の窓は「受けている依頼（0）」（065 の直後）。長編の筋が追えない。

### 中
5. **港の用心棒の絵が現代の警備員。** 制帽に記章、胸に名札、手に警棒（023）。文は「首の太い男、腰の鈴」。この世界の絵ではない。差し替えか、絵なしに。
6. **港の敵が丘と塔に出る。** 鐘撞きの丘の魔物の組に港の用心棒が入っていて（`src/data/locations_w3.js:42`）、「樽の陰から…密輸の荷を見張る」の前口上のまま、丘で二回、崩れた物見の塔の主としても一回出た。五日で三回。丘の組から外すか、丘向けの前口上を。
7. **商人の立ち絵が現代の服。** 道ばたの両替商が、ファスナー付きの多ポケットのベストにシャツ（017）。文は「眼鏡を額に上げて」だが眼鏡が無い。
8. **長編の入口・絆の褒美・求婚が「持ち物・その他」の組に入る。** 右の列で「使徒を追う」「絆」「想い」の組が「持ち物・その他」にまとめられ、「微笑の糸を断つ」「ディルが呼んでいる」「ディルに一緒になろうと言う」がそこにしかない。長編の始まりと恋の山場が、いちばん見ない組に隠れる。組の名前を残すか、「人に会う」に入れてほしい。
9. **入口の出来事が地下 3 階で起きる。** 鶴嘴の女親方マグダの出来事（「遺構の入口の天幕の群れの真ん中で」）がエル・ナフ遺構の地下 3 階で出た。`src/data/events_c5.js:467` の `where: ["ruins"]` に階の条件が無い。入口（depth 0）だけに。
10. **使徒戦で倒れたときの文が地下に合わない。** 水の書庫（遺構の最奥）で倒れたのに「空が見えた。いつの間にか、仰向けになっていた。雲が一つ、ゆっくりと流れていく」。屋内・地下の死に別の文を。同じ場面の「次に活かせること」が「剣を抜く前に、集めておくべきものがあったのかもしれない」だったが、この主人公は弱点の品も弱体の出来事もそろえていた（使徒 HP 213/355）。そろえていたときは別の助言（仲間・さらに弱らせる）に。
11. **求婚の文が町の中に合わない。** 港町ヴァレンツァの町で「鳥が鳴いている。風が草を倒していく」「水筒は坂の下まで転がっていった」（074）。野外の文が町でも出る。場所で分けるか、場所を問わない文に。求婚の場面にディルの立ち絵が出ないのも惜しい（会話では出る・060）。
12. **「戦いのあと」の得た物と、ログの食い違い。** 棘猪を倒した戦いのあとで「得た物 なし」なのに、ログには「干し肉を手に入れた」（019 の直後）。
13. **町に着いたときに◆の付いた「旅立つ」が開く。** 上の表 4a。
14. **静かな節目の一行の形。** 「（小さな家の値段）ここで旅を終えることもできる、とふと思った。」「（違っている歌）ここで…」と、節目の題が丸括弧で頭に付く（`src/data/epilogue_m6.js:79`）。内部の札が漏れたように読める。「節目『小さな家の値段』──ここで…」のように見出しの形に。
15. **スマホの戦闘。** 図鑑・用語集の知らせが HP・MP の帯に重なり、魔物の絵は本文の枠の上に頭だけ（072）。知らせは戦闘のあいだ下に、絵は枠の上に収まる高さに。
16. **迷宮の最奥で鳥の声。** 眷属カインを倒した地下 4 階で「遠くで止んでいた鳥の声がまた始まった」。屋内・地下の戦いのあとの一行を分けてほしい。
17. **使徒戦の山場に知らせが被る。** 暗転して「忘れ水の使徒ルアマリスが、得物を抜いて向かってきた」と大きく出る瞬間に、左に用語集の知らせ三つとトロフィーの知らせ（054）。山場のあいだは知らせを溜めて、終わってから出してほしい。

### 低
18. 行動のあとのログに「所持金 +3G」「HP -1」が地の文の段落のあいだに一行ずつ入り、下の「得たもの」の枠と二重（010）。枠があるなら本文の行は消してよい。荷車で親方を助けそこねたのに +3G、理由の無い HP -1 も気になる。
19. 能力値の画面の「術の才：能力値と一緒に振り直される。種族と職業で変わる」。主人公は人間だけで種族は選べないので「種族と」は余計。
20. 傭兵の職業の札に「覚えている魔法」が無いが、術の才を引くと得意な属性の初級を一つ知って始まる（`src/engine/m14_magic.js:134`）。才の欄に「才があれば得意な属性の初級を一つ知って始まる」の一行を。
21. 出目「00」が「→ 100 大失敗」（049 のログ）。案内は「出目（00〜99）が成功率以下なら成功」。00 を 100 と読むなら案内を「01〜00」に、そうでないなら 00 は成功に。
22. 商店の細剣「＝今より攻撃-1」（上の表 5g）。
23. 買い物のログ「心得の巻物『礼法』を買った。（-150G）／顔なじみだからと、少しまけてくれた。（+15G）」。一覧の値段は 135G。まけた分を含めて一行にできる。
24. 依頼の一行「鐘撞きの丘で関所ネズミの群れを1体倒す」。群れを「1体」は変。「一群れ」か「関所ネズミを倒す」に。
25. 戦闘の「その他」に「4 一つ前に戻る」があり、上の「↩ 一つ前に戻る」と二重（仲間の手を選ぶとき）。
26. 旅の途中でも左上の帯が出発地の町名（「商都ブランデール」のまま）。本文の札は「旅の途中 鐘撞きの丘へ」なので、帯も道中にしてよい。
27. 1920×1080 で本文の欄が短い文でも高いまま、下が大きく空く（035）。
28. 物語を終えたあとの年表に、同じ日のトロフィーが二度並ぶ（071。注入したセーブなので、ふつうの遊び方でも起きるか要確認）。
29. 「勢いのまま、とどめを刺した。」がダメージの行の前に出る。倒れる演出は直っているので、文の順だけ。

## 新しく確かめた所（前回の未確認）
- **迷宮（エル・ナフ遺構 1〜4 階）**：三枚目の敷石・濡れた書架・空洞の床の罠が「調べながら進む」で読め、失敗すると覚え書きに「本を抜いたら、棚が降ってきた。なぜ壁から離してあった？」が残る。最奥の眷属カインは渾身の一撃の溜め → 目つぶしで崩す → 深く入る、の読み合いが成り立つ。倒すと壁画の一行と「戦いのあと」に品・成長・トロフィー・覚え書きがまとまる（043）。よい。問題は 9・16。
- **仲間連れの戦闘**：あなた → ディル → カイデルの順に手を決め、札が光り「手：これから／手を選んでいる／手：狙いを攻める」が切り替わる。「一つ前に戻る」でディルの手に戻れる。解くと「ディルの攻撃がオークに 1 のダメージ」「カイデルがあなたの前に出て、盾になる構えを取った」「ゴブリンの攻撃！ 1 のダメージ」と一巡ぶんがまとまる（048）。仕組みは分かりやすい。問題は 3・25。
- **使徒戦（忘れ水の使徒ルアマリス・B 級）**：弱点の品（名前を刻んだ石）と弱体の出来事をそろえると、戦いの頭で「懐の石に刻んだ自分の名前が冷たく重い。女の指が触れても、名前は抜けていかなかった」「棚の一段を探る。そこに入っていたはずの一冊が無い」と、品と出来事の効きが文で分かり、答えは書かれない。HP は 213（そろえない場合 355）。そろえずに挑むと呪いで一手番 18〜31、刃は 4〜9 しか通らず、能力値 55 の一人では勝ち目が無い。方針どおり。問題は 10・17。
- **長編（微笑の糸を断つ）**：靴売りコルネリウスの語り（「売れた。全部だ」「祭りなら、もっと楽しそうな顔をするさ」「子どもの靴」）は A の空気と D の風呂敷が利いていて、続きが読みたくなる。問題は 4・8。
- **恋（絆の段・褒美・結婚）**：段は「顔見知り → 知人 → 友 → 深い仲 → かけがえのない人」で、人に会うの札に「信頼している（55）・友」「慕っている（100）・恋仲・かけがえのない人」と出る。褒美「角の折れた目録」はディルらしい（「字、汚いな」の返しもある）。求婚は「まっすぐに言う／指輪を渡して言う／今、ここで誓おう」で、受けた文（「遅えよ。待ちくたびれた」水筒が坂を転がる）はよい。相手は 24 歳の人間。恋の決まり（18 歳以上・人の姿）は、データの検査（`tests/checks/c11_love_human.mjs`・`love_age.mjs`）がある前提で、見た範囲では守られていた。問題は 8・11。
- **王城**：謁見の間の文（玉座の肘掛けの本に獣の爪の栞）、王位を奪う場面（柱の数を数える・扇が落ちる・「痴れ者が」）、倒したあとの貴族が順に膝を折る流れ（061）は C の圧がある。問題なし。
