# E11（#356）のあとの 3 つの決めごと

配り役が持ち主に聞くためのメモ。どれも #356 では入れず、今の形のまま止めている。

---

## 1. 使徒の固有の守りに、ゲームの効き目を持たせるか

**何が問題か**：絶界を持たない 15 体の使徒は、挑んだときに守りの一行が出るだけで、戦い方は変わらない。たとえば「斬っても砂に崩れて組み直る」「霧で本体が分からない」と書いてあっても、数字の上ではただの強い敵と同じになる。

**案**
- A. **文だけのまま**（今の形）。強さは HP・ダメージ・弱らせる出来事で表す。
- B. **軽い効き目を一つずつ足す**。数値の小さな上乗せで、使徒ごとに一つ。
  - 再生：毎ターン HP が少し戻る。
  - 霧：こちらの命中が下がる。
  - 刃を齧る：武器の耐久が減る。
  - 糸：最初の数ターン、こちらが後手になる。

  弱点や出来事をそろえると、その効き目が消える（伝承と結ぶ）。
- C. **守りごとに特別な仕組みを作る**。たとえば「砂の体は火でしか崩れない」「見上げたら負け」のような専用の判定。

**おすすめ**：**B**。「書いてあることが効く」ようになり、出来事で弱らせる手触りも上がる。C は 15 体分の作り込みで重く、釣り合いの測り直しも大きい。B なら、効き目の分だけ HP を下げれば、今の勝率の目安（B ≥ A ≥ S、A 約 3 割）を保てる。

**決めないと止まるもの**：使徒ごとの戦いの差を付ける作業。B か C に決まれば、E レーンで一つの PR にして、勝率を測り直す。A のままなら、何も止まらない。

## 2. 錆びた鍔の筋（F2「錆びた鍔」）を書き直すか

**何が問題か**：目的「伝説の武具を得る」の導入筋が、鍔・鞘・「剣は待っているだけ」と、剣の言葉のまま残っている。伝説の武具は今は槍と鎖なので、遊ぶ人は「剣の話を追ったのに、手に入るのは槍か鎖」と、ちぐはぐに感じる。昔話の場面（伝説の武具の話を訊く）だけは、#356 で槍と鎖の絵に直した。

**案**
- A. **そのまま**。鍔は「どこかの古い剣」のもので、伝説の武具とは別の話、と読む。
- B. **小物だけ差し替える**。鍔を「鉤の留め具」（槍の鉤を柄に留める金具）に、鞘を「留め具の受け」にして、「剣は待っている」を「武具は待っている」にする。筋の流れと選択肢・フラグはそのまま。対象は `f2_threads.js` と `zv3_prose_f2.js` の 5 場面。
- C. **筋を二つに分ける**。槍の筋（竜の骨・鉤）と鎖の筋（社・鳴る音）にする。

**おすすめ**：**B**。文の差し替えだけで、セーブの形（フラグ `f2_sold_tsuba` など）も変えずに済む。C は新しい出来事を十ほど書くことになり、目的の導入としては重い。

**決めないと止まるもの**：止まっているものは無い。今も遊べる。ただし、目的「伝説の武具」を選んだ人が最初に読む筋なので、A のままだとずれが残り続ける。

## 3. 明けの鎖を、敏捷と筋力のどちらで振るか

**何が問題か**：明けの鎖は今、旧聖刀の数値のまま（筋力・命中 +15・ダメージ 2d6+5）。説明の「振れば打ち、投げれば絡む」は身軽さの武器に読めるのに、筋力の高い人ほど強い。敏捷の高い職業（盗賊など）には、伝説の武具の選びがいが無い。

**案**
- A. **筋力のまま**。
- B. **敏捷にする**。
  - 細剣・短剣と同じ型になる。
  - 鉤槍は筋力、鎖は敏捷と分かれるので、どちらを取りに行くかに意味が出る。
- C. **筋力と敏捷の高いほう**で振る。
  - 誰でも使いやすい。
  - ただし今のゲームに、この決まりの武器は無い。

**おすすめ**：**B**。二つの武具の性格がはっきりし、目的「伝説の武具」の選び方に幅が出る。
- 使徒の勝率の測り（`tests/checks/e8_power.mjs`・`e3_apostles.mjs`）は鉤槍か mithril で行っていて、鎖を使っていない。だから目安は変わらない。
- 測り直しは、鎖を持ったときの一回の確認で済む。

**決めないと止まるもの**：止まっているものは無い。B か C に決まれば、`items.js` の一行と、確認を一つ足すだけの小さな PR にする。
