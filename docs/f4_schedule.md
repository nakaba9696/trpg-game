# 仲間の予定（いつ・どこに居るか）の書き方

仲間になる人（`D.C2_PEOPLE` の `join` がある人）は、時期ごとに居る場所がだいたい決まっている。その時期にその場所へ行けば会える。
仕組みは `src/engine/zz_f4_roster.js`（F4）、既にいる 12 人の予定は `src/data/f4_roster.js` の `D.F4_SCHEDULE`。

## 書き方

その人のデータに `schedule` を足す（`join.schedule` でもよい）。無ければ、今の場所（出会いの出来事の `where`・誘える町 `join.home`）に一年じゅう居る。

```js
mira: {
  name: "ミラ", /* … */
  join: { /* … */ home: ["nerva"] },
  schedule: [
    { from: "春", to: "夏", loc: "nerva", note: "港の市場で魚を捌いている" },
    { from: "秋", to: "秋", loc: "w2_granbel", note: "秋は麦の都へ出稼ぎ" },
    { from: "冬", to: "冬", loc: "frost", note: "冬は北の街道の宿で働く" },
  ],
},
```

- `from`・`to`：季節（`"春"` `"夏"` `"秋"` `"冬"`）か、年の中の日（1〜360。春 1〜90・夏 91〜180・秋 181〜270・冬 271〜360。暦の長さは `src/engine/core.js` の `G.SEASON_DAYS`）。`"秋"`〜`"春"` のように年をまたいでもよい。
- `loc`：場所の id（`src/data/locations*.js`）。
- `note`：図鑑と噂に出す一言。その人の暮らしの手ざわりで書く（「冬は北の街道の宿で働く」）。
- 予定の無い時期は「どこかへ出ている」（会えない）。会えない季節は多くても二つまで（`tests/checks/f4_roster.mjs` が確かめる）。

## 気をつけること

- **出会いの出来事は、予定の場所で起きる。** その人が主（出来事の `c2` の最初）の出会いの出来事と、仲間になる流れの入口は、今の時期の居場所に移って起きる。
  ただし場所の種類（町・野・迷宮）が出来事の `where` と違う時期は起きない（森の出来事は町では起きない）。その時期は、会ったことがあれば町で「誘う」だけができる。
- **出来事の文と食い違わない場所を選ぶ。** 「酒場の二階」の人を野に置かない。図鑑の説明（`D.F2_PEOPLE`）に町の名前が書いてあれば、その町を中心に。
- **冒険ごとの揺れは数日だけ**（予定が前後する）。誰が居るかは変わらない。出来事の中身（出会い方・脇の出来事・噂）は乱数で変わる。
- **出来事で予定を変える**：結果に `f4move: { id, schedule: [...] }`（追われて逃げる・旅に出る）。もう会えなくなるときは `f4away: id`（死ぬときは今までどおり `c2dead`）。図鑑に「出来事『〇〇』の後は会えなくなることがある」と出る。
- **仲間にする方法**は `join` と出来事（`c2join`・`next`・判定・戦い・金・`cond`）から自動で組み立てる。書き足したい人だけ `joinHint: "…"` か `joinHint: { full: "…", vague: "…" }`。

## 図鑑とプレイヤーの手がかり

- 会った場所と季節は図鑑に残る（「秋の王都レオネスト」）。季節ごとの表の、知らない時期は空欄。
- 酒場の噂とギルドの尋ね人の貼り紙で「〇〇なら冬は北の宿にいる」のような手がかりが出て、図鑑の表が埋まる。
- 図鑑で知っている人（かつて会った・噂で居場所を聞いた）が今いる場所では、「〇〇を訪ねる」で出会いの出来事に入れる。
- 図鑑の「次の冒険で狙う」印（三人まで）を付けた人は、その人の出会いの出来事が出やすく、噂にも上りやすい。
