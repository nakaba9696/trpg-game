# 顔だけを大きく作るやり方の試し（2026-10-14・face-trial-1）

持ち主「キャラタグ＋表情で作れる気がする」。顔の窓専用の絵（assets/portraits/faces/<id>_<表情>.webp・512×512）。全身の絵には戻さない。置き場所は画面側と合わせる。

作り方（tools は手元のスクリプト face.py。値は docs/art/gen/<id>_face.json）：
1. 顔の窓の四角（src/data/u41_face_box.js）を基本の絵から切り出し、1024 に拡大。
2. img2img（denoise 0.7・steps 28・cfg 5.5・Euler a）。プロンプト＝style.json の prefix＋顔の大写し＋ identity・tags＋表情のタグ（variants）。
3. ControlNet：
   - canny（controlnet-canny-sdxl-1.0-xinsir-v2・重み 0.6・終わり 0.7）。基本の顔の線（Canny 80/180）から目・眉・口の所を消した線画を渡し、輪郭・髪・小物は線で押さえ、表情の所だけ自由に描かせる。
   - reference_adain+attn（重み 0.7・終わり 0.8）：基本の顔で同じ人に見せる。IP-Adapter のモデルは入っていない。
4. 目・眉・口の四角の外と、その中の守る所（前髪の色・絆創膏・汚れ・鼻・ひげの色）は、描いたあとに基本の画素を戻す（境目は 10 画素ぼかし）。

compare.webp：上が otmar（基本・喜・怒・哀・楽・冷たい目）、下が nora（基本・喜・怒・哀・楽・目を輝かせる）。

## 2 回目（2026-10-14・round2.webp）：表情がひと目で分かることを最優先に
持ち主の返事「なんの表情かわからない」「nora の怒りがわかりにくい。楽しいも前髪で目が隠れてウィンクか分からない」「otmar は全部 OK」を受けて：
- 表情のタグを、ひと目で分かる形に決めて重みを上げた（1.5〜1.6）。
  - 喜：口を開けて笑う・目を細める
  - 怒：眉を吊り上げて寄せる・歯を食いしばる・にらむ・怒りの印
  - 哀：眉を八の字・口を結ぶ・涙
  - 楽：いたずらっぽい笑み・片目つむり
- 逆の表情をネガティブにした。無表情・焦点の合わない目・小さな瞳もネガティブにした。denoise は 0.8〜0.85 に上げた。
- 前髪で片目が隠れる人（nora・mirza）は、見える側の目と口で表す。片目つむりは、見える側の目にする。
- 人ごとに出してはいけない物をネガティブに入れた。adele のそばかす（基本の絵には無い）、barnabe の粉の白い点、mirza の頬の汚れ。
- otmar は 1 回目のまま（持ち主 OK）。nora は喜・哀・目を輝かせるを 1 回目のまま使い、怒・楽を作り直した。
- mirza は、顔の窓の四角が顔より上にずれているので、切り出しを顔の高さの 14% 下げた。顔の窓の四角そのもの（u41_face_box.js）も直すかは、画面側と合わせる。

## 3 回目（2026-10-14・round3_tools.webp）：決まりを道具で守る
持ち主「ずっと同じ指摘してる気がする。ツールとかでもっと精度あげれないの？」。
- 点検の道具 tools/art/face_gate.py（WebUI の venv の python で動かす）。基本の顔と作った顔から、合否と理由を出す：
  - 目の数と位置（ADetailer の AnzhcEyes-seg）：基本より多い・基本に無い所の目 → 落とす
  - 眉と目の重なり：基本の目の上の帯（眉とのあいだの肌）が暗くなったら → 落とす
  - 表情の札（WD14 wd-eva02-large-tagger-v3）：狙った札が弱い・逆の表情（怒りなのに笑う）・multiple eyes など → 落とす
  - 使徒・強者：anger vein・tears・blush・sweat の札 → 落とす
  - 元から笑顔の人の喜・楽：表情の札の並びが基本とほぼ同じ → 「変わってない」で落とす
- 生成 tools/art/face_make.py：描き直す範囲は目の検出の箱＋眉の帯（前髪を除く）＋口の四角だけ。前髪で隠れた目は描かない。目の箱の中は基本の画素を戻さない（目が二重にならない）。同じ人は IP-Adapter（plus-face）で保つ。描いたら face_gate で点検し、落ちたら seed を変えて 3 回まで作り直し、3 回落ちたら作らない。
- 元から笑顔の人の喜は「目を閉じて笑う」、楽は「いたずらっぽい口・舌を出す・片目つむり」にして、基本の笑顔と形を変える。使徒・強者は抑えた表情のタグ（冷たい目・伏し目・口の端を上げる）を使う。
