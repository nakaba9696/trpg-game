# 使徒の絵の試し（威厳・dorontabi）

持ち主の声「使徒、もうすこし威厳を出して欲しい。絵柄も少し変えていいです。dorontabi とかどうでしょう」から、3 体を 2 案で作った。同じ seed・同じタグで、画風のタグだけが違う。

- `<id>.current.webp`：今の魔物の画風（style_monsters.json の prefix のまま）
- `<id>.dorontabi.webp`：prefix の絵師タグに `(dorontabi:1.3)` を足した案（1.0 ではほとんど変わらなかった）

タグは 3 体とも、神々しさ・畏れ・大きさが出るように直した（majestic, imposing, divine, awe-inspiring, from below, dramatic lighting など）。案が決まったら 10 体を描き直す。dorontabi は使徒だけに使う。
