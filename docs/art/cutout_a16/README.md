# A16：囲まれた背景の切り抜き（確かめのシート）

実行時の切り抜き（`src/ui/a13_cutout.js` の `a13core`）を、`assets/portraits/`・`assets/monsters/` の全部の絵（1268 枚）に掛けて比べたもの。
絵そのもの（webp）は変えていない。

- `rep_*.jpg`：代表。各段は「元の絵｜直す前（マゼンタの上）｜直した後（マゼンタの上）｜直した後（濃紺の上）」。
  - `rep_priests_bandit.jpg`：神官 4 枚と街道の盗賊（熊手の柄と体のあいだ・腕と体のあいだ）
  - `rep_weapons.jpg`：武器を持つ人物
  - `rep_hair.jpg`：長い髪の人物（髪の房のあいだは薄白の半透明になる）
  - `rep_white_kept.jpg`：白い服・白い毛皮の人物（服が抜けていないこと）
- `pairs_*.jpg`：直して切り抜きが変わった 384 枚すべての「前｜後」。段ごとにマゼンタと濃紺を交互に敷いている。
  変わらなかった残りの絵は、前と同じ。

作り方：画像を RGBA に読み、`G.a13.keyOut` を Node で動かして（ブラウザの Worker と同じ核）並べた。
`keyOut(px, W, H, { dbg })` に `Uint8Array` を渡すと、囲まれた塊ごとの判定（1 透明・2 薄白・3 残す）が書かれるので、色を付けて見られる。
