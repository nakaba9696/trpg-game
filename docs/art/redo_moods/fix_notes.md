# 元の表情違いを直す（2026-10-14・fix-moods-1）

持ち主「基本的に元のほうが表情がいい。ひげなくなってたり、メガネ変わってたり、髪が変わってたり、手が生えてるのを直してほしい」。
表情は描き直さない。今のゲームの表情違い（main）を下地に、崩れている所だけ基本の画素を戻した。

- 守る所（<id>_keep.png）：基本の絵から作る。目にかかる前髪（頭の髪とつながる髪の色）・ひげ（あごの色）・眼鏡と片眼鏡の縁（レンズの輪の帯ごと。rim.py）・顔の範囲の肌でない所（傷・そばかす・化粧・布・仮面・耳飾り・髪留め・鼻や輪郭の線）。目（瞳・白目・眉）と口の楕円は外す。口の楕円の中のひげは、表情違いの画素が肌かひげの色の所だけ戻す（口の形は残す）。
- 顔の窓に映る所（顔の箱を 30% 広げた中）だけ直す。体・服・持ち物は直さない。
- 位置は整数の平行移動だけ合わせる（今回は全部ずれ 0）。拡大・縮小はしない。境目は 0.8 画素ぼかす。透明度は守る所では基本の値。
- 顔の中の、外とつながらない透明（constance・nora・rui・sixth・tiria などのレンズや目の透け）は、まわりの色で埋めた。constance は目の色が元から無いので、灰色の目になる。
- 片眼鏡の人で、表情違いにもう片方のレンズが出ていた所（hermes の fun・zalve・dietrich）は、もう片方の目の位置の縁の帯も基本に戻した。
- 目の色が変わっていた絵（ilse・mirlene・radmila・vittorio の一部）は、瞳の色相を基本に合わせた。
- 試しの 10 人で持ち主が OK した新しい絵（redo-moods-9）はそのまま使い、同じ直しをかけた。「いらない」の 12 枚と、葉っぱをくわえて直らなかった ambroise_sorrow は消した（基本の絵か近い表情に落ちる）。
- 目を自動で見つけられなかった人は、目の位置を手で書いた（眉を戻して表情が消えないように）。
- 直さなかった物：体・服・持ち物の描き直し、表情の差が無い絵、手の形（lazare の fun・serious は手が顔の窓の端で、そのまま）。
