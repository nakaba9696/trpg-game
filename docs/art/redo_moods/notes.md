# 表情違いの作り直し（2026-10-12）のメモ

やり方：基本の絵を下地に、顔（目・眉・口・頬）だけを inpaint（Only masked・masked content original・denoise 0.6・seed は id から固定）。顔の外は基本の画素のまま、透明度も基本のまま。設定は docs/art/gen/<id>.json、顔のマスクは docs/art/redo_moods/<id>_mask.png。

- マスク（redo-moods-2 から）：目と眉の帯（顔の箱の上から 28%〜60%・幅 80%。列ごとに上から髪の色が続く所＝前髪の房は外す）と、口の楕円（中心 72%・幅 48%・高さ 26%）。**頬は描き直さない**ので、絆創膏・傷・ほくろ・化粧は基本の画素のまま、全部の表情で同じ。
- denoise 0.72（目・眉・口を一度に。redo-moods-3 からは目の denoise 0.8・表情の語の重み 1.5 で表情の差を強める）。描く前に、基本の口の芯の「肌の色から離れた所」（歯・口の線）を肌の色で塗る（基本の笑った口を引き継がないため）。
- プロンプト：基本と同じ文から、その人の札にある表情の語（grin・smile など）を外し、表情ごとの眉と口の形の語（怒り＝v-shaped eyebrows・clenched teeth、哀＝eyebrows raised in the middle・closed mouth など）と表情違いの語を 1.3〜1.4 で足した。表情ごとに逆の語をネガティブに（怒り・哀に smile など）。
- 基本の絵：透けた穴（体の内側の半透明・小さな透明）を不透明に（半透明の色は残し、足りない分はまわりの色）。背景が白いままの 7 人は白い背景を抜いた。
- 基本に無い特徴を足す（傷・絆創膏・飾りなど）は、この回ではしていない（下の表の「残り」）。
