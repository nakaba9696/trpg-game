# 最初の差分の直し（2026-10-15・orig-fix-1）

最初の差分（全身の img2img で作った表情違い）の表情はそのままにして、表情でない所を基本の絵に戻した。道具は `of.py`、絵ごとの記録は `rep/<id>.json`、まとめは `summary.json`。

- **合わせ**：差分を基本に ECC（相似変換）で重ねる。0.5px 未満のずれは動かさない（ぼけないように）。
- **表情の範囲**：
  - 目（AnzhcEyes-seg の塊を少し広げた所と、目の楕円）、眉の帯、口、目の下から口の周りの頬の肌（肌の色の所だけ）。
  - 口の所は、差分と基本で大きく違う所まで広げる。口の位置が下がった差分で、基本の口が残らないように。
- **範囲から外す所**：
  - 基本の守る所：前髪、ひげ、傷、化粧、布、耳飾り、髪留め。作り方は keep.py と同じ。
  - 差分の前髪とひげ。
  - 眼鏡の縁。
  - 差分にだけある汚れの塊。
  - 透過の縁。
  - 眉の帯の中では、前髪の上に描かれた眉の線だけ差分を使い、髪の色の所は基本のまま。
- **重ねる**：範囲の外は基本の画素と透過。範囲の中は差分の画素で、縁は内側へ約 3px ぼかす。差分の肌の色合いは、両方で肌の所の差の中央値だけ基本に寄せる（±15 まで）。
- **瞳**：差分の虹彩（白目とハイライトを除く）を、基本の虹彩の Lab の平均と広がりに合わせる。ΔE 6 未満なら触らない。
- **点検（自動）**：
  - 目の数。
  - 目の位置のずれ（眼鏡の人は厳しく）。
  - 範囲の外が基本と同じか。
  - 境目の段差。
  - 眉と目の重なり。
  - 表情の差が 0.025 以上残っているか。
  - 瞳の色の差。
- **点検（目）**：全部を顔の窓の四角で、基本・直す前・直した後と並べて見た。
  - 自動の「目が 3 つ」「目の位置がずれる」が外れていた 13 枚は使った（lumia・sixth・zork・magda_fun・raios_fun）。
  - 「表情の差が残らない」の 37 枚も使った。目を検出できず、差を口だけで測っていたため。直す前と同じ表情が残っていることは目で確かめた。
    - 当てはまる人：barnabe・constance・ingrid・yurien・farina・felix_anger・aubin_joy。
    - barnabe と farina は、元の差分が基本とほとんど同じ。
  - gerhard の surprise・serious は、口とひげが混ざって崩れていたので落とした。
- 落ちた絵は main の絵のまま。描き直し（inpaint）はしていない。
