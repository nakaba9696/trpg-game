# 恋の相手の一覧（romance）

持ち主の方針：「仲間にできるキャラは 50 人くらい、恋愛結婚できるキャラは 20 人くらい」。

- **全体の目標は 20 人**（上限 25。`tests/checks/c_romance.mjs` が超えたら落とす）。
- 名のある人物のデータ（`D.C2_PEOPLE[id]`。C4 以降の人も同じ表）に `romance: true` がある人だけが、恋（M10・M11）の気配・告白・求婚・結婚・嫉妬の相手になる。無い人は、好感度が高くなると「信頼・親友・家族のような情」の出来事（`src/data/events_c_bond.js`）と終わり方になる。
- 18 歳未満・子どもの姿の人は、`romance: true` を付けても恋の相手にしない（`src/engine/zzz_love_age.js`）。だから付けない。
- 名の無い（乱数の）仲間は、この表と関係なく今まで通り（数に入れない）。魔物の子分（ゴブリンなど）は恋の相手にしない（C11）。
- **恋の相手は 18 歳以上で、人の姿の者だけ**（C11・持ち主の決定「人間っぽいやつ以外と恋愛させないで」）。人の姿：人間・エルフ・獣人。人の姿でない：ゴブリン・オーク・スライムなどの魔物。印は人物の表の `humanLike: false`、仕組みは `src/engine/zzzzzzzz_c11_love_human.js`（`G.loveHuman`）、表は `src/data/zc11_love_human.js`。
- 格の違う相手（M11 の `D.M11.AP`）も、`romance: true` が無ければ続き物が進まない。
- 仕組みは `src/engine/zzzz_romance.js`。この表と `G.romanceIds()` が食い違うとテストが落ちる。**付けたら、この表に一行足す。**

## 恋の筋（R2）
持ち主の声：「仲間の恋の話を深めて」。恋の相手一人ひとりに、段を踏んで進む恋の続き物を書く。**全部データで動く（Claude を呼ばない）。**

- 仕組み：`src/engine/zzzzzz_romance2.js`（会話 `G.tk` と M10 を包む）。中身：`src/data/romance_<id>.js`（`D.R2.ARCS[id]`）。共通の表（トロフィー）は `src/data/romance_r2.js`。
- 格の違う相手（ベリエラ・ドレイゼ）は仲間でないので、筋は出来事（`src/data/romance_yoi.js`・`romance_zalve.js`。M11 の続き物の間に段を足す）。
- 確認：`tests/checks/r2_romance.mjs`。

### 段（話す の話題として出る）
| 段 | 名 | 出る条件（好感度は F3 の −100〜+100。難しい道は `hard.add` を足す） |
|---|---|---|
| 1 | 気になる | 15 以上 |
| 2 | 意識する | 25 以上 |
| 3 | 二人きりの約束（町歩き・祭り・星見・稽古など、その人らしい逢い引き） | 35 以上 |
| 4 | すれ違い・試練（その人の過去や秘密と結びつく） | 42 以上 |
| 5 | 告白 | 50 以上・ほかに恋人がいない。返しの `m10: "love"` で恋仲（M10）になる |
| 6 | 恋仲 | 恋仲（M10 の love・vow・wed） |
| 7 | 求婚 | 62 以上・恋仲になって 5 日。返しの `m10: "vow"` で約束（式は教会で、M10 のまま） |
| 8 | 結婚 | 連れ合い（M10 の wed） |
| 9 | 暮らし（家・子どものほのめかし） | 連れ合い・前の段から 4 日 |
| 10 | この先（旅を続けるか、剣を置くか） | 連れ合い・前の段から 6 日。`fut: "retire"` を選ぶと「想い」の欄に「〇〇と暮らすため、剣を置く」（冒険の終わり）が出る |

- 段は一日に一つまで。話題の一覧には、出せる段の話題が必ず一つ入る（夜の会話にも出る）。
- **M10 の告白・想いを打ち明ける**は、筋のある人には「すれ違い」（4）のあとだけ。**求婚**は「恋仲」（6）のあとだけ。M10 の出来事で先に恋仲になったら、筋は告白（5）まで済んだことになる。別れたら、すれ違い（4）に戻り、仲直りから。
- 古いセーブ（`S.r2` が無い）：恋仲・約束・連れ合いの人は、告白（5）まで済んだことにする。

### 返し方に書ける鍵（会話の返しの鍵に足す）
| 鍵 | 意味 |
|---|---|
| （無し） | 深まる：段が進む |
| `hold: 日数` | 保留：段は進まず、日をおいて同じ段がまた出る（告白を「考えさせて」など） |
| `sour: true`（`sourDays`） | こじれる：段は進むが、仲直りの話題（`mend`）を済ませるまで次が出ない |
| `m10: "love"` / `"vow"` | 告白（5）・求婚（7）の受け入れ。間柄が動かなければ保留になる |
| `fut: "road"` / `"retire"` | この先（10）の選択。人生の物語（M6）の一行も変わる |
| `mend: true` | 仲直りの話題で、仲直りになる返し（無い返しは、こじれが続く） |
| `aff2`・`rel`・`rivalSour` | やきもちの話題で、相手（`{m}`）の好感度・二人の間柄（K7）・相手の筋がこじれる |

### データの形
```js
D.R2.ARCS.dil = {
  hard: { add: 8, need: { 5: { test: (S, c) => …, hint: "…" }, 7: {…} } }, // 難しい道だけ
  chron: "{who}と、…", // 結婚の段の年代記
  steps: [ { title, text, replies: [R(…), …], mood }, … ], // 10 個。並びが段
  mend: { title, text, replies }, // こじれたあとの仲直り（何度でも出る）
  jeal: { title, text, replies }, // 別の恋の相手（{m}）が一党にいて、筋が 3 段まで進んでいるとき
  trust: [ {…}, {…}, {…} ], // 18 歳未満の主人公には、恋の代わりにこちら（兄姉・師のような情）
  story: { love: […], wed: […], retire: […] }, // 人生の物語（M6）の一行。{name} 主人公・{sp} 相手
  retireSay: […], // 剣を置くときの一言
};
D.R2_PARTS.dil = { ltease, lworry, lteased, lworried, jeal, jealR }; // 恋仲の相手と、ほかの仲間の型の掛け合い（下）
```
- 文の差し込みは会話と同じ（`{n}` `{you}` `{m}` など）。主人公で変わる所：`{hs:男の文|女の文}`・`{hr:elf=…|beast=…|*=…}`（種族）・`{ha:young=…|mid=…|old=…}`（25 歳未満・45 歳未満・それ以上）。文を関数 `(h, S, c) => …`（h は `{ sex, race, beast, age, band, name }`）にしてもよい。
- 好感度の動き：ふつう +3〜8、深い段 +8〜10、こじれる返し −3〜−6。

### 難しい道
エルフ・獣人・格の違う相手（と、好感度の低いところから始まる人）は、`hard.add`（段の好感度の線を上げる）と `hard.need`（告白・求婚などの段に条件）。条件は**噂（`D.RUMORS`）と会話で察せる**ようにする（その人の身の上を聞いた・故郷に寄った・仲間との間柄・主人公の種族など）。条件がそろうまで、その段は出ない。

### 仲間どうし
- `D.R2_PARTS[id]`：`ltease`（恋仲の相手をからかう）・`lworry`（心配する）は仲間 48 人全員、`lteased`・`lworried`・`jeal`（張り合う）・`jealR` は恋の相手の 20 人。`{o}` 相手・`{you}` 主人公。「」は書かない。子どもの姿・18 歳未満の人は、家族の情（兄姉を取られた・心配）で書く。
- 型：冷やかし（恋仲の相手と、ほかの仲間。間柄 −10 以上）・心配（間柄が気安い以上）・張り合い（恋の筋が 3 段まで進んだ二人。間柄 −3）。
- 手書きの掛け合いは `id` を `bt_r2_` で始め、`when: (S) => G.r2St("dil", S) >= 6` のように段で出す。恋の掛け合いが出せるときは、先にそれが選ばれやすい。

## 恋の相手の一覧と組み合わせ（Q8）
持ち主の決定（「結婚は男と女、女と女としかできない」「恋仲になれるのは人間の見た目をしたものだけ」「いきなり惚れない」）。表は `src/data/q8_pairs.js`（`D.Q8P`）、仕組みは `src/engine/zzzzzzz_q8_pairs.js`。

- 恋の相手は `D.Q8P.ALLOW` の一覧の人だけ（romance の印・18 歳以上・子どもの姿でない、に加えて**人間の見た目**）。ギグラ（ゴブリン）は外した（`D.Q8P.DENY`）。名の無い仲間・魔物の子分も恋に進まない。好感度が高ければ、今まで通り情の出来事（`events_c_bond.js`）になる。
- 主人公と相手の組み合わせは「男と女」「女と女」だけ。「男と男」では恋の気配・恋の話題・恋の筋・告白・求婚が出ない。
- 恋の気配（M10 の spark）と恋の筋の一段目は、加わってから 14 日たち、身の上話を 2 話以上聞いてから。
- 格の違う相手（`D.M11.AP`）は、人の姿で現れる二人（煙の女・両替商）だけで、組み合わせの決まりも同じ。
- 古いセーブで、すでに恋仲・約束・連れ合いの仲は、そのまま残す。ただし人の姿でない者（ギグラ・魔物の子分）との仲は、恋の間柄を解いて「固い絆の仲間」にする（C11。`G.c11Fix`）。
