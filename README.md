# Morsveld 世界観・人物の設定まとめ

ブラウザの一人用 TRPG「Morsveld」の世界観と人物の設定一式。別のゲームで流用するときに、エージェント（Claude Code など）に読ませる前提でまとめた。

## まず読む順番
1. `docs/review/canon_2026-10-11.md`：**設定の正の一覧（いちばん大事）**
   - 第一部：世界・時代・国・場所・使徒・眷属・世界のきまり・受動的な出来事の根拠
   - 第二部：仲間 53 人と名のある人物の、性格・目的・口調・関係・居場所
   - 2026-10-11 に、物語の全文と照らして点検してある。
   - そのあと持ち主が決めたこと：聖都エルヴィナは王国領にあるが教会が治める治外法権の街。第六王子ティリアの都は麦の都グランベール。ほか（「設定側で一つに決めること」節）。
2. `docs/lore/world.md`：世界観の入口。設定の段階の印〔知〕〔噂〕〔進〕〔秘〕の意味もここ。
3. 必要に応じて、ほかの `docs/lore/*.md`
   - `life.md`：暮らし
   - `igyo.md`：異形・化物
   - `majin.md`：使徒
   - `gods.md`：神々
   - `history.md`：歴史
   - `ancient.md`：古い文明
   - `curses.md`：呪い
   - `dungeons.md`：迷宮
   - `mountains.md`：山
   - `strata.md`：階層
   - `reveal.md`：何をいつ明かすか
   - `voice.md`：語り口
   - `taste.md`：持ち主の好み
4. `docs/VISION.md`：ゲームの方向性・用語集・文体の決まり（Morsveld 用。流用するのは用語集と世界観の部分だけでよい）。

## 流用するときの決まり
- 設定・世界観・人物の性格をねじ曲げない。足すときは、この設定と食い違わない形にする。根拠が無いなら、その形をやめる。
- 出来事は、受動的なもの（世界・人物の側から起きる。動く理由が設定にあるときだけ）と、能動的なもの（プレイヤーが探索・行動して初めて起きる）に分けて考える。
- 〔秘〕の真相は、プレイヤーに見える文に書かない。
- 一般の人は上位の存在を知らない。設定を説明するためだけの人物や文は書かない。
- 性的な描写は直接書かない（ほのめかしと場面転換で）。恋の相手は人の姿をした大人だけ。
- 参考作品の名前・キャラ名は書かない。

## 絵
人物と魔物の絵は、別に渡す素材集（ツクールMZ 用）にある。canon の人物の id と、素材集の id は同じ。
